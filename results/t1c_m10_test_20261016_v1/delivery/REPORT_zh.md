# T1-C：m10 修正版 19 dB 测试集结果

仅原 common500 与独立 new100、两个冻结熵码家族、每源原三次噪声。两个集合分别统计。固定 N=1024（68 头＋956 正文）、Es=2、q=6、k/n=4780/5736；13 bit 长度＋16 bit CRC 后实码容量4751 bit。失败输出保留分母。

600次 m10 TX 已全部完成；原24终点全部逐字节一致。common500仅6/500、new100仅1/100实际装下完整 m10。其余严格按校准后冻结的整尺度/部分尺度顺序回退，未再选择策略或检查点。

3600逻辑帧中2454帧复用（其中378帧来自另一家族的完全相同既有事件）；1146个改变的逻辑帧合并为1125个不同物理发送，上限2250包。相同实际发送与实际RX输入仅执行一次。各阶段实际调用数见closure_audit.json。

**必须披露的版本差异：**旧common500整尺度来自较早4090环境，其码流与当前冻结H800实现不同。因此500源的整尺度旧版本不能直接继承；其中126源可从另一家族的完全相同既有事件继承，其余374源需要更新发送；与旧整尺度的差值混合了实现环境/码流版本和m10开放的影响，不能全部归因于m10。旧版本及旧分数仍保留。
