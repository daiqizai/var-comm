# 训练结束后直接测试

本轮按用户“跑完直接开始测试”执行。触发条件是原计划的 256 分辨率 100,000 步与
512 分辨率 50,000 步全部完成，总计 150,000 步；单个运行窗口结束不是训练完成。
既有八卡任务保持原代码、截止时间和资源账本。之后只在实际退出为 0、PID/start_ticks
确认退出、检查点哈希正确且八卡空闲时，建立新的有限恢复段。模型、损失、数据、优化器、
随机状态与总步数不变。旧四臂不恢复，STOP_MAIN 或未知失败阻止接续。

唯一 `posttrain_chain_v1.py` 等待既有角色，最多接续八个 12 小时段（每段最多 96 GPU
设备小时，软停止留出保存时间），整个控制链七天到期；并非无期限训练。达到计划步数
立即停止增加训练段、保留最终完整检查点，开始测试。它不会根据测试结果选择检查点或调参。
测试每个角色最多两小时，48 个单卡角色上限合计 96 GPU 设备小时；未用额度不制造调用。
原窗口不重置；这些是新的、逐段登记的有限分配。

## 固定比较

- 原有 500 个测试源 ID，保持原顺序；核验文件、原生像素、两种预处理像素及与训练集的隔离。
- 256 预算：512/768/1024/1536/2048/3072/4096/8192 bit；512 各预算乘四。
- 每图、每方法、每预算计一个真实源包结果；总计两分辨率各 8,000 个逻辑位置。
- 新模型使用已实现的 136-bit 封装；原 codec 使用已有 72-bit 封装与预先共享的分辨率。
  所有封装、终止和熵流字节均计费。这是相同总源包预算的系统比较，不是等开销消融。
- 256 原 codec 的 4,000 个逻辑位置从已验证缓存选择，不重新推理。独立 RX 原生像素、
  接收前缀、实际码长与指标输入哈希逐项核验；每个评分分片核验一个固定旧图像对的指标路线。
- 512 原 codec 采用其原生四个 256 patch、28 个 slice 的表示，固定一个全图预算；
  新模型采用已训练的全图表示。资格与完整结果来自实际执行，不预称通过。
- TX 与 RX 为独立进程；RX 禁止读源图和 TX 私有目录。接收 ID 在后续 CPU/指标审计中比对。
- FP32 推理、TF32 关闭、math SDPA；训练仍保持既有 BF16 E/D。四指标为 PSNR、
  LPIPS-Alex、DISTS、DreamSim，均从原生浮点重建评分。训练 LPIPS-VGG 不代替测试指标。
- 复用完整源顺序一致的 10,000×500 bootstrap bank，直接对 new−original 逐源差值计算区间。
- NULL 保留灰图和分母；未知执行错误保留记录并阻塞该分辨率，不伪装成成功或自动重跑。
  独立分辨率仍可继续。没有新增无线 PHY、旧训练臂或参数扫描。

## 实际状态与交付

协议、清单、缓存身份和数据分隔先在 CPU 上登记；控制链启动后仅等待当前训练，尚无新质量结论。
第一个固定分片完成 TX、独立 RX、评分与审计后，其余七个分片才启动。
最终交付逐图指标、均值与配对区间、实际包长/端点/NULL 数、调用与复用数、资源账本、
失败记录和正负结果报告。大数组、权重与日志仅保存在 PFS。

原先日志显示的质量平台不会被有限 loss 或更大参数量替代解释；是否提升以本测试为准。
