# 多码率主模型实现与训练启动记录

已实现 **639,592,611** 个可训练参数，并在 PRO 的1/2/4/5四卡上训练同一个模型。
本快照已执行 26266 次优化器更新，活动训练清单 115471 张图像。新模型质量尚未正式评价，
这些更新和训练损失不构成率—质量改善结论。旧四臂、其检查点和 STOP_P2 原样保持暂停。

模型：RDVQ 兼容预训练初始化；12层/768宽编码latent Transformer，24层/1024宽条件重建
Transformer；新增stride-8离散表示；256/512分别1360/5440 token。码本、编码器、熵模型和
重建器均可训练。预算条件改变源描述，因此不声称不同预算共享同一码流前缀。

真实源包包含17-byte付费封装。60个候选分别终止，通过实际字节数检查容量。资格包7904bits，
工作预算8192bits，端点43；独立进程只用checkpoint与packet恢复，token与原生像素逐项完全
一致。CRC拒绝已检查。256/512全部模块组梯度有限非零，实测峰值12.93/18.51GB。

训练：全局batch32，256/512的单卡microbatch4/2；BF16用于E/D，熵概率/CDF、参数和优化器
保持FP32，TF32关闭。训练目标MSE+LPIPS-VGG+可微率项+预算超出项+VQ；每四次更新一次完整
表示训练。计划256的100k更新和512的50k更新尚未全部执行。首窗口最多12h/48GPU设备小时，
原截止时间不重置。checkpoint包含全部rank的随机状态、优化器、步数及数据清单/游标。

第一次训练已在step26248安全保存后切换到独立train_v2代码，修复“数据清单切换后再保存模型
与优化器”的恢复顺序，并允许接纳最后不足1000张的已验证语料尾段。继承原checkpoint和同一
资源截止时间，没有重置训练步数、学习率计划、损失、模型或精度。原训练actual0/gone保留。

COCO候选116287个训练ID，剔除固定开发/校准ID；当前有效去重训练图116238，34个下载失败
保留，未冒称完整下载成功。训练清单仅含验证文件SHA、官方ZIP CRC及原生像素身份的图像，
排除已有开发/校准/测试像素。另已启动固定100k Open Images数据准备；尚未进入活动训练。
其官方元数据、许可和CVDF缩放图像身份按配套脚本保存。200k–1M语料目标仍在推进。

原失败：两个资格进程在任何优化器更新前因BF16/FP32索引赋值不一致退出；明确修订后使用
FP32熵路径并通过。首数据进程因复用记录的status字段重复而中止，独立v2复用已验证图像。
原诊断、资源账本及源快照保持，未覆盖失败或把它们计为成功。无旧P2重启、无新无线帧结果。
