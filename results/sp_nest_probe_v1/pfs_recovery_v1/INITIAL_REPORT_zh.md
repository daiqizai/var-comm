**链路究竟验了什么。** 接收端只取得公开规则、计数器、噪声信息及接收符号；两层有各自的 CRC 和公开加扰。合法的基础层才能用于 SIC；增强层失败保留基础层；头部或基础层失败走灰图状态。12 位目录含付费 NULL 共 3,805 项，基于码长界剔除不可能回退的项，不按图或分数定目录。对一张已登记图的真实源 token，在受控条件 CDF 下，24 个历史单段、4 个基础层和 68 个增强层码流与原实现逐位一致；4 个进入 `(10,0)` 的新增边通过独立解码。组合测试在一个无噪声非空帧内由实际接收比特解回 297 个 token；另一个显式 NULL 帧占满 1,024 符号，得到 `NULL_GRAY` 状态。这些检查使用真实 LDPC/调制解调和算术码，但没有运行冻结 VAR 概率模型或神经图像解码器，不能据此报告感知质量、带噪可靠性或系统增益。

**已有真实码长能回答的一个问题。** 在预定网格中取容量最大的基础层和增强层（分别为 1,245 和 3,795 源比特）。基础层取到第 6 尺度时，50 张图的基础层均装得下，但其中 47 张在端点 `(9,192)` 的增强层已经超出上限。对同一初始上下文和独立终止规则，延长前缀不会缩短码长，因此至少这 47 张不能一直发到 `(10,0)`，另外 3 张是否能发全仍未知。第 4、5、7 尺度切分下，可同时装下两层直到完整表示的源数上界分别为 1、1、1。这个结果约束了可行端点，不给出接收质量，也不决定叠加相对于单码字或时分的优劣。

**补齐 SP0 还需要什么。**

1. `sp0_source_length_evidence.csv` 枚举全部 3,600 个键；已有 3,400 个实际 B/E 长度对，另有 150 个预定主切分和 50 个合法回退切分缺 `(10,0)` 增强流长度。历史整尺度流不等价于重置算术状态后的条件增强流，296 个核过身份的 T6 整流均未冒充增强流。
2. `sp0_clean_quality_evidence.csv` 枚举 1,250 个源/端点组合：1,200 行有历史 DINOv2 与 PSNR，50 行完整端点待核。DISTS 与 DreamSim 均显式留空。`sp0_gray_quality_evidence.csv` 另有 50 条与原生源图身份及灰图哈希一致的 DINOv2 原值；它们不是新的神经评分。恢复原生重建并逐个匹配已有 SHA256 后，才可补感知指标。缺失值不计为零，不缩减 50 源分母。
3. 原图缓存缺 slot 10 / `0008`：`n01514859/ILSVRC2012_val_00006195_n01514859`。其 token 已核对；尚缺可读取的原生源图文件。`pilot50_asset_inventory.csv` 中 `original_checkpoint_verified` 指原始的逐源元数据 JSON，不是模型权重。该源原始文件见 `results/layered_entropy_feasibility_20261014_v1/assets/pilot50.json` 中对应条目的 `archive.path`；冻结的模型、定制解码器与数值路径见同目录 `model_routes.json`。优先查共享 PFS 原 LE 工件 `science/streams/`、`science/all_clean_images.json`，不得以展示 PNG 或其他权重代替。
4. SP1 选单码字基线前应澄清候选身份：工作单称“396 个 NeST 候选”，原统一校准表在 4/7/10/19 dB 的每个 SNR 分别列 300 个 NeST、84 个 WHOLE、12 个 Ada，一共才是 396。表中也没有现成 13 dB 冻结策略。先固定真实 NeST 候选/候选清单与 13 dB 的选择规则，再评分；不能把其他模型并入 NeST 或把 10 dB 结果当成 13 dB。历史 LE2 的 7/10 dB 数据不是本次双接收机广播实测。
