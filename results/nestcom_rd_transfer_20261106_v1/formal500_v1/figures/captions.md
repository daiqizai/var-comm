# Fixed-step original NeST comparison

Matched budgets: four equal total information-packet limits (source capacity plus 12-bit profile, 13-bit length and 16-bit CRC). All five metrics and all pointwise 95% source-bootstrap intervals are retained. This is a clean-packet source-codec evaluation, not a new wireless-frame experiment.

Full representation: both systems independently decode all 680 tokens. Actual terminated arithmetic-code length is reported separately; this comparison measures the full-reconstruction ceiling, not equal-bit performance. Points and error bars use all 500 fixed held-out sources.
