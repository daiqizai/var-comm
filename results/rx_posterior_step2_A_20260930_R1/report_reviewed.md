# P4084 接收端验证：A 部分结论与完整结果

已完成固定 200 张校准图和 100 张 development 图的六档评估，训练更新为 0。下面直接回答执行方案的四个问题；后文保留完整逐点表、负结果、诊断与图表。

完整 per_frame/token_accuracy CSV 在 Git 中以原样分片保存；首次克隆后按 [恢复说明](README.md) 运行 `python3 tools/archive_rx_step2_tables.py restore` 即可恢复原路径和字节。完整原文件 SHA 见 [分片清单](table_shards/manifest.json)。

## 四个问题的答案

1. **V 是否胜过原 P4084？** 在 1/4/7 dB，校准选择真正旁路，最终输出与 B2 相同，未建立范围内增量。在训练范围外的 −5/−2 dB，V 超过原 P4084，并通过预定的明显增益标准。−5 dB 相对 B2 的 LPIPS 下降 0.05076、DINO 提高 0.19734；−2 dB 分别为 0.01789 和 0.04599。PSNR 均值差为 −0.06459/+0.02500 dB，均满足下降不超过 0.3 dB 的约束。
2. **V 是否超过 A1 和 A2？** 两个范围外点都超过这两个控制。−5 dB 对全部控制同时满足 LPIPS 与 DINO 的明显收益分支；−2 dB 对全部控制由 DINO 分支达到明显收益标准，并通过各自的源图匹配特异性检查。−2 dB 的 LPIPS 差显著改善，但幅度未达到 0.02。范围内三个策略都旁路，主策略之间没有增量。
3. **共同融合权重下是否仍有增量？** −5/−2 dB 对 A1_common 和 A2_common 仍保留 LPIPS、DINO 与源图匹配特异性收益，支持候选内容的作用，收益并非完全依赖各自 alpha。1 dB 相对共同权重控制仅有较小 DINO 收益（+0.00520），LPIPS 区间跨零；V_common 相对原 B2 的 LPIPS 恶化 +0.00596、DINO 下降 0.00663，不能据此替代旁路主策略。4/7 dB 的选中 raw lambda 为 0，V 与 A1 候选相同。
4. **下一步应验证哪个具体问题？** 优先问题是：在专门适应 −5/−2/1/4 dB 的 P_low 基线上，VAR 是否仍超过该基线、无先验量化和静态先验？现有数据尚不能回答低 SNR 收益中有多少来自原 P4084 的训练范围失配。方案 B 需要用户另行决定，当前 A 已停止。范围内没有部署收益，不建议依据这一轮自动推进 Step 3。

## 代价与高 SNR 保护

- -5 dB：CPU 接收波形→CPU 图像平均 12.99 ms（B2）与 125.87 ms（V），增加 112.88 ms，约 9.69 倍；包括 P 接收网络。
- -2 dB：CPU 接收波形→CPU 图像平均 12.94 ms（B2）与 125.31 ms（V），增加 112.38 ms，约 9.69 倍；包括 P 接收网络。
- 13 dB：最终旁路与 B2 相同。未旁路 raw lambda=0 融合候选的 LPIPS 恶化 +0.00056，95% 区间为 [0.00042, 0.00070]；固定 lambda=1 候选也恶化。保护来自旁路，不能称 VAR 修正天然高 SNR 无损。
- 计时按单帧真实接收链测量；质量评估采用配对批处理。计时表未逐像素核对其输出与质量分支一致。
- 原始 timing.csv 的 B2.raw_selected_lambda 字段保存同一 SNR 的 V 候选元数据；B2 实际不使用 lambda。本报告 B2 的该列标为“不适用”，原表保持原样。

## 证据与阅读入口

四项必要自检、历史 B2 复现和权重冻结检查通过。保存了 25200 行图像指标、108000 行逐尺度 token 诊断、360 次正式计时、40 张固定样例和 8 个图表文件。服务器原始结果的 68 个文件已下载到本机并逐文件通过 SHA256 校验。

该 development 已多轮使用，结论是探索性证据；区间不包含训练 seed 变异，未作多重比较校正。−5/−2 dB 的优势属于训练范围外诊断。经验误差方差与相关误差融合均不构成精确物理后验。

## 证据与适用范围

- 原始 per_frame.csv 保留同一 P 观测下的全量配对图像指标、原坐标 latent 误差、动作、lambda 与实测 N/E。
- 以 100 个源图为推断单位；每张源图先平均三噪声。所有方法共用 10000 组源图 bootstrap 索引，seed=20260930，逐点 95% 百分位区间，未作多重比较校正。
- 该 development 已多轮使用，本轮是探索性验证；区间不包含训练 seed 变异。
- 经验重建误差方差包含学习映射与压缩误差；融合是误差可能相关时的启发式收缩，不是精确物理后验。
- BYPASS 原样返回 B2；lambda=0 仍是量化修正候选。旁路结果不记为 VAR 修正成功。
