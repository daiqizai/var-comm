# 自适应 BPG 补充结果与论文边界

这份说明只读取已完成的 `metrics_v1`，未重新 bootstrap、推断或运行 PHY。原始精度数字见 `paired_interpretation.csv` 与 `adaptive_summary_original_precision.csv`；方便阅读的六档对照表见 `paired_results.md`。差值始终是“自适应 BPG − 参考方法”，LPIPS 没有翻转符号，一致性差值乘 100 后以百分点表示。

## 必须保留的结果

| 参考方法 | 结论 |
|---|---|
| 本文 | 自适应 BPG 在 1/4/7/10/13/19 dB 的 PSNR 全部更高，增量分别为 +2.668/+3.575/+3.164/+2.828/+2.843/+2.665 dB，六项配对区间均大于零。本文在全部六档的 LPIPS、DINOv2-L、ConvNeXt 原图预测一致性更好，对应区间均排除零。应写失真与感知/表征代理指标之间的取舍，不能写本文全面胜出。 |
| 连续潜空间 JSCC | 自适应 BPG 的 PSNR 六档全更高；LPIPS 和一致性六档全更差。DINOv2-L 在 1–13 dB 更差；19 dB 差值 −0.01414，区间 [−0.03274, +0.00442] 跨零，不能写该点仍有明确优势，也不能据此宣称等效。 |
| SwinJSCC-80k（适配） | 1/4/7 dB：自适应 BPG 四项全较差。10 dB：PSNR 差值 +0.00425 dB、区间 [−0.08132,+0.09737]，方向不能确定，其余三项较差。13 dB：PSNR +0.29346 dB、区间 [+0.20118,+0.39362]，但 LPIPS 较差；DINOv2-L 和一致性均跨零。19 dB：自适应 BPG 四项均更好，必须同时标注该点在 Swin 训练和校准范围外。 |
| 原生 256 BPG+LDPC | 自适应版本在四指标 × 六档共 24 项均改善，已有逐点区间均排除零。原生版本保留为单独补充对照，不能只展示其溢出灰图来代表传统数字方案。 |

在 13 dB，自适应 BPG − 本文的原配对结果为：PSNR +2.84287 dB [2.75854,2.92977]，LPIPS +0.37678 [0.36542,0.38852]，DINOv2-L −0.33177 [−0.35200,−0.31142]，一致性 −48.0 [−52.4,−43.4] 个百分点。

自适应版本在六档均没有 `SOURCE_UNFIT`。7 dB 有 15/1500 帧正文 CRC 失败（1%）；其余五档 1500/1500 成功解码。所有失败帧均保留，不能转成成功子集指标。成功解码也不等于源图细节或语义均得到保存：低分辨率压缩可能提高 PSNR，却有较弱的其他代理指标。

## 适用边界

1. 这是在已评估过的共同 500 来源上，后来加入并独立冻结的基线比较；不改写成全部方法事先共同预登记。主方法和旧结果保持原样，新增 BPG 的 MCS 来自旧 100 图校准，源码候选与选择规则事先冻结。逐源分辨率/QP 是发送端已冻结的源码率控过程，不是根据收到的噪声或测试成绩重新选择系统策略。
2. 必须区分 `BPG+LDPC (native256)` 和 `BPG+LDPC (adaptive downsampling)`。后者让 256/128/64/32 四档源码分辨率竞争并恢复到 256×256 计分。不能继续用“这个预算下传统 BPG 根本装不下”概括全部 BPG 基线。
3. Swin 是固定 80k 适配版本，不是官方最优或充分收敛版本。19 dB 在其训练及校准范围之外，不能拿自适应 BPG 在这一个点的四项优势推导整个方法家族的优劣。
4. 所有区间都是原已有的逐点 95% 源级区间：每来源先均值化三次噪声，再按源配对。整数种子相同不代表不同波形共享同一观测；这里不声称逐帧噪声配对。96 项比较未做多重比较校正，不能据此宣布全局系统赢家。
5. DINOv2-L 使用 `dinov2_vitl14_cosine`，不能混成旧 DINO-S。ConvNeXt 是与原图预测的一致性，不是标签分类准确率，更不是语义正确率。一致性差值是百分点，不是相对提升百分比。
6. 现有 A3 BPG 在线计时对应原生 256 版本。自适应源码搜索有额外编码和解码搜索工作，不能直接继承原生 BPG 耗时，也不能未经同窗计时就称自适应版本更快或成本相同。这份结果说明没有新增计时。
7. 本机对已下载的 507 个科学输出逐个通过原完成清单 SHA 验证；其余 1000 个 source-feature cache JSON/NPZ 未下载，本次没有本机哈希核验它们。远端全 1507 输出检查由 root 另行完成；不能把两者混写成“所有缓存已完整落到本机”。本次还精确核对了 9000 帧、12000 源均值、24 汇总、96 配对均值方向，以及 96 个旧汇总/区间值没有变化。直接发布目录的旧 CSV 本机路径未提供，因此旧数值检查使用有原完成清单绑定的科学统计 JSON/CSV。

质量评价实际运行记录为 2635 次新唯一图像评分，复用 379 个原生 BPG 同源同像素评分，另做 500 次源图特征准备。本说明的核查新增评分、PHY 和 bootstrap 次数均为零。
