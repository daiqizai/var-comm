==================== 1. 本轮要回答什么 ====================

核心问题：
同样固定符号预算与相同功率下，NeST-Com 能否通过更充分使用实收信息、改进补全和选择合法前缀，进一步改善源图重建？

分开记录三类收益：
(1) 接收端收益：传输内容与实际接收结果不变，仅改变 A/B/C；
(2) 装填或选点收益：D/E 改变发送前缀，需要相应实际链路验证；
(3) 组合收益：最终系统相对当前 NeST，以及同一新接收规则下的 WHOLE。

优先研究工作点为 N1024、7/10 dB。
保护性检查覆盖 N1024、4/19 dB 和 N512、4/10/19 dB。
7 dB 不增加 N512 新点；本轮不做新的 0 dB、衰落、多用户或 ARQ 分支。
主目标是 LPIPS 与 DreamSim，PSNR 和 CLIP-I 同时报告。图像示例不用于选策略。

已有证据：
- Quarter→Eighth：100源固定模型/MCS/上限控制，利用率95.38%→97.39%，PSNR约+0.123dB，LPIPS约−0.00223；DreamSim区间跨零。
- 同上限32源：Quarter→逐token，利用率94.14%→99.07%，PSNR+0.07343dB，LPIPS−0.006486，DreamSim−0.014042。不是common500新结论。
- 已训练多前缀锚定Dc相对当前冻结Dc，在(7,0)有PSNR+0.3832dB、LPIPS−0.005015；(10,0)小幅变差。未测DreamSim与完整固定帧收益。
- 当前NeST为null-class和argmax；同尺度未知位置没有重新使用实收边界token预测。
- 已有32源两候选离线LPIPS择优，仅比逐token再降低LPIPS0.000805，DreamSim反而增加0.001615。本轮E不能假定收益。
- 7dB的Dog21在WHOLE/NeST下均收到(7,0)，输出相同；Pastries95的NeST收到(7,25)，WHOLE收到(7,0)。不能以狗图声称边界增益。

==================== 2. 共同通信与实现合同 ====================

固定：
- 256×256源图，原统一预处理；
- VAR-d16、原VQ tokenizer及4096项codebook；
- 原整数CDF构造、总频率2^24；
- N复符号/图；原68符号profile及其卷积保护；body包含13-bit length+CRC16共29bit；
- 原MCS、名义Es=2、实际扰码与功率定义、AWGN和LLR噪声方差；
- 原拒收/NULL规则：灰图保留在总体分母；
- 固定raster位置顺序；
- 当前原始NeST、WHOLE、Ada的冻结策略，不能顺便用最终测试结果重新选MCS。

A/B/C均在原码流正确解析后工作。它们不修改已传token的整数CDF，不用生成概率回填已接收数据。
接收端只能使用合法实收token、实收端点、共享模型和事先定义的随机数。
部署RX进程不可读取原图RGB、完整源token或指标分数；这些信息只在合法TX编码/选点、训练监督或独立评分进程使用。
E的TX本来拥有原图，允许读取它计算预定选择目标；此权限不传递给RX。
训练输入中的粗尺度特征必须由实际可用的完整粗尺度token构造，不能误用全图连续latent。

凡改变码流/profile/端点：旧成功接收结果不自动代表新帧成功。
只有码流、波形、噪声、计数器、协议、模型、预处理和随机状态满足所需的完整身份一致，才能复用对应阶段。
三个信道事件即使重建完全相同，也仍然在统计分母中保留三次；不得把逻辑记录数当成独立GPU调用数。

==================== 8. C：同尺度实收信息条件补全 ====================

8.1 研究问题
当前粗尺度条件预测边界后，实收位置覆盖，但未知位置不重估。
C让当前边界的实收内容参与该尺度未知位置的预测。
它保留原熵模型和无线协议，新增内容只在接收重建阶段使用。

8.2 支持范围
m表示完整接收尺度数量。
m=7：下一尺度10×10，L=100。
m=8：下一尺度13×13，L=169。
只在这两个尺度且0<K<L时调用C，其他尺度/whole/full/灰图旁路原接收器。
K=L先规范化为完整尺度端点，不作为一个额外partial语法。
两尺度共用一个模型。

8.3 输入
原VAR边界前向只执行一次，收集覆盖前的以下量：
(a) 粗尺度构造的32维next_token_map，线性32→64；
(b) 当前尺度原base_logits的log_softmax，4096→64；
(c) 实收边界token的32维codebook embedding与1维mask，33→64；未收embedding置零；
(d) 64维位置/端点信息：固定二维sin/cos位置，加两个尺度ID的embedding，加K/L的线性投影。
四组拼接为256维。
注意这里next_token_map指原接收过程中边界前的32通道空间latent输入，不得误拿已经融合真实边界或全细尺度的latent。

模块只接收(c)中已收到位置的真实值。
完整边界token是训练target，置于单独字段，不能被forward读取。
同容量无内容控制保留相同mask、K/L、粗尺度特征、base_logits、位置，但(c)中的token embedding全部为零。

8.4 网络
- 两层pre-LN Transformer encoder；
- hidden=256，heads=8，FFN=1024，GELU，dropout=0；
- 输出LayerNorm，再linear256→4096；
- 输出linear的weight/bias均零初始化；
- 参数量约2.90M，执行时报告实际参数数，不把设计估计当实测。

l' = l_base + (1-M) * delta_logits。
仅未知位置用argmax(l')。
已知位置不论模型输出如何，均严格写回实收token。
之后使用原get_next_autoregressive_input累加与推进，不改变后续VAR参数。
C单路训练和评估使用原Dc、argmax；与A/B的交互留到组合阶段。

8.5 训练数据与mask
固定同一组10,000训练源，两尺度各一份coarse/base-logit/target条件。
每个batch两尺度均衡；每尺度：
50%的K均匀来自Quarter：
m7为25/50/75；m8为42/84/126。
另50%在1…L−1全部整数中均匀采样。
这样覆盖Eighth和逐token的新K，组合时不需要悄悄扩充支持范围。
固定raster；不同时训练随机空间mask路线。
这些训练端点不一定都能放进某个实际帧；条件端点诊断与真实预算结果分开。

8.6 损失与训练
Loss = CE_missing(l', target) + 0.02 * KL_missing(p_base || p_new)。
先在每张图的未收位置平均，再在batch内平均。
p_base从冻结原logits得到并detach。
训练目标只监督训练源；确认图像不反传。

AdamW：
lr=3e-4，betas=(0.9,0.95)，weight_decay=0.01；
100步warmup，之后cosine至3e-5；
effective_batch=32，默认microbatch=8，accumulation=4；
gradient_clip_norm=1；
FP32，TF32关闭；
每个run最多3000 updates；
种子2026103001/2026103002。

主种子跑C_content与C_no_content两组，严格匹配模型容量、初始非零参数、源顺序、mask序列、batch、训练步数。
初始seed检查点也保存，零残差时应重现原接收器。
每500步记录loss并保存完整可恢复状态。
只在1000/2000/3000步做完整FIT100图像评估，避免每500步重做全套重建。
同容量控制同样评估这三个checkpoint。

checkpoint按第11节的预定双感知score在FIT100选择。
如果主种子相对基线有下游收益，且实收内容相对无内容控制有增量，才执行第二种子两组。
第二种子使用同样选择规则，只检验复现方向；不择优替代主种子，不作ensemble。

8.7 C的缓存与KV正确性
每个候选从空KV开始，由实收完整粗尺度重放到边界。
边界VAR前向只做一次；C在VAR外改变token选择。
不要为“让边界条件生效”再次append同一尺度到原KV。
合并边界后用原函数推进到下一尺度，后续状态重新计算。
第一版不跨候选共享可变KV；需要优化时另做与独立重放的一致性验证。

原熵解码和C重建必须分离。不能把C修正后的概率用于重新解已收到码流。
(c)中的实收embedding不能提前混入(a)/(b)，否则no_content控制失效。

8.8 必须验证的工程不变量
- zero residual→同环境下原输出一致；
- 已收token逐项一致；
- 改动“未收目标标签”不改变forward输入；
- K=0、完整端点、其他尺度、灰图直接原函数旁路；
- 控制模块没有边界真实内容，但两组均保留最终known-token overwrite；
- 候选先后执行与独立执行一致；
- 梯度有限，冻结参数无变化。
先用固定32训练源进行小型smoke，相关计算计入本轮预算，不作为科学结果。

8.9 存储
完整FP32 base logits原始量：
10000×(100+169)×4096×4 = 44,072,960,000字节，约44.1GB。
先核验并复用现有同权重/null-class概率缓存。
新增大数组只放PFS，Git只记录manifest。
预留80GiB本轮大缓存上限；不足时停止C准备并报告，不执行中偷偷改为FP16或缩样本。

==================== 9. D：Quarter/Eighth/逐token装入 ====================

D0 Quarter、D1 Eighth、D2 Token-wise。
各SNR固定原MCS、原最大端点、相同模型/接收器、相同raster、相同真实帧预算。
细网格包含粗网格；不同时扩大最大尺度。

复用一次概率和增量算术编码遍历，在合法端点非破坏地独立finish。
每个候选按真实finish后长度判断可行；不从长码流直接裁切，不假定码长严格单调。
选token数最多的可行端点。无可行端点按原付费NULL。

9.1 profile目录

==================== 10. E：三候选发送端率失真选择 ====================

E0为当前Quarter最长可行端点。
E1在相同Quarter网格、原Dc、argmax下做三候选选择。
首次不与随机补全、C或D联调。

对每图固定：
e0 = 原方法实际会选择的最长可行端点；
e1/e2 = 同一网格与目标上限内，紧邻的两个更短可行端点。
不足3个时用实际可行数；无候选NULL。
禁止额外搜索“视觉特别好”的第四个端点。

TX使用原图模拟每个候选的确定性成功接收重建，选择：
D(x,x_hat_e) = MSE_RGB(x,x_hat_e) + 0.1*LPIPS_Alex(x,x_hat_e)。
MSE_RGB在RGB[0,1]范围内对全部通道/像素平均；LPIPS使用当前固定输入变换。不得临时改为0…255或−1…1范围的MSE而保留同一0.1系数。
并列容差1e-12时优先e0，其次e1，再e2。
使用原生float32图像和冻结预处理，不用PNG计分。
DreamSim/CLIP-I不参与TX逐图选点，只用于独立报告和确认。

TX本来拥有原图，允许此analysis-by-synthesis操作。
但TX不准访问未来AWGN、实际RX拒收、译码后错误图像，也不能用已发生信道结果事后换端点。
最终只发选定端点及其真实码流，profile开销仍计入预算。
不生成/挑选多个随机seed。

在FIT100先复用候选缓存检查最多三候选质量与计算成本；缺失候选才补确定性重建。
候选图像上被优化的D下降不是充分证据；必须报告DreamSim、PSNR、选择比例和实际TX计算。
若只有很小LPIPS收益而DreamSim变差，E停止扩展。
E最多只做当前3候选，不自动转为25/49/651个重建搜索或学习selector。

组合时E重新匹配最终确定性receiver与D网格：
新e0为D*最长可行端点，e1/e2是该网格紧邻更短候选；总数仍不超过3。
首轮不将E与B随机补全组合。两条独立分支可以各自有效，不要求强行拼接。
最终如果选随机分支，E作为独立研究结果报告。

==================== 11. 评价、选择与停止规则 ====================

11.1 指标
LPIPS-Alex、DreamSim为共同主要指标；PSNR与CLIP-I完整保留。
复用当前FP32指标、resize/normalize与模型权重，不改定义。
DreamSim、CLIP-I按当前224×224 bicubic-antialias流程。
C额外报告missing-token CE/accuracy，但不据此单独宣告图像通信改善。

随机B先对生成实现求平均，再对信道实现求平均，最后等权源图。
其他路线先源内平均信道再等权源图。
跨工作点汇总时先逐工作点归一化，再等权工作点；不得把重复次数多的点加更大权重。
拒收/NULL的灰图始终进入总体；“共同成功子集”只作补充诊断。

11.2 FIT100预定选择分数
核心工作点c∈{N1024/7,N1024/10}，用原NeST基线均值L0,c、D0,c：
J = mean_c[0.5*(LPIPS_c/L0,c + DreamSim_c/D0,c)]。
基线J=1，越低越好。
WHOLE以自身原基线单独归一化报告，不与NeST混在同一个主J里选最优。

主采纳候选须：
- J≤0.995（至少0.5%的联合相对改善）；
- 两项感知距离跨核心点的归一化平均均不高于基线；
- 任何已测单点LPIPS或DreamSim相对恶化不超过1%；
- 任一已测工作点PSNR均值下降不超过0.10dB。
这些是本轮工程推进标准，不是统计显著性或普适质量阈值。
若指标改善但不满足此规则，报告有限收益，不改阈值追胜。

各路线的FIT范围统一登记：A/B先完成核心与守护七点；C的checkpoint选择只用核心两点，主种子候选冻结后补守护点；D/E全部候选先做核心两点，胜出候选再补守护点。未经守护检查不进入CONFIRM。WHOLE接收端对照同样报告守护结果，但NeST的主J仍单独计算。

候选J差小于0.001视为实用近似：依次优先更少部署计算、更少模型、较低温度/较粗网格。
这不是统计等效性声明。

C还要求：C_content相对同容量C_no_content的核心J更低；至少一项主要图像距离有增量。
若只比原模型好、和无内容控制相当，只能支持额外接收训练/容量收益，不能归因于实收边界条件。
该情形可作为次级结果保留，但不扩大“边界条件机制”分支。

E还要求：LPIPS平均相对改善至少1%，DreamSim平均不恶化；报告TX成本。
若E只能改善其直接优化的MSE+0.1LPIPS而不满足上述要求，停止E扩展。

11.3 CONFIRM100
参数在读取结果前冻结，评估三个实际信道实现。
采用决策的两个CI均针对核心7/10dB的预定汇总，不能任选一个有利SNR代替。
记M为LPIPS或DreamSim，mu0_M,c为FIT100已冻结的原NeST在核心点c的均值；对源i：
delta_i,M = 0.5 * sum_{c in {N1024/7,N1024/10}} [(M_candidate,i,c - M_old,i,c) / mu0_M,c]。
M_i,c先平均生成实现、再平均信道实现。对每源delta做配对bootstrap；整个比较始终使用冻结分母，不按结果重设工作点权重。
至少一项主要感知指标的上述直接源配对95%CI有利并排除零，另一项CI上界不超过+0.01，即冻结FIT基线尺度的1%。各工作点原始量纲与相对该点原基线的结果同时报告。
同时保留第11.2节单点保护线；不以总体均值掩盖某个预算明显退化。
E在FIT与CONFIRM均须满足其LPIPS平均相对改善至少1%、DreamSim均值不恶化的额外门槛。
C同时对原receiver及同容量控制报告配对增量。内容模块相对无内容控制也须通过同一汇总CI规则，方可把新增收益归因于边界内容；两个训练种子分别呈现，第二种子应复现均值方向，不能择优。
若证据不足，结论为“本轮确认不足/有限收益”，不是“方向永久无效”；不自动补更多样本。

各路线与工作点的95%区间是逐点探索性区间，不能写成同时覆盖所有比较的保证。
FIT选择与CONFIRM推进属于开发流程，最后的独立确认仍由NEW200完成。

11.4 最终统计
common500复用原10000×500源bootstrap索引与源顺序。
CONFIRM100、NEW200各生成一次固定10000次来源重采样索引，随后全部方法复用。
bootstrap_seed：2026103017；每个数据集单列身份与维度。
先源内聚合，再直接对配对差重采样，不能减两个边际CI。
NEW200预注册最终候选相对原NeST的两个主要指标为共同主检验。
两个主检验使用11.3的固定FIT分母和核心工作点汇总，分别对应LPIPS与DreamSim；不是在多个SNR中挑两个显著结果。
除常规95%CI外，给这两个主检验各97.5%双侧CI；同时改善的表述以两者均有利为准。
Ada/WHOLE及各SNR附加比较逐点报告，不用它们反向更换最终配置。

==================== 12. 组合策略：控制实验数量 ====================

各路线先独立评估，不把多项改动同时加入后只报一个总增益。
仅确认有收益的路线进入组合；失败路线完整交付。

确定性receiver候选依次为：
原receiver；
A（若有效）；
C（若有效）；
A+C（仅两者有效时）。
在FIT100用同一规则选择R_det，冻结后确认。

A/C/B组合的调用顺序固定：按原CDF解码全部已传token→原VAR边界logits→C修正未知位置logits（若启用）→按B温度采样（若启用，否则argmax）→known-token overwrite→后续尺度按当前生成规则推进→A选择最终图像decoder。
A必须解码当前组合实际生成的latent，不能复用原argmax完成latent；C+B不能在C之后重新使用base logits把C丢掉。
C零残差在C单路复现原argmax，在C+B中复现相同随机状态的B分支。
D*表示已通过确认的D网格；若D未通过，D*=D0原Quarter。因此E有效而D无效时仍评估R_det+E。

随后：
- R_det+D*：D有效时，使用冻结网格；
- R_det+D*+E：E有效时，对该确定性receiver重新做三候选TX选择；
- R_det+B*：B有效时，检查随机补全与已选decoder/refiner是否兼容；
- (R_det+B*)+D*：B、D有效且前一步兼容时。
累计组合候选不超过8个，已有独立结果直接复用。
E不与B强行组合。
若A或C没有通过，跳过对应节点，不创建另一个未经注册的替代模块。

最终候选在FIT100选择；CONFIRM100只作采用/不采用判断，不调配置。
最终逐项移除消融：原系统、最终系统、逐一移除最终保留的组件，最多7臂。
最终不含E时，接收端组件移除可复用同一实际前缀；D/E移除改变TX时须验证真实新帧。
最终含E时，移除A/C会改变TX模拟的重建与三候选评分。完整系统消融必须按移除后的receiver重新选点，对改变的码流补真实PHY；相关计算计入预算。
若固定原E选出的实收前缀、仅改变RX，则另标为“固定前缀RX干预”，不能当作完整系统去组件消融。
全部消融先在CONFIRM100完成；NEW200只测试冻结最终系统及预定外部/同模型对照，不跑所有开发组合。

A/C新接收器收益与D端点收益分开：
最终系统与原NeST比较整体提升；
最终系统与使用同一新receiver的WHOLE比较尺度内传输收益；
最终系统与去掉C_content输入的同容量控制比较同尺度真实信息作用。
不能把全部系统提升归因于某一个模块。

==================== 14. 计算预算与调度 ====================

以下是执行上限，不是耗时预测：
P0 1 GPU设备小时；
A 2；
B 6；
D 4；
E 3；
C（缓存、smoke、四个训练run及重建）24；

只有通过确认的冻结最终方案，才使用额外最多24 GPU设备小时完成common500/NEW200/计时。
全轮总上限72 GPU设备小时。

GPU设备小时为所有科学worker实际占用的GPU墙时相加，包含模型加载、特征准备、训练、重建和指标；不以多卡并行缩小计费数。

预算不足保留checkpoint和报告“预算内未完成”，不把它当作负结果，更不重置计时器续跑。

默认最多2个GPU worker并发，C单个训练run用一张卡。
先检查实际空闲资源；不默认占满八卡，不影响他人任务，不修改全局GPU设置。
独立训练run可以在可用的第二张卡并行，仍各计设备小时。
源码/PHY/统计CPU worker使用已核验的资源配额；同一实验只保留一个链路owner，避免重复启动。

全部新科学任务采用单一有限调度链：状态PREPARED/RUNNING/COMPLETE/NO_GO/BUDGET_STOP/BLOCKED。
成功调用不因绘图或汇总错误而重跑。工程修复保留原失败记录，在新版本入口继续尚未执行的工作。
