# 主系统草案：已有事实与待冻结选择

## 要验证的问题

在每张图固定的信道预算下，部分尺度载荷是否比充分优化的整尺度载荷，更有效地利用冻结 VAR 的补全能力？系统目标需同时报告源图一致性、像素与感知失真、失败概率和计算成本。DINO 上升本身不表示主体内容更正确。

## 拟定的 N1024 主系统

发送端按冻结视觉 Encoder/VQ 取得多尺度 token。策略从按同一合法性规则形成的对称有限短名单校准选择整尺度前缀或前缀加部分下一尺度，每个家族、每个 SNR 最多三个候选；最终只称“登记范围内最优”，不称全网格最优。token 保持原 12-bit 表示。68 个 QPSK 符号的头部携带公开配置 ID，正文至多 956 个符号。正文为一个 CRC16+LDPC 组，具体 QPSK/16QAM、码块和 rate matching 均按真实实现计费。

接收端只使用实际头部判定及译码输出，把可用 token 放回正确位置，再由冻结 VAR 进行无类别、greedy argmax 补全，最后由同一 Dc 解码。失效处不使用真实源 token 作为答案。CRC 接受仅是协议判定；漏检帧必须按收到的错误 bit 处理。

以下仍是 S1 需要校准、登记的选择，不能在论文中写成已完成：

- 部分尺度光栅序或熵序。K>0 时顺序改变实际发送 bit，须各自通过真实链路；光栅优先的工程容差按方案执行。
- KEEP 或 DROP 失败处理。二者共享同一实际译码；KEEP 需要真实失败硬判决，干净 Q 表不能替代。
- 同一科学口径下最优 WHOLE 和 PARTIAL 策略。PARTIAL 的动作集合包含 WHOLE，不能给 WHOLE 更弱的保护或选模机会。
- 各 SNR 的最终配置、边界 N512/N2048 配置、完整指标与在线计时协议。

所有配置在校准集选定，development 不参与选择。新主系统预计在 AWGN、已知工作 SNR、一次前向传输下评测，不含重传。QPSK 保证逐帧 E=2N；16QAM 保持平均符号能量 2，另外报告实际逐帧能量，不称逐帧严格等能量。

## 已完成系统在主图中的身份

| 系统 | 可以直接陈述的事实 | 需要保留的区别 |
| --- | --- | --- |
| P1024 | 选定40k、像素+LPIPS+latent联合损失的连续基线 | 预算截断；不是纯 MSE；不重新训练 |
| SwinJSCC | 同一共享 N1024/N2048 的 MSE 模型、用户指定80k | N1024为768正文+256付费头；尚未证明收敛 |
| HiFi-DiffCom | 冻结 ADM 接收生成，复用同一 Swin 实际观测 | 当前仅固定16、7/13dB的小样本；成本约80秒/帧 |
| 旧 M1 | 部分尺度、原卷积码和原分包失败规则的实测 | 属于历史协议，不换名为新 LDPC 主系统 |
| 旧 LDPC B0 | 单组保护、熵序、CRC拒收丢弃，已有AWGN实测 | 光栅/KEEP等变化后需重新核对波形和输出复用条件 |

关键对照是同协议 WHOLE/PARTIAL，以及同一实际接收 token 的 VAR 补全/直接 Dc 解码。主系统与 P/Swin 的比较回答系统取舍，HiFi 提供生成式外部定位；三类问题不混为一项结论。

## 独立 C 模型筛选

C 是单次前向、共享量化 CSI 的 QCSI-U/QCSI-C8 对照，不是主系统的中途反馈或 ARQ。N1024 中导频16、3-bit反馈16、头68均计费，正文上限924。CSI仍理想，仅考察资源支出，不模拟有限导频估计误差。两者使用相同的792,747个已枚举候选，冻结量化阈值；800源构造、既有200源描述性复核。C8公开字典最多8个配置，其内容选择另有发送端计算代价。

C 模型达到预登记增量门槛只表示值得讨论下一步，不能称为实际链路或独立测试优势。当前授权在模型报告处停止；补位置资产、实际 fading、图像与独立分类验证要另行安排。S1 主系统可继续按已授权顺序推进。

本草案不声明文献优先权，不代替最终科学登记，也不表示新的 holdout 已开始。
