# S1规则选择：光栅 + KEEP

已核验下载的 `S1_SELECT_COMPLETE` 凭证以及它绑定的 `selection.json`、`bridge_summary.csv`、`REPORT.md` 三个输出SHA。这是**200张calibration上的规则桥接**，没有完成主系统1000张完整校准，也不是新holdout。

## 按原登记规则得到的选择

范围为原construction800中的固定hash200，7/13 dB、噪声4101/4102/4103。先在冻结的DROP口径比较排序；光栅−熵序的DINO-L≥−0.005且LPIPS≤0.003时优先光栅。然后在已选排序下，KEEP的DINO-L均值严格高于DROP时选KEEP，否则选DROP。

实测排序差为DINO-L **−0.001763**、LPIPS **+0.000478**，符合原工程容差，所以选光栅；光栅下KEEP−DROP的DINO-L为 **+0.001282**，因此选KEEP。它不表示光栅在图像质量上超过熵序，也不是统计等效性结论。S1的工程容差不能替代H新登记的零非劣界。

| 配对诊断（7/13 dB等权） | 均值差 | 95%源级区间 |
|---|---:|---|
| 光栅−熵序，DROP，DINO-L | −0.001763 | [−0.008122, +0.004555] |
| 光栅−熵序，DROP，LPIPS | +0.000478 | [−0.002156, +0.002883] |
| 光栅−熵序，DROP，PSNR | −0.016252 dB | [−0.045943, +0.011780] |
| KEEP−DROP，光栅，DINO-L | +0.001282 | [0, +0.003254] |
| KEEP−DROP，光栅，LPIPS | −0.001111 | [−0.002784, 0] |
| KEEP−DROP，光栅，PSNR | +0.009234 dB | [0, +0.023770] |

这些区间沿用原2000次、seed2026100507，未参与选择，不改成H/C的新区间协议。KEEP/DROP共用实际译码；CRC接受但错误的比特按实际接收重建。7 dB光栅DROP的灰图率为0.333%，KEEP为0；13 dB这两种失败规则的输出均值相同。失败子集只能解释变化，不代替全帧结果。

后续主系统按光栅+KEEP、LDPC、QPSK/16QAM各自完成原有界校准，再冻结配置。H压缩包继续使用自身登记的DROP，不直接套raw KEEP。
