# 后续 H 执行代码准备

本次只交付后续阶段的代码和模拟 CPU 验证，尚未登记或启动这些科学阶段。

- 有界精化：只执行冻结预筛请求中的最多两个码块测点，每点增加6144次，与原2048次合成8192次。
- 真实载荷 CPU 接收：验证来源、预算和完整候选表，保留实际收到的头部和正文；算术源解码交给独立接收阶段。
- 独立接收与重建：按实际接收输入执行规范算术解码或拒绝，接收器不读取发送端真值；完成后按源图计算逐帧PSNR。
- 200源选策：完整核对每候选200图×3噪声，按逐源平均PSNR，在四臂、两个SNR下各选一个原候选。

每个新阶段仍须绑定实际上游完成凭证、代码和输入，另立执行登记。模拟测试不代表真实链路或GPU资格通过。
