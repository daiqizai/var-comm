# S1 排序与失败规则桥接

冻结排序：**raster**；冻结失败规则：**KEEP**。

在 DROP 口径下，光栅减熵序的等权 DINOv2-L 差为 -0.001763，LPIPS-Alex 差为 0.000478。

200 张原 calibration 构造源、7/13 dB、4101/4102/4103 噪声。KEEP/DROP 共用实际译码；熵序 KEEP 的失败 partial 全部丢弃。CRC 接受但错误的比特按实际接收重建。

这是一次预登记工程选择，不是测试集效果，也不是统计等效性结论。最终两族配置仍需按统一新规则完成有界 calibration 后冻结；本阶段不自动开展 holdout。
