# N1024 paid-NULL protocol extension

Independent protocol `NESTCOM_N1024_PAID_NULL_20261029_V2`; historical frozen code and historical results are unchanged. Original 372 profile records, header waveforms, public scrambling convention and normal source paths are preserved. Twelve appended paid IDs cover the original twelve MCS layouts. Missing input evidence raises an error instead of being converted into a NULL.

The bounded CPU check actually transmitted and received 18 complete 1024-symbol frames (36 packet decodes): three historical payloads were checked through both catalogues, and twelve constructed no-fit cases covered all MCS layouts. Normal full waveform, profile, information/codeword hashes and RX output were identical. Each no-fit case paid the 68-symbol header, 956-symbol body, 13-bit length and 16-bit CRC, recovered the explicit two-zero-bit NULL, and produced the fixed 0.5 float gray image. m10 WHOLE/PARTIAL fallbacks and failure guards also passed pure checks.

No neural inference, source encoding, image metric, resampling or training was performed. Three existing image archives were hash-verified and reused from identical RX inputs; no new neural replay is claimed. These finite noiseless-input/40 dB demapper checks establish targeted implementation behavior, not a new noisy reliability or image-quality result. Original N1024 formal results used the historical error-on-no-fit implementation and contained no no-fit events.
