# ARPC：固定 100 源匹配比较

本轮完成官方适配权重的独立接收资格、有限候选的完整 cal1000 校准，以及冻结策略后的 external_common100_v1 测试。测试共 900 个逻辑方法帧：100 源 × 4/10/19 dB × 每源三次噪声。所有失败均计入分母；比较单位是先平均三次噪声的来源。

五种方法使用相同的 100 个 source ID。NeST-Com 19 dB 采用 T1-C m10 修正版；P100k、Swin200k 和 BPG 的既有逐源分数直接复用。此结果不代表整个 common500，也不称为新的盲测。

## 冻结策略与实际接收

每个 SNR 在两项预先提名的完整策略中，按 cal1000 的来源平均 DINO-L 选择；PSNR/LPIPS 不参与选取，测试结果不反馈选模。各源仍执行实际码长回退。

| SNR (dB) | 冻结策略 | 发送实际终点分布 | 接收状态 | 灰图帧 / 300 |
|---:|---|---|---|---:|
| 4 | e7_q2_r2-3 | 3: 129; 4: 171 | PAYLOAD_PARSED: 300 | 0 / 300 |
| 10 | e7_q4_r2-3 | 5: 300 | PAYLOAD_PARSED: 300 | 0 / 300 |
| 19 | e7_q6_r5-6 | 5: 12; 6: 288 | PAYLOAD_PARSED: 300 | 0 / 300 |

实际接收后审计发现 0 帧存在合法接收但信息不等于发送端的情况；真值只用于固定输出后的审计，没有纠正接收数据。原始逐帧文件同时保存发送终点、实际译出终点、接收状态和来源解析结果。

## 源码与成本范围

N=1024 个复符号，68 头部 + 956 正文，标称 Es=2。caption、caption 长度、视觉流、模式/边界/终止和对齐包含在实际源码载荷中；正文另外支付 13 bit 长度和 16 bit CRC。profile 经付费头部传输；不能装下时仍保留完整空帧及失败分母。

ARPC 使用原官方适配先验、BLIP caption、接收端独立文本编码与原采样配置。native TX/RX 在 leo 的已登记 GPU 与独立环境执行；评分使用原 H800 指标环境。原 mixed arithmetic、FP32/TF32 设置和权重身份均随登记披露。阶段墙时用于资源规划，含 I/O、初始化等开销，不能与旧共享 H800 计时计算速度倍率。

## 执行、限制与材料

A1 的初始 CUDA/NVML 身份失败以及工程 PHY 接收环境失败均保留；对应独立修订只处理身份或解释器读取范围；最终评分前的旧 BPG 名称映射遗漏也已修正并保留失败记录，评分未重复。成功科学调用未重复。各阶段实际退出、失败记录、完整账本核验和输入输出 SHA 随轻量发布提供；合成测试不计作模型实验完成。

本轮没有训练、新基线重评分、HiFi 恢复、额外功率/分层方案或完整 common500 ARPC 扩展。来源 bootstrap 仅生成一次：10,000 次重采样、seed 2026100701。其不覆盖训练随机性、历史选题和全部架构不确定性；历史基线噪声 seed 不完全相同，此处是来源配对。

图表在 ../final_figures_v2/，完整均值、配对区间与逐源记录在 ../a3_metrics_v1/。恢复备份依用户要求延期。正式交付须另核正常 Git 发布和远端 SHA。
