## 模型与不确定性

头部和所有正文组先在同一瞬时 SNR 下组合，再对固定块 Rayleigh 分布积分。概率按 dB 线性插值，两尾保持端点值；16/32 阶 Gauss-Legendre 对照只检查数值误差。尾部质量见 numerical_diagnostics.json，不能当作已测曲线。
正确、拒收和未检出错误独立计数。未检出/未知状态质量点值为 0，固定策略另报 [-1,1] 敏感性；这些范围不是统计置信区间。没有将错误接受评分为干净前缀。逐图 Q 负增量保留，未作单调化或截零。

## 分布与成本

uniform_vs_full_vs_8.csv 和 per_source_quality_gain.csv 给出均值、逐图增量与分布；decision_distribution.csv 给出 m/K/MCS 选择频率。quality_outage.csv 先对每源、每状态 Q 与阈值比较，再对概率求平均。
sender_cost_inventory.csv 按不同接收状态去重计数。八个配置可能需要多于八次生成；缓存命中率不等于新图上免费推断，CPU 查表耗时不是部署时延。
辅助 calibration 指标仅在完整原缓存存在时交叉报告；缺项不填零，ConvNeXt 未读取。全 1000 张统一最优单列为描述性参考，不替代 800 张选定的正式复核基线。

C 的工程门槛只决定 CPU 物理探针优先级，不代表实际图像收益、论文结论、相对 P 全面优势或 GPU 授权。旧 F1 的 UNCERTAIN 与旧 UEP/A1/A2 队列原样保留。
