版本：2026-10-28 / 设计稿 v1
用途：可直接交给 Codex 实施；本文是计划，尚未启动新训练或信道实验。
核验基线：daiqizai/var-comm @ 2f13240b9338c8e79f14d6087e221714d3259c6b

一、这次确定做什么

方案 A：保留现有 tokenizer、VAR 和图像 decoder，把源流组织与信道码块分开。
先做更细的实际码长装入和共享长 LDPC，验证可靠性与部分恢复；只有出现净收益，才研究码字内部的不等保护。

方案 B：保留现有粗尺度 token，冻结大模型，训练一个小型数字残差编码器。
新增表示通过嵌套量化逐步细化，提供比现有 VQ token 更密的合法端点，用真实熵编码长度做率失真评价。

二者可并行准备与小试。A 给出更强的数字链路参照，B 检验新增表示是否提高每单位源码的价值。
当前 WCL 稿与正式权重继续保留原版本；新结果成立后再决定进入本稿还是后续论文。

二、为什么安排这两条

已核验的 P3：
- 旧三块方案最佳 J=0.356429421，最佳已测单块 J=0.399495571。
- 三块减单块 PSNR=-0.491548 dB，LPIPS=+0.040215，DreamSim=+0.047263。
- 当前 32 源、TX 名义 2 dB、实际 0/2/4 dB、每点三次噪声只是开发试验。
- 旧三块在 2/4 dB 已全部完整恢复，仍落后；因此只改低 SNR 拒收规则不能解决全部差距。
- 三块独立恢复 C+B 的机制已成立，但全系统未获益，原研究按 NO_GO_STOP 闭合。

此前码长审计：
- 最佳三块信息长度为 398/119/119 bit，总 636 bit。
- 各块 13-bit 长度和 CRC16 共 29 bit，净源容量 369/90/90，总 549 bit。
- 平均 AC 码长 422.9375 bit，平均 padding 126.0625 bit，净源区利用率约 77.04%。
- 最佳单块信息长度 637 bit，净源容量 608 bit；平均 AC 码长 572.34375 bit，padding 35.65625 bit，约 94.14%。
- 这些 padding 位已经作为 LDPC 信息的一部分编码并发送，不能直接当作额外无线符号。

A 要回答：集中装入和长码字能否改善当前数字链路？
B 要回答：同样再给几十到几百 bit，新的渐进细化表示是否比原始 token 更有效？

三、两条路线共同固定的条件

1. 第一轮 N=1024 个复符号，头部 68、body 956；Es=2，总帧能量 2048。
2. 头部沿用实际两点映射 ±(1+j)，不是 68 个普通四点 QPSK 符号。
3. body 使用 QPSK，编码输出 n=1912 bit。
4. RX 只使用实收 profile、实收译码位和合法预共享模型，不读取源图 token 真值补齐上下文。
5. 第一轮仍使用 TX 名义 2 dB，实际 0/2/4 dB 等权；不同时扩展衰落、功率分配、重传和反馈。
6. 当前 32 源用于工程与小试，不能成为新方法的独立泛化证明。
7. 训练集、开发集、策略校准集、common500 分开记清身份。common500 已多次使用，称固定测试集，不称全新盲测。
8. 对真实无线结果，每源先平均三次噪声，再按源求均值和配对差；正式区间按源 bootstrap。
9. 新帧的载荷或几何改变后必须实际编码、调制、加噪、译码。旧 CRC 成败不能替代新 PHY。
10. 旧缓存只在模型、输入、实际解码内容和重建规则身份一致时复用。复用计数与新增调用分开。
11. 核心指标：
    A 的部署选择沿用 J=三个 SNR 等权的平均 DINOv2 cosine；
    同时完整报告 PSNR、LPIPS-Alex、DreamSim、CLIP-I。
    B 的训练选择以预定源率失真目标为主，不能看完结果再切换目标。
12. 记录实际 AC bits、全部字段、信息 padding、k/n、N、能量、失败状态及总体图像质量。
    利用率只是机制量，不能替代质量收益。

四、方案 A：共享长 LDPC、紧凑装填及有条件的内部保护

A.1 最终想形成的结构

少数可独立校验的源流共用一个长 LDPC：
- C：完整粗尺度 q<=m。
- A、B：同一边界尺度的两组 token。
- A/B 的熵概率只依赖完整 C；B 不依赖 A。
- RX 从同一个长码字得到信息位后，以局部校验决定能用哪些源流。

“同一个长码字”不自动产生 UEP。初版只称共享长码和局部恢复。
真正的 UEP 需要后续的可验证保护差异。

A.2 先建立两个单块控制

控制 S-fill：
- 使用原冻结模型、单一连续 AC 流、一个 LDPC、一个 CRC。
- n=1912，k=637，净源码容量 608 bit。
- 将边界端点细化到逐 token。
- 第一轮公开候选限制在完整 m4/m5 及其下一尺度的合法 raster 前缀。
- 上限包含 m5 的完整下一尺度，即 K<=36；端点重复时统一规范表示。
- TX 遍历候选的真实 finish 长度，按预定顺序选最深且能装入的前缀。
- 不把估计熵或从更长码流裁下的 bit 当作合法 AC 长度。
- 这与旧最佳 m5,K27 有目标候选范围和粒度上的差异；报告为更细的实际装入控制，不把全部差值解释成单一因素。
- 当前旧单块仍保留为参照。若 S-fill 指标反而下降，后续强参照采用预先校准规则选出的更好者。

控制 S-protect：
- 固定旧单块每源实际端点和实际 AC 载荷。
- n=1912 不变，从公开 k 候选 {512,544,576,608,637} 选满足 k>=b+29 的最小合格值。
- 每个 k 必须通过当前 Sionna 后端构造、无噪声往返和 rate-matching 资格核验；不支持的档位从冻结目录删除并记录。
- RX 通过实收 profile 知道 k，不能先读取块内长度再倒推 LDPC。
- 它把部分 padding 换成保护，不增加已发送源内容，不称语义 UEP。
- 此控制的主要证据是实际失败率和失败计入后的质量，不是利用率变高。

A.3 长码机制控制：保持旧 636 bit 信息内容完全相同

使用旧最佳三块的真实信息块：
- C 信息块 398 bit，原编码输出 1196 bit，对应 598 QPSK 符号；
- A 信息块 119 bit，原输出 358 bit，对应 179 符号；
- B 同 A。
- 连接三个信息块，总 k=636，统一编码为 n=1912，仍为 956 body 符号。

必须保持：
- 每源 C/A/B 的源 token、AC 载荷、长度、局部 CRC 和 padding 原样；
- 三个公共信息区边界为 398/119/119；
- 原 decoder、VAR 完成和 SEL/SEQ/ALL 规则一致；
- LDPC 译码器基础算法、迭代数及数值设置沿用当前后端。

RX：
- 解出 636 个信息位后按固定边界切开；
- 分别检查局部 CRC、长度和 AC 合法性；
- C 有效后才尝试依赖 C 的 A/B；
- 不设置新的外层 global CRC；
- 不以整个 LDPC 码字的 syndrome 通过作为所有局部数据可用的前提；
- 保留实际 hard 输出，按局部校验判定，并记录 LDPC 收敛状态。
- 不用与真值比较来决定是否接收；真值仅供离线错误审计。

同一物理接收记录回放：
- ALL：全部启用源流有效才重建。
- SEQ：C 有效，按启用顺序连续使用增强流。
- SEL：C 有效，使用每个通过局部校验的 A/B。

本步只隔离“三短码变一长码”，旧 padding 尚在。即使没有超过强单块，也可以完成接下来低成本的紧凑装填检查。

A.4 紧凑装填：固定 k=636，真实计费目录

第一版只用 m4、边界 L=25，K=0...25。
- C 传全部 q<=m4。
- A 传边界 [0,floor(K/2))。
- B 传 [floor(K/2),K)。
- 位置和 K 从 profile 读取，采用固定公开顺序。
- 26 个 K 加 NULL 即可表示本模式；总 profile 目录还应计入其他控制、k 档和模式，冻结前确认不超过 4096。
- 不用 12-bit profile ID 免费传任意逐图源码长度。

信息区语法：
- 固定位置目录：ell_C、ell_A、ell_B 各 10 bit，后接 CRC16，共 46 bit。
- C：实际独立终止 AC 流，后接局部 CRC16。
- A：实际独立终止 AC 流，后接局部 CRC16。
- B：实际独立终止 AC 流，后接局部 CRC16。
- 剩余位置统一放尾部 padding。

三个 10-bit 长度足够覆盖 k=636 内的长度范围。
目录 CRC 输入绑定实收 profile ID 与三个长度；各局部 CRC 输入绑定 profile ID、流角色、该流长度及实际 AC 载荷。公开上下文字段不重复发送，但收发必须采用相同定义。
字段总开销 = 3*10 + 16 + 3*16 = 94 bit。
净源容量 = 636-94 = 542 bit。
旧三流字段开销 87 bit；此目录方案多 7 bit。紧凑装入收益必须扣掉这 7 bit。

对每张源图：
1. 从缓存 CDF 或合法 TX 前向得到各流概率。
2. 对 K=0...25 的真实分流逐个完成 AC finish，存 ell_C,ell_A,ell_B。
3. 在 ell_C+ell_A+ell_B+94<=636 的候选中按固定规则选择最大 K。
4. K=0 时 A/B 未启用、长度为 0，仍按约定保留字段；C 放不下则付费 NULL。
5. 不假定所有独立终止长度严格随 K 单调，不直接用二分搜索替代实际检验。

RX：
1. 实收 header 校验后选择 profile 和 k。
2. LDPC 输出信息位；先取固定目录并校验目录 CRC。
3. 检查每个长度范围、非空 C、总长度和所有起止位置。
4. 目录失败输出灰图。
5. 依据目录定位各流，分别做局部 CRC。
6. C 失败输出灰图；C 成功后按实际恢复的 C 一次性构造完整边界尺度 CDF。
7. A/B 分别取自身行解码，不用 A 更新 B 的上下文。
8. 局部 AC 解码后按同一规则重新编码并 finish，检查规范性。
9. 使用有效 token 重建；部分可用时按原接收完成规则处理。
10. 尾部 padding 不设置“一个 padding bit 错就全拒收”的额外全局 gate，否则会抹去局部恢复收益。
11. 不对未启用增强流的 CRC 成败作有效内容判定。K=1 时 A 未启用，SEQ 应越过 A 使用 B，不能把它人为算成 SEL 专属事件。
12. 接收通过但内容错误的事件必须保留、重建和计入；离线另记 undetected error。

为分清装填作用，保留同目录语法、固定 K=12 的紧凑控制。
对照“紧凑固定 K=12”和“紧凑逐 token K”时，字段、CRC、padding 判定与 LDPC 几何完全相同。

A.5 A 的最小实验序列

第 0 步：CPU / 缓存账目
- 复用 32 源，先算所有实际长度与合法 profile。
- 产出每源 endpoint、三流长度、字段、padding、源利用率。
- 检查最小 k、码率档与后端重复位限制。
- 所有源码必须从真实 Encoder.finish 得到，不从旧前缀码长相减推算新独立源流。

第 1 步：工程闭环
- 合格几何的无噪声往返。
- K=0、1、12、25 与最大目录长度边界。
- 修改目录、修改 A、修改 B、删除 C 等定向错误。
- 验证 B 的上下文只来自实收 C。
- 完整 CAB 重建与等价连续前缀逐 token/逐像素对齐。
- 新紧凑格式的失败规则独立测试，不把这些定向注错当无线统计。

第 2 步：无噪声质量
- 至少评估所选完整状态，以及可能使用的 C/CA/CB 状态。
- 与 S-fill、旧强单块比较，判断同一预算下源内容是否有实际质量价值。
- 干净 CAB 通常是重要参考，但不称各指标的数学上界；旧结果已出现删部分 token 后指标偶然更好的样本。
- 若源质量差距仍大、真实链路又几乎全通过，则停止扩大该候选；少量局部救回很难补偿这类系统差距。

第 3 步：32 源真实无线小试
最多 7 臂：
(1) 旧强单块；
(2) 旧最佳三短块；
(3) S-fill；
(4) S-protect；
(5) 同信息串共享长码；
(6) 紧凑固定 K=12；
(7) 紧凑逐 token K。

每臂 32*3 SNR*3 噪声=288 帧，总上限 2016 帧。
旧 (1)(2) 若身份完全一致可复用，最多新增 1440 帧；不能因为使用同一批源图就认定可复用。
ALL/SEQ/SEL 是同一物理事件的逻辑回放，不重复计入新物理帧。
新方法尽量共用登记的逐源/SNR/repeat AWGN 库；旧不同噪声结果只作源图配对。

第 4 步：独立于当前 32 源的开发确认
- 从 calibration1000 中固定选 128 源，不与当前 32 源重合。
- 最多 2 个新候选 + 2 个强控制。
- 128*3*3*4=4608 帧上限。
- 仍不作为 common500 正式结论。
- 若旧 cal1000 各样本有既往使用，公开其开发集性质，不称完全未见数据。

A 的继续条件：
- 真实源码和字段账目成立；
- 在预定 SNR 分布下，对更强单块参照有失败计入后的净质量收益；
- 若声称局部恢复有用，同一记录的 SEL 相对 ALL/SEQ 必须有对应可解释贡献；
- 不能只因为比旧三短块更好就扩到正式实验。
- 若目标变成降低处理时间，要另列相同部署条件下的时延目标，不事后混入质量结论。

A.6 可选后续：长码字内部 UEP

只在前述长码/装填机制有继续价值时做。
- 当前后端没有“token importance”参数。
- 先用独立的 PHY 校准数据确认信息位位置可靠性和错误相关性是否有稳定差异。
- 可以将目录与 C 映射到更可靠信息位；公开置换，RX 逆置换后仍按原协议解析。
- 比较同一 geometry、同一载荷、无置换/随机置换/可靠性置换；不用测试图像反复调位置。
- 若差异不稳定或端到端无收益，停止此扩展。
- 第一轮不同时改 Polar、非规则 LDPC、层次调制和功率。
- 标准等功率 QPSK 的 I/Q 位在 iid AWGN 下对称，换调制位位置不是 UEP。
- 普通 VQ token ID 的高位不是“轮廓位”，不按索引高低位宣称语义重要性。

A.7 预期论文价值

若只是 S-fill/S-protect 改善：属于更好的实际装入和保护控制，可改进基线与工程。
若共享长码 + 局部恢复在同预算下超过强单块，且保护收益被隔离：才形成更明确的通信机制证据。
不提前承诺对 Ada-TokenCom 或所有 SNR 的胜出；已有对照成功后再安排外部基线。

五、方案 B：训练可逐步细化的数字残差表示

B.1 第一版只做一个明确架构

固定 m=4。
冻结现有：
- 图像 encoder/tokenizer；
- 原多尺度 VQ codebook 与残差累加算子；
- VAR；
- 图像 decoder D_c。

新增训练：
- 残差分析网络 g_a；
- 残差合成网络 g_s；
- 小型二进制熵概率模型 p_phi。

不从头重训整套 VQ-VAE/VAR。
本版也不解冻 D_c；若后续解冻，要补同等训练机会的旧表示控制。

B.2 可在两端一致构造的基底

F_full：原冻结 tokenizer 的完整量化累计 latent，使用当前 D_c 对应的张量定义。
F_C：只用真实 q<=m4，经原 codebook、上采样、尺度残差算子累加得到的 coarse latent。
缺失尺度完全不贡献，不以“token ID 0”替代未知 token。
发送端和成功恢复 C 的接收端应得到同一个 F_C。

待编码残差：
r = F_full - F_C。

发送端：
u = tanh(g_a(r,F_C))。

接收端：
F_hat_j = F_C + g_s(u_hat_j,precision_j,F_C)；
x_hat_j = D_c(F_hat_j)。

j=0 时强制残差修正为 0，即 x_hat_0=D_c(F_C)。
网络不能在无残差比特时偷偷使用源 F_full 或图像相关特征。
第一版选择 direct F_C，避免为生成残差在 TX 额外运行完整 VAR 补全；它是否足够强，由实际 RD 曲线决定。
m4 基底弱是本 MVP 要面对的风险，不能用此前 m7 decoder 微调的正结果保证 m4 成立。

B.3 建议的小网络规格

- 若实际 latent 为 32x16x16，g_a 可用两次轻量下采样，把 r 与 F_C 的条件信息映射到 4x4x4，共 64 个标量。
- 若实现张量与上述不同，以实际 shape 为准，先在清单中冻结。
- g_s 从 4x4 的量化特征和精度 mask 上采样回 latent 空间，输出与 F_C 同形状的残差。
- 采用小型卷积/residual block，第一版新增总参数以不超过约 5M 为设计目标；运行前报告实际数量。
- 每个标量最大 4 bit，共 256 个二进制精化决策。
- p_phi 只依赖 F_C 和公开位置，给每个标量输出 16 个细量化值的概率，共 64x16 个概率。
- 根据当前标量已收到的高位前缀，对符合前缀的概率求和并条件归一化，形成下一位的 Bernoulli CDF。
- 这样一次条件网络前向就能支持全部位平面；不读取未传 r/u，也不建立一个大自回归模型。
- 不加入需要逐图传输的增益、均值、方差、latent 排序或 hyperlatent；若将来加入，重新计费。

这些是试验起始结构，不声称是最优容量或已收敛结构。

B.4 真正的嵌套量化

对 u_i in [-1,1]：
v_i = clip(floor((u_i+1)*8),0,15)。

v_i 是 4-bit 量化索引，但其前缀必须按已定义的嵌套区间解释。
已收到前 d 位、其整数值为 p 时：
u_hat_i(d) = -1 + (2p+1)/2^d。
d=0 时 u_hat_i=0。

固定发送顺序：
- 先发送全部 64 个标量的第一位；
- 再发送第二位；
- 然后第三位、第四位；
- 同一位平面内按固定公开位置顺序。
- 不发送任何未经计费的逐图重要性排序。

合法决策数 j=0,1,...,256，共 257 个候选，可在任何一个二进制精化决策之后合法终止。
RD 图固定展示 j={0,16,32,...,256} 的 17 个锚点，另评价真实预算选择的端点；不需要给每张图做 257 次图像 decoder 前向。
“一个决策”不等于实际发送一个 bit，更不等于一个无线符号。实际新增码长由 p_phi、算术编码和终止决定。
逐决策端点的实际码长间隔与原 VQ 逐 token 端点一起报告，不凭名称宣称分辨率一定更细。

这一结构保证量化区间逐步收缩，但不保证每张图的 PSNR/LPIPS/DINO 都单调改善。
报告已评估锚点及真实预算选中端点的平均质量；退化比例按这些已评估相邻端点计算，不声称覆盖全部 257 个端点。
普通现有 VQ ID 和普通 FSQ 不自动具备这个前缀定义。

B.5 第一版熵码流：只用一个 AC 状态与一个整体 CRC

为了避免每 16 个决策增加一套字段：
1. 在一个算术编码器状态中，先用原 VAR CDF 编码 q<=m4。
2. 不 finish，切换到新增二进制 p_phi 的 CDF，继续编码前 j 个精化决策。
3. 在合法 j 的编码器状态上 clone 并真实 finish。
4. 遍历真实终止码长，选择满足 b(x,j)+29<=k 的最大 j；j=0 也放不下时发送预定付费 NULL，不改变 m=4。
5. body 仍用 L13 + 单一已终止 AC 流 + padding + CRC16。
6. profile 公开指定 m、j、k/MCS 和固定的模型/格式版本。257 个候选不是 257 个独立短包；整个公开目录连同模型/格式与 MCS 组合须核验不超过 4096。
7. RX 从 profile 知道 coarse token 数和二进制决策数，在同一 AC decoder 中按顺序切换 CDF。
8. coarse token 实际恢复后才能构造 F_C 和 p_phi 条件。
9. 最终规范性检查重编码整个混合符号序列并 finish。
10. 核验现有 range/AC 实现是否支持同一状态中切换 4096 类和 2 类 CDF；不支持时先完成接口资格检查。

不能从最长 AC 码流截取前若干 bit 假装成候选。
本版的“渐进”指量化精度和合法源前缀；尚不承诺任意已发 bit 边界都能安全终止。
每个候选的末尾终止位可能不同，这适用于 TX 在发送前已知预算的任务。

本版采用一个整体 CRC：
- 成功则恢复所有所选信息；
- 失败按当前单块规则拒收；
- 不宣称能在任意残差 bit 出错后保留 coarse。
将来与 A 合并时，需要重新定义独立 AC restart、目录和局部 CRC，并重算开销。

B.6 训练目标与量化梯度

第一版失真项沿用当前已有配方尺度：
D_j = MSE(x,x_hat_j) + 0.1*LPIPS(x,x_hat_j)。

训练目标：
L = E_j[D_j + lambda*R_j]。
R_j 为新增二进制决策的可微率估计，单位固定为 bit/image；coarse 源码不随这组新参数变化，单独计入评价总码长。

可执行初始设置：
- 全局 batch=4，所有训练臂固定同一数据顺序和主样本暴露数；
- AdamW，初始学习率 1e-4，weight decay=0.01，梯度裁剪 1；
- 先采用 lambda=1e-5 bit^-1 作为预登记起点；
- 如有完整八卡且首轮闭环通过，第二预登记 lambda 可为 3e-5；
- 这些数值是起始方案，不是声称已调好的超参；任何改动均在开发训练/验证上决定并保留版本。
- 训练可用混合精度，但实际熵编码的概率转整数 CDF 和舍入规则固定；TX/RX 验证一致。
- 非零端点 j=1...256：取 j=256 的概率 1/4，其余 255 档均分 3/4。
- 每个训练 batch 只需一个采样端点和一次相应图像重建，完整端点通过采样得到锚定，不额外偷偷增加教师前向。
- j=0 是工程/评价点；因大模型冻结、修正强制为零，不把它当作有梯度的训练样本。

关键实现检查：
- forward 采用实际硬量化。
- 采用 soft assignment 或 hard-forward/soft-backward 二进制松弛，使率项能更新 g_a。
- 单纯把硬 bit 作为 BCE label 训练 p_phi，不能让 g_a 学会减少码率。
- 分别检查失真项和率项对分析网络的梯度确实存在、有限。
- 没有收到任何精度的标量在前向和反向都按常量 0 处理，不给未发送分量伪造重建梯度。
- D_c 的参数 requires_grad=False，但图像重建前向不能整体包在 no_grad 中，g_s 仍需要经过 D_c 的输入梯度。
- 训练率估计和实际 finished bits 都记录；选择与报告以实际码流为准。
- integer CDF 概率不得为零；精度、clip、累计和与解码端完全一致。

B.7 训练数据与旧资产

- 优先复用此前 19,968 张 ImageNet 训练子集的原图/token/latent 缓存。
- 先核对是否真的有当前冻结权重对应的 F_full；此前“8 个已完成 latent 端点”缓存不必然包含所需张量。
- 缺失时只补 F_full/F_C 和身份清单，不重复生成全部旧 VAR 完成图。
- checkpoint 验证集从已登记开发/校准数据固定划分，例如 200 源；排除与训练集的重叠。
- 必须明确这些 200 源属于开发集，不能又称用于最终独立评估。
- checkpoint 与 lambda 的开发选择目标固定为：对每源、每个净源码预算 {449,547,608} bit，选实际能装入的最大 j 并重建；三预算等权平均 D=MSE+0.1*LPIPS，越低越好。两训练臂采用同一规则，no-fit 保留预定灰图及分母。
- 策略校准 cal1000 仅在模型/候选结构固定后使用。
- common500 及 Kodak 不参与表示训练、lambda 选择或 checkpoint 选择。
- 若将来加入 Kodak，只作冻结后的域外评价，不能据其图像挑模型。

B.8 最小训练对照

F0：旧表示 + 原冻结 D_c + 现有强单块/更细合法端点。
F1：已有 progressive RD 的 D_c checkpoint 作为额外强参照，前提是权重、张量接口、训练身份可核验。
    该旧结果主要在 m7...m10 端点，不能预设对 m4 同样有效；没有兼容证据则写不可比，不强行复用。

R-scalar：相同 residual analysis/synthesis/entropy 架构，按逐标量顺序，先发一个标量的四位，再发下一个。
R-progressive：同架构，按逐位平面顺序，先让所有标量获得低精度，再整体精化。
- 两臂都按上述同一 j 分布做多截断训练，g_a/g_s/p_phi 都训练，D_c 都冻结。
- 两臂都允许 j=0...256；R-scalar 可在最后一个标量的当前高位前缀处结束，以免人为削弱对照。
- 同 seed 时用相同初始化规则、训练源顺序、优化更新数和 lambda。
- 这个对照检验“把有限精度先分配给更多残差分量”是否优于“逐个完成标量”。
- 相同决策数不等于相同实际 bit，比较时按实际源码预算选择各自合法 j。
- 两臂都胜过旧 token、彼此却无差异时，只能支持新残差编码有价值，不能声称逐位平面顺序是收益原因。
- 新结构相对旧 token 的收益，必须通过实际净码长下与 F0/F1 的比较判断。
- 若后续解冻 D_c，必须新增原表示+同等 D_c 适配控制，不能把 decoder 训练收益全算给新量化器。

B.9 B 的最小实验序列

B0：接口和码流闭环
- 先在固定的小训练子集上验证 shape、量化前缀、全部 257 个候选的真实 AC 和解码、j=0 和最大 j；图像重建只需 17 个锚点和实际预算选中点。
- 此处使用训练图做工程调试，不拿开发/测试图过拟合。
- 检查所有 profile、CDF 和模型版本由实收或预共享规则获得。
- 产出实际 bits / 估计 bits / 终止开销的分解。
- 确认当前 encoder、VAR、codebook、D_c 的参数 hash 未改变。

B1：有界短训
- R-scalar 和 R-progressive，各单种子 5000 更新，全局 batch=4。
- 共 10,000 更新、40,000 主样本暴露。
- 每 1000 更新固定开发集评估；不提前把 5k 试跑说成完整收敛结果。
- 先看多个真实源预算下的 PSNR、LPIPS 及 D=MSE+0.1LPIPS。
- DINO/DreamSim/CLIP-I 在少量预定候选/端点上作同步评价，不每步大量调用。
- 完整保存最新和按固定开发目标选出的 checkpoint。

B1 的继续标准：
- 合法码流和实际预算通过；
- R-progressive 在目标低/中预算区间相对 R-scalar 有可重复方向的优势；
- 与 F0 及可用的 F1 比较，存在值得继续的真实码长—失真或感知权衡；
- 若只有估计熵变好、实际码长无收益，不通过；
- 若 64x4-bit 最大端点都无法在目标预算提供有意义质量，停止此具体 MVP，分析原因，不能自动改成重训整个 tokenizer。
- 若尚明显未收敛，只能结论“该短训尚未建立收益”，不能否定整个研究方向。

B2：训练重复和有限扩展
- 只给有继续价值的设计及其匹配控制补第二 seed。
- 原 seed 如继续到 10k，两个训练臂同步继续；新 seed 按同一 10k 总更新完成。
- 两个 seed 的结果分别报告，再给平均；不把源 bootstrap 当作训练种子置信度。
- 首轮不增加更多 bottleneck 宽度、粗尺度、codebook、损失组合的大网格。
- 若要加第二 lambda，在预先登记的小配置表里做，不看 common500 决定。

B3：从源码 RD 接到真实无线
- 首先接现有单长码 body，全局 CRC 与失败规则保持一致。
- 固定 N1024、n=1912；首轮拟合 k={478,576,637} 三档，分别对应净源码容量 {449,547,608} bit，各几何须先资格核验。选择这三个预算是为覆盖当前 coarse 加小 residual 的低/中码长范围，不把名义码率取整当作精确几何。
- 对每张图用真实总 AC 长度 b(x,j) 做端点选择，不能给每方法固定相同 j 就当同预算。
- 某个预算连 j=0 的 coarse C 都放不下时，发送预定付费 NULL，按灰图计入；不减小 m，也不省略该图。
- 实际较小预算（例如 N512）需要重新确认粗尺度是否可装入，本版不默认 m4 在 N512 可行。
- 先用 128 开发源、0/2/4 dB、每点三次噪声，与强单块比较。
- 源码增益在无线侧被失败或开销吃掉时，应如实停在源码研究结论。

B 的正式研究问题：
“给定相同 coarse 表示，能否学习具有密集合法端点的 residual code，使固定数字帧下的实际 RD 更好？”
若还要声称信道自适应，必须进一步证实 endpoint/MCS 的选择带来实际无线收益。
第一版源训练本身不构成端到端 JSCC 或已经完成的 channel-aware tokenizer。
