# 尺度内部分传输与残差观测引导：执行方案

用户于 2026-10-02 授权依次完成两个方法，并补充 K 按 SNR 校准、显式计费 oracle 掩码、按真实预算递减的残差 oracle 梯度。本方案覆盖这两项，新增神经网络训练为零。此前停止条件由本次明确授权扩展，旧队列保持停止。

## 仓库一直在研究什么

目标是在单次发送、固定复符号数 N 与可核对能量、无重传的低码率图像传输中，比较生成先验带来的语义/感知收益和像素失真、失败后果、接收计算代价。它不是一个已证明全面领先的 VAR 系统。

早期 prefix/full-VQ 消融证明，收到同样粗尺度 token 时，VAR 补全比只解码前缀更能保留 DINO/LPIPS。随后的逐尺度信道译码、CRC 失败回放、熵编码与整帧对照说明，CRC 成功率不能代替全体失败计入后的图像质量。WeTok、重编码、数字基图加连续增强等训练支线产生过局部增量，但部分没有越过强数字/连续参考，失败结论需保留。

9 月中后期建立共享视觉接口：冻结 Encoder 提取 F（32×16×16）；十尺度 VQ token 使用 4096 码字、每个 raw index12bit；VAR 根据已收到尺度补完后续尺度；输出使用共同冻结 Dc。连续 P 在同 F 上训练通信收发模块。数字类标签从早期免费信息修正为收费头并与无条件分开。严格精度、真实 PHY、源图配对和失败全计分也逐步补齐。

接收后验探针先对有噪 F 使用逐尺度距离加先验，再检验真实 P 接收 latent。N4084 常规 SNR 下策略选择旁路，训练范围外曾有局部收益；P_low 重训和 N512/N1024 插件结果均未建立常规增量。N512/N1024 的新匹配连续 P 都达到40k预算上限，仍改善且未宣称收敛。N1024 U-QPSK 的 DINO 优势仅在1/4/7dB成立，13/19dB未建立，PSNR/LPIPS/F 仍有代价。

实现证据位于 `src/var_comm/next_scale_prior.py`、`scale_channel.py`、`experiments/var-latent-enhancement-20260917/src/latent_enhancement/latent.py`、`experiments/rx-posterior-step1-20260929/` 与 `experiments/extreme-bandwidth-20261001-N1024/`。新代码只复用冻结资产和这些已核对基础设施，不覆盖历史结果。

## 方法一：先分离细粒度载荷与排序贡献

五方案为整尺度、光栅部分尺度、共享随机序、熵序、带付费掩码的 oracle。主实验无类别条件；N512/N1024、QPSK/16QAM、SNR1/4/7/13/19。原始图像、校准/开发划分和三噪声种子沿用。随机序只依赖收到的前缀与公开常量。

新头保持68个QPSK复符号，用3bit表示整尺度数、7bit表示K、2bit表示排序。K0是整前缀，K>0使用前缀与部分尺度两段独立 CRC16+tail6。长度和保护分配由收到的头与公开公式推导；oracle 在部分包内另发下一尺度长度的位图。各段有效码率不超过.9。N1024/16QAM允许完整m8作为强整尺度控制，因为它本来就装得下，不能只与旧候选域m4–m7比较。

没有反馈时，发送端不知道接收端CRC是否通过。因而熵序失败不改成光栅解释同一payload：前缀失败时各臂都弃用部分段，保留同样的未验证hard prefix；头失败输出灰图。误接受、实际错序、部分丢弃分别记录，CRC通过不能被当作前缀正确。

VAR 的同尺度输出在模型分解中是位置独立的；先算全部概率，再固定收到的位置、生成其余位置，随后更新更细尺度。主实验沿用argmax，不能称为后验采样；该分解也不是对真实图像分布的精确性证明。熵排序使用完整4096概率、确定性数值协议及索引打破相同熵。独立两端的顺序必须逐项复现。

每档 SNR 在校准集独立选 K（允许0）。先用原1000校准源中的固定前200、一个登记噪声对全部合法网格做筛选，再对冻结短名单使用全1000及三噪声完成选择。筛选与最后选择都不读development。独立政策比较之外，强制给出熵策略相同m/K的光栅、随机对照；oracle只在计费后合法时加入。源码中的排序未必对应最终图像最优，因此 oracle 是有真值的诊断参考，不是严格性能上界。

源表示码率曲线与真实噪声链路曲线分开。额外符号也可能提高纠错保护，不能一概称浪费容量。只有实测支持才能说高SNR饱和得到缓解或熵序有独立贡献。

## 方法二：先检验预算、降维和噪声之后剩下多少收益

按顺序完成全维8×8无噪声、空间/逐位置通道PCA降维无噪声、相同降维加目标SNR噪声。固定m4前缀与原坐标残差；PCA仅在原校准残差上拟合共享通道投影，不混合不同空间位置。全维8×8×32等于2048实数，单独就需1024复符号，清楚标为免费侧信息oracle，不能算N1024可行链。

正式计费保留头、数字前缀CRC/tail、保护率、幅度控制和模拟测量。超预算工作点明确记NOT_FEASIBLE。只在预登记的预算可行、加噪声校准结果达到PSNR/LPIPS联合增量并保住DINO时，继续真实数字/模拟链。门槛与维度网格见 `protocol.json`。未过则完整交付oracle梯度和停止证据。

实际混合链的68符号头只表示固定m4和已登记投影，不携带真实类别。幅度系数使用32bit浮点值，向下取整后经过CRC16/tail6保护，占32个QPSK复符号；另付1个模拟符号补齐每帧能量，接收端不利用它估计幅度。收到的幅度及恢复观测若无法用规定精度有限表示，与校验失败一样弃用模拟信息，并记录原因。

逐位置通道投影保留局部计算接口，但官方量化器的bicubic与3×3 Phi卷积使完整观测对token仍有空间耦合。实现保留实际前向算子和偏置差分；未知后续残差只能用校准统计建模。报告称为 Gaussian 工作似然/复合引导，不称精确独立后验。控制含不引导、仅似然、静态先验、VAR先验及直接残差校正，避免把任何连续信息的收益都归于VAR。

具体计算在每个尺度使用校准的逐坐标均值与单个各向同性方差，只做一次光栅坐标扫描，每个位置比较完整4096候选。VAR和静态先验的权重分别在7dB校准，跨其他SNR冻结。执行时先在校准集完成预算可行的加噪声门槛和全部政策选择，再在开发集按完整无噪声、降维无噪声、降维加噪声的梯度评测，最后评测获准的真实链路；无开发结果参与选参。

## 验收、交付与停止

先通过CPU真实协议边界测试和真实权重资格，核验K0与旧补全一致、TX/RX顺序可复现、clamp位置不变、无真值泄漏、完整帧N/E/CRC及超预算拒绝。冻结源码、模型、源图、参数与候选网格后后台串行执行。方法二须检查方法一完整交付回执，不与之抢GPU。

全体失败计入图像质量，F误差有效样本分母单列。源图内先平均噪声，再做10000次配对bootstrap。分别解释PSNR、LPIPS、DINO、F误差与计算，不按单指标胜出写全面优势。开发集已反复使用，区间不是新holdout或训练seed不确定性。

按方法交付主表、原始逐帧/资源数据、配对区间、固定样例、策略、完整TX/RX时间、与冻结P512/P1024的差距。必要仓库检查通过后正常提交推送，验证远端SHA；两方法及条件分支结束后停止。
