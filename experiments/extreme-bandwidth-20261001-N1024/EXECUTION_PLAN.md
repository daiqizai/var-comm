# 极低带宽验证修订版 R1：第二阶段 N1024

用户于 2026-10-01 明确授权本阶段。以下范围覆盖原 R1 的“N1024 留待确认”限制；其余规则沿用[第一阶段 R1](../extreme-bandwidth-20260930/EXECUTION_PLAN.md)。完成 N1024 报告、正常推送并核验远端提交后停止。

## 研究问题

确认 N512 中无条件数字 VAR 的 DINO 优势在 N1024 是否仍存在，并量化 PSNR、LPIPS 和原始 F 坐标平方误差代价是否减小。H_D 数字分工与 H_R 连续接收插件分别判定，不把单项指标获胜称为全面优势。

## 训练和选模

- 只训练一个全新 P1024。使用实际登记的 P512 初始化方式、种子 2026093001、结构族、原数据、损失、AdamW、精度、批大小与选模规则。只改变 N 相关瓶颈和收发形状；不截短旧模型，不载入 P_low 或其他通信模型权重、优化器。
- 沿用原 20,000 训练源图、1000 校准源图、100 development 源图及全部登记噪声种子；训练、校准、评测 SNR 均为 1/4/7/13/19 dB。
- 每 2500 步完整校准 1000×5×3，包括步 0。校准平均原训练损失最小者选中，并列取较早步。
- 20k 为首个里程碑。在 20k/30k，最近两个相邻 2500 步区间的损失相对下降均至少 0.002 时延长 10k，最多 40k。到上限仍改善时记录 budget_truncated，不宣称收敛。
- 真实 GPU 资格检查的试验更新丢弃；验证完整优化器及随机状态恢复后，从正式步 0 开始。

## 对照和接收边界

- 完整输出 P1024、无条件数字 VAR、付费类别数字 VAR、P1024+A1/A2/VAR。
- 数字动作分别在完整 1000 校准源图选择；插件在原 200 校准子集重估方差、参数和融合权重。不得复制 N512 策略。
- 保留原候选网格、真正 BYPASS、共同 A1 融合权重消融、固定 lambda=1 与未选原始诊断；不新增参数搜索。
- 所有主结果共用同一冻结视觉 Encoder、F、Dc。D0 只渲染同一次接收的同一 latent，不重新选择动作。
- 插件共享 P1024 的同一波形、一次 AWGN 观测和接收 Fhat；不加第二次 latent 噪声，不使用未发送真值。
- 头失败保留灰图且无实际 Fhat，所有质量统计保留失败；F 误差仅在实际有效估计上统计并报告计数。正文 CRC 失败保留不可信硬判前缀，不用真值修补。

## 数字账本和能量

- N=1024：头 68 次、正文 956 次。候选 m4–m7 的 raw 前缀为 360/660/1092/1860 bit；CRC16、tail6、rate-matching 均计费。
- 按原合法编码与有效码率不高于 0.9 的规则，QPSK 允许 m4/m5/m6，16QAM 允许 m4/m5/m6/m7。
- 两种 PHY 分别登记、分别校准、分别报告。C/U 独立按原可靠性参考、PSNR 容差 0.25 dB、LPIPS 最小规则选 m；同动作同前缀 C/U 诊断分离类别贡献。
- QPSK 与连续链逐帧 E=2048。16QAM 保持原固定星座缩放，单列实际能量分布；不新增归一化或事后混合调制。

## 统计、图表与报告

- 逐源先平均三个登记噪声重复，沿用 10,000 次 bootstrap、种子 20260930 和点态 95% 区间。H_D/H_R 阈值和共同质量分支规则保持。
- 输出完整主表、配对差值与区间、失败计数、固定源图 0/25/50/75 在 4/13 dB 的样例、校准策略、接收延迟和代价。
- 比较 N1024 与原 N512 的数字减连续基线差值变化，逐项报告 DINO、PSNR、LPIPS 和 F 误差，另列类别与 16QAM 贡献。
- 复用 N512 实际 40k 结果及兼容的 P2048/P3060/P4084 已测点，画固定符号功率下的质量—资源曲线。不得为图表重跑历史实验或填补未测点。
- 保留 N512 的 budget_truncated 说明；复用 development 的探索性证据不称独立新测试，也不覆盖训练种子方差。
- 报告必须回答 VAR 插件是否在同一质量分支同时超过 P1024、A1、A2；选择 BYPASS 不计独立增量。

## 执行和停止

所有新代码、登记、输出位于独立 N1024 目录。源码检查和真实资格通过后，后台顺序执行训练、源参考、数字校准、插件评测、数字评测、历史兼容检查、分析和正常 Git 提交；未知失败保留证据并停止。

不继续训练 P512，不启动 N256/N128、生成模型微调、新 loss 或旧队列。本阶段报告提交完成后停止，等待用户下一步决定。
