# 已完成历史方法的统一补充评测

用户在2026-10-03将范围收窄为论文必补项目，并随后明确选择“必补完成后补第5、6、8项”。本扩展只执行该筛选清单，保留原模型、选模记录、策略、数据、噪声、调制、解码器和资源账本。训练更新和策略选择次数均为零。

## 范围与完成标准

`queue_registration.json`冻结执行名单、必补优先顺序、源码和证据；`coverage_manifest.json`逐项登记原方法、来源、图像缓存与精确行数。完成仅指用户筛选范围，不代表全部历史探索都补评。

必补：最终P2048/P3060及两个独立P4084选定版本；N2048/N3060/N4084的已有最终数字策略（QPSK与16QAM分开）；Phase2严格精度N4084最终数字策略；早期N3060数字/感知DeepJSCC最终对照；SwinJSCC/ADJSCC已完成点；同一冻结视觉接口的无信道参考。共46,800行。

随后补：P4084与P_low在−5/−2 dB的基线及A1/A2/VAR主策略；H6-V/P第一seed、N4084、13 dB；Phase2原m8+1024、冻结资源策略及当时的pure10k控制。共9,900行。旁路及严格相同浮点图像复用评分。

排除第7、10、12–16、18–20、22项；不重训极低带宽外部基线，不运行其他旧队列。

现有N2048数字点是付费类别D_C，旧协议raw头70符号，不能重标为当前D_U或68符号协议。兼容D_U的N2048仍作为未测空缺保留。曲线不跨解码器/类别条件拼接，不插入或外推未测点。

原六项研究 N512、N1024、M1、M1_RATE、M2_ORACLE、M2_ACTUAL 继续由原流程完成。本扩展等待它们及已登记的恢复记录全部校验、推送和退出。原 N512 的 40k 结果及预算截断说明保留。

## 图像与指标

- 有原始浮点重建缓存的，核验原回执、文件哈希、图像位置、原图身份和原指标后使用。PNG 预览不能代替浮点科学输出。
- 无浮点缓存的，从原选定权重与冻结策略调用原推理函数。逐帧核对原指标及可用的通信记录；不调用旧训练、校准或队列主程序。
- 新指标复用原统一评测的冻结模型、权重、预处理、精度与批次资格规则：DINOv2 ViT-L/14、CLIP ViT-L/14、DISTS、DreamSim、MS-SSIM，以及独立ResNet-50 ImageNet1K V2的真实标签准确率与原图预测一致率。原DINO是DINOv2 ViT-S/14，原LPIPS是AlexNet v0.1；原PSNR、LPIPS、DINO及其他已记录指标保留。
- 新指标列使用 `new_` 前缀。每一行的原字段、原行哈希与重复次数保留；完全相同的重建浮点像素、目标像素和评测模型身份可以复用新指标计算，不能仅根据方法名、均值或 PNG 相似性复用。
- D0 参考、同 Dc 的主结果、类别条件、oracle、旁路及消融分别标注。使用真实类别的生成结果不作为分类准确率的主要证据。

## 统计与比较

每种方法沿用原开发集与登记噪声重复数。先对同一源图的噪声重复求均值，再按源图进行 10,000 次 bootstrap，种子为 20261002。配对比较在计算新指标前登记，只允许原图浮点身份与源图集合一致的组配对。原物理 SNR 和等效 SNR 分开；不同预算、调制、解码器及参考条件保留在表中。

无信道每种输出100张，合计18种参考，不复制噪声重复。17种是旧标量重放，m8无类别补全是新确定性推断，通过独立重复图像一致性验证，明确不伪称旧指标存在。新生成的浮点RGB按源保存并绑定逐行身份，以后补指标无需再次重解码。

原六项研究的已完成统一结果以其核验后的输出索引引用，不填补未测点。KID/FID 继续遵循原最终大样本评测安排，不将这里的少量重复帧当作独立大样本。

## 执行与交付

后台入口为 `history_controller.py --root ROOT --queue-registration PATH`。它核对原流程完成与所有登记进程退出，待 GPU 空闲后发布本扩展源码，再依次执行每项补评、汇总和结果发布。

每项评测必须通过真实首源的原结果一致性检查，之后按源图保存可校验断点。CPU 夹具测试只证明工程行为，不代表真实图像评测通过。任何身份、覆盖、原结果或源码校验失败都会停止并保留证据。

交付包含逐帧新列、源图均值、均值区间、已登记的配对区间、方法覆盖清单、原六研究索引及中文报告。只提交审查后的轻量文件；大 CSV 按原字节分片。发布使用当前唯一主仓库，正常提交与推送并核验远端提交。完成登记范围后停止。
