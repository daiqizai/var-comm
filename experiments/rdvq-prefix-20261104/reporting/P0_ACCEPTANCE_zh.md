# P0：真实码流、接收隔离与训练资格

P0 已通过，允许进入本次独立 RDVQ 研究的 P1/P2。这里的通过指明确测试范围内的接口和数值资格，不代表新训练方法已经有效，也不代表所有硬件可互通。

## 已实际完成

| 检查 | 实际证据 |
|---|---|
| 公共初始化 | `lam_4.8_tau_0.1.pt`，1,007,856,193 字节；SHA-256 `827aaab038626bb306fc30fac37634eece418dd02bd4617f88e65d8d19e92294`；547 个原生模型状态项严格加载 |
| 源编码 | 固定前 8 张开发图，每图一次 E；每图全部 28 个原生 slice 前缀分别终止，共 224 个非空源包 |
| 独立接收 | 另一个进程从公共源包恢复 224 组已收索引并补全、重建；8 个 NULL 输出固定灰图；事后逐一核对已收索引完全一致 |
| 输入边界 | RX 不读取源图、TX 索引、未发送 suffix 或 TX 内部状态；补全使用已收前缀和公共冻结模型 |
| 四指标资格 | 原生浮点重建的 232 对 DISTS、DreamSim、PSNR 和 LPIPS-Alex；后续仅在像素和完整身份一致时复用 |
| 训练梯度 | E/D/P 有有限梯度，码本冻结；所有资格更新丢弃，P2 仍从同一公开权重开始 |
| 保存恢复 | 原生状态导出键名、形状及 dtype 对齐；完整训练状态恢复最大差 `1.1920928955078125e-7`，通过预定 `1e-6` 容差，非逐位相同 |
| 可运行 batch | 单卡 microbatch 4、累积 4 次、有效 batch 16；资格阶段暖态约 4.82–4.94 s/update，峰值分配显存约 24.635 GB；这是吞吐资格，不是正式公平系统计时 |

源包封装固定收费 72 bit（版本/端点、两条流长度与 CRC32）。每条非空 rANS 流自身的终止状态已计入码流字节；不另外免费传输边界。NULL 包收费 72 bit。全部候选使用独立终止后的实际字节数，不把较长 rANS 流任意切割，也不套用旧 NeST 算术编码器的码长性质。

## 原失败与独立修订

1. 首次原生 CPU 扩展构建缺少匹配的 `Python.h`。原失败保留；私有依赖区补充 Python 3.10.12 头文件后，独立 `cpu_codec_headers_v2` 通过。共享环境和上游模型代码未修改。
2. 首次 GPU 源编码在模型前失败：该主机的 NVML UUID 与 CUDA runtime UUID 不同。保留原实际退出 1；独立 v2 使用数值设备索引和 PCI 顺序，并核对设备身份。此前未成功执行的模型调用没有伪装成复用。
3. 首次训练资格在第一次 optimizer 更新之前因确定性模式不支持原生 bicubic backward 失败。独立 v2 明确采用原生数值路径并记录容差恢复；不声称逐位训练确定性。共 8 次成功的资格 optimizer 更新均被丢弃。
4. 首次指标加载因模块父路径缺失失败，实际指标调用为零；独立 v2 完成全部 232 对。原异常字节和各自登记均保留。
5. 资产下载期间的网络与依赖导入失败单列，不能混同于图像解码失败率。固定 22,500 个数据身份最终已经完整验证，没有换图或缩小分母。

P0 已登记 GPU 进程实际收费 0.08183870269 设备小时；加上两次 CUDA 可见性诊断，保守合计 **0.08347030765 GPU 设备小时**，低于 16 小时上限。CPU 与 GPU 使用量分开记录，父进程的含子进程 CPU 用量不能再次叠加。

## 新 PHY 的准入边界

本研究另行建立动态 MCS 头：64 个受保护头符号，头部承载版本、MCS、源包字节长度和 CRC16；主体容纳已经含 CRC32 的源包。接收端先恢复头信息，再解码主体，不免费获得 TX 的逐帧 MCS 或前缀。

原资格计划包含 72 个全帧测试，完成 68 个后遇到 `N=2048`、64-QAM、rate 3/4 的单码块信息长度上限；更高码率未执行。原任务实际退出 1，不能写为 72/72 通过。已成功的 **N=512/1024、12 MCS、48 个完整帧** 经单独范围核对后用于 P1；没有重跑成功帧。N=2048 高码率适配保留为未完成项。

P1 后续的 14,400 帧是实际校准无线帧；源编解码的所有前缀重建不是新增无线帧。条件控制器报告还必须区别于正式测试集上的实际无线评测。

## 当前限制

- 共同初始化来自作者公开联合 RD 权重；没有公开中间 optimizer/discriminator 状态。本次是声明过的共同微调路径，不是完整重放作者训练。
- 训练集有一对完全相同的原生像素，保留相同 ID 暴露规则供各臂共享；跨新划分没有完全相同的像素。近重复及上游预训练图像级排除未获证明。
- 本批只执行 P0–P2。新表示的有效性须由同数据、同初始化、同训练量的 R3–R2 对照，以及实际比特预算和完整表示结果共同判断。

对应逐项原始回执、哈希和命令由 `p0_gate.json`、`resource_snapshot_p0_v2.json`、`retained_failures.json` 和复现索引提供。
