## 1. 统一观测模型（任务 A、B 共用）

直接在同一个 F 上加噪，**不做 PCA 截断，不考虑增益头信息**：

$$Z = F + \sigma \odot n,\qquad n \sim \mathcal N(0,\ \eta^2 I)$$

- F：VAE 编码器输出的连续 latent，形状 32×16×16，与现有 Dc 使用的 F 相同。
- $\sigma$：在校准集上逐维估计的标准差。噪声大小与各维尺度成正比，与真实链路"标准化 → 线性模拟传输 → 零强迫估计"后的噪声结构一致。

**等效信道 SNR（近似）。** 在 1:1 线性模拟传输下（N = 4096 个复符号对应 8192 个实数维），校准分布上标准化后的集合平均能量为 2N（未逐帧归一化），每个实数维的噪声方差约为 1/SNR，因此 $\eta \approx 1/\sqrt{\mathrm{SNR}}$。

- 执行前必须按项目实际的 SNR 与能量约定核对这一换算，如有出入按实际约定重算。
- 该换算忽略了 N4096 与 N4084 的差别，以及增益头信息，与 P4084 的比较只能标注为"近似"。

## 2. 任务 A：Oracle 上界（半天，可与任务 B 并行）

**在标准化坐标下逐维融合：**

$$\bar x = \frac{x_q/\rho + z/\eta^2}{1/\rho + 1/\eta^2},\qquad \bar F = \mu + \sigma \odot \bar x$$

其中：
- $x_q$ 是真实 Fq 的标准化值；
- $\rho$ 是 $(x - x_q)$ 的方差，在校准集上按 32 个通道分别估计；
- $\eta^2$ 是观测噪声方差（见第 1 节）。

| 编号 | 内容 |
|---|---|
| B1 | LMMSE：$\hat x = z/(1+\eta^2)$，输出 $D_c(\mu + \sigma\odot\hat x)$ |
| O1 | 以真实 Fq 作为先验均值融合，输出 $D_c(\bar F)$ |
| 参照 | 第 0 步摘录的 P4084 在 1 dB、4 dB 的结果（近似匹配） |

- 等效 SNR：−5、−2、0、1、4、7、13 dB。
- 数据：100 张 development × 3 个噪声种子。
- 指标：PSNR、LPIPS（alex）、DINO；在源图上做 10000 次配对 bootstrap。

**天花板判定：**
- O1 相对 B1，在 ≤1 dB 的 4 个点中至少 2 个点上，同时满足 **ΔLPIPS ≤ −0.02** 且 **ΔDINO ≥ +0.02**，置信区间不跨 0；
- 同时，1 dB 时 O1 在 LPIPS 或 DINO 上至少有一项优于 P4084（近似匹配）。

**不通过则整个方向停止。**

## 3. 任务 B：逐尺度消歧探针（2 天）

### 3.1 噪声档位按 token 难度选定

- 在校准集中预先固定的 200 张子集上，给定真实前缀，测量"无先验最近码字"在细尺度（第 8–10 尺度平均）上的 token 准确率。
- 选出 4 个 $\eta$，使该准确率分别约为 **90%、70%、50%、30%**。
- 同时记录每个档位的等效 SNR。
- 保留已在原 200 张校准子集上选出的四档：30.6、20.2、14.6、10 dB；另加目标区间 4、1、−2 dB。额外 30 dB 仅用于 TF 相对诊断，不计入 M1–M3。
- 每档的模糊带由同一 200 张校准子集 × 三噪声 seed 上 A1 的 TF 准确率落在 [20%,95%] 的尺度确定，含端点；仅使用 1e-12 的 float64 归约容差。尺度集合在 B-development 前冻结。
- 档位和全部 B 参数写入 config 并冻结后，才能读取 B-development；任务 A 按用户明确要求先运行，其结果不参与 B 校准。

### 3.2 逐尺度打分

对第 k 尺度（pn ∈ {1, 2, 3, 4, 5, 6, 8, 10, 13, 16}）的每个位置 j、每个码字 t：

$$\text{score}_{k,j}(t) = \lambda \log p_k(t) - \frac{\|r_{k,j} - c_t\|^2}{2\sigma_k^2},\qquad r_k = \mathrm{down}_k(Z - \hat f_{<k})$$

- $\mathrm{down}_k$：与 VAR 编码器相同的面积插值；pn = 16 时不下采样。$\hat f_{<k}$ 的累积方式与官方 `get_next_autoregressive_input` 一致。
- 固定版似然方差只含噪声项：$\sigma_k^2 = \sigma^2_{noise,k}$（删除 $s_k^2$）。噪声趋于 0 时，严格退化为最近码字。$\sigma^2_{noise,k}$ 是 $\mathrm{down}_k(Z-F)$ 的方差，仍在校准集上估计。
- 用于 M1–M3 的 A2/V 固定 β=0；仅 λ ∈ {0.5,0.75,1,1.5} 可校准。两者使用相同流程：每档在固定 200 张校准子集上最大化真实前缀准确率，按冻结模糊带尺度等权、三噪声和源图等权平均。精确并列取最小 λ；空模糊带时 λ=1 且该档 M1 不适用。
- β>0 的四档 {0.05,0.1,0.2,0.5} × 同一 λ 网格，只按 TF 第7–10尺度平均真实-token对数概率拟合概率诊断。对数概率、熵和可靠性在相同的 β=0 决策前缀上报告，不改变 MAP、重建或 M1–M3。
- β=0、λ=1 固定参照一并报告。所有选择与每个接收方案的融合方差均在 B-development 前冻结。
- **只用 MAP**（逐位置 argmax）。本步不做采样。

### 3.3 三组先验（同一观测、同一似然）

| 编号 | 先验 $\log p_k(t)$ | 作用 |
|---|---|---|
| A1 | 0（无先验，最近码字） | 测量单纯的码本去噪 |
| A2 | 各尺度静态频率（校准集拟合，沿用第一关实现） | 排除"只是偏好常见 token" |
| V | VAR 无条件（label = 1000）完整 logits，不截断、不用 CFG | 测量跨尺度先验能否帮助消歧 |

### 3.4 两种前缀模式

- **TF（真实前缀，仅作诊断）**：第 k 尺度的前缀使用真实 token，逐尺度独立评估。这不是合法的接收端成绩。
- **CL（闭环，合法接收）**：前缀使用自己之前的判决结果。

### 3.5 指标

**逐尺度：**
1. TF 准确率；CL 的“与原真实编码 token 一致率”仅作附属诊断，不作为 M2。
2. CL 路径条件准确率：在接收端自己的前缀下，离线用干净 F 计算当前应选最近码字，再与 RX 判决比较；干净 F 只进入评分支路，不进入 RX 先验、判决或融合。
3. CL 原坐标 latent 平方误差 ||F−Fq_post||²。M2 的路径准确率按十尺度等权平均，另报 token 数加权值。
4. 真实 token 平均对数概率和后验熵作为机制/概率诊断。

**只对 V 组：**
4. 可靠性图——按最大后验概率分箱，统计每箱的实际准确率，并计算 ECE。

**只在 CL 模式下做重建，全部用 $D_c$：**
5. token 输出：$D_c(F_q^{post})$；
6. 融合输出：用 $F_q^{post}$ 代替真实 Fq，套用第 2 节公式，其中 $\rho$ 改为在校准子集上实测的 $(x - x_q^{post})$ 方差（按通道估计）；
7. 两种输出都计算 PSNR、LPIPS、DINO。

**统计方法：** 100 张 development × 3 个噪声种子 × 7 个判定档位，另加 30 dB TF 相对诊断；在源图上做 10000 次配对 bootstrap。主要比较为 V 对 A1、V 对 A2。

| 编号 | 判定内容 | 通过条件 |

**解释边界：M3 才是图像层面的实际检验。** 低 SNR 下细尺度准确率低，不自动否定粗/中尺度消歧或融合收益；是否接近随机水平必须看实测。Token 指标只说明机制，不能代替 M3。
