# 四臂同预算继续训练协议

2026-09-14制定，未激活GPU训练。本轮解释变量是更多匹配更新机会，不宣称训练日程本身是通信创新。

## 理由与对照

Joint full-grid innovation在5000时最强，且train/calibration仍改善；其它结构的最优完整校准点也在末端。当前4/8/16对普通全网格没有显著LPIPS/PSNR/时延收益，不能预先假设尺度优越，也不能用固定5000自动证明各结构充分收敛。

四臂：原Joint single、原Joint multiscale_state_history、新Joint full_grid_state_history、新Joint full_grid_innovation。保留multiscale匹配训练以区分训练长度/初始化适配与结构问题，不只给更喜欢的候选更多更新。旧no-history、R-only和所有系统参考完整保留，但不追加它们的训练，也不在10000阶段声称与其5000是同更新机会。

## 不变条件

- 各臂从实际5000末端`models`和`optimizers`恢复；共同更早父点仍为原7000 single。已有选中点恰为5000不构成重置optimizer的理由。
- AdamW全部moments和step5000保留，继续1e−4、betas(.9,.99)、weight decay1e−4、clip1；不重置、不同时改lr/loss/温度。
- 每臂新增5000更新，原续训总步数5000→10000；数据global12000→17000。首个新完整里程碑7500，下一10000；不是从global7000再次抽取已配对旧数据段。
- 原20k训练源/两个视图、1000校准、1/4/7/13/19 dB，所有新臂共享数据/增强/SNR/标准噪声。有效batch4/micro1，FP32，冻结视觉Encoder/量化器/Decoder及指标网络。
- MSE＋0.01LPIPS＋0.01bit BCE＋0.01state，GT state仍来自实际Fq的平均池化，接收历史来自自身。DINO不进入训练或选模。
- 原Fq输入、continuous_mean输出、N3060/E6120、0 header、实噪声1/γ，无类/caption/反馈/测试真历史。不同学习发送器不要求同y。

## 保存与选择

起点5000已有完整校准，不重复GPU校准；继承各臂截至5000的合法选择与历史。新增每500更新固定100图监控，7500/10000全1000图校准；监控不参与选择。完整校准LPIPS最小、同值取早，旧5000点可继续被选择，必须如实披露。

断点保存四模型/四optimizer、完整数据位置、实际噪声/批次fingerprint、frozen身份、源码/配置与实际运行成本。必须先保存完整的四臂同一步，避免中断后不同臂处在不同更新数。

## 实施与停止解释

先完成CPU模型/Adam加载、数据接续与小型真实driver中断等价测试；这是实现自检，不要求未训练方案先在质量上胜出。旧forward/VJP完全复用，只接续状态，不重写已冻结模型。

预计四臂新增5000含关键全校准约3–4 GPU小时，以真实速度修正，不作为研发总预算上限。记录共享执行背景；质量与独立时延继续分离，不改设备设置或干扰其它任务。

首要比较为同10000机会下multiscale对普通full-grid，及full-grid innovation对普通full-grid/single；另报告各臂相对自身5000的变化与强系统差距。额外训练收益不能归给新增算法，旧R-only只有5000机会需明确标注。

若train/cal改善停止或出现泛化/指标取舍，按证据更新计划，不无限重复同类训练；有强对照支持的机制再进入训练重复、鲁棒性和新holdout。本轮仍仅使用原development，当前没有研究完成证据。
