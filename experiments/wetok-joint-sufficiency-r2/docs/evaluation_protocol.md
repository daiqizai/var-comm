# R2同机会评测：续训效果不当成新机制

2026-09-14制定。当前训练仍按原协议到7500再决定10000；本文件只准备同10000机会的最终比较，不根据未完成的监控选择方案，不改变训练或任何旧结果。

## 人口、选择与信息

原100张development、七SNR、三噪声，新增四R2模型，保留Grid5000已封存的全部18方法。合计22方法/46200主行，其中8400新推理；新400与旧1100合计1500无噪名义19诊断，600固定支持Deep记录保留。

四个R2方法均拥有相同10000更新机会，模型从继承的0/1000/2500/5000及新7500/10000完整校准中按LPIPS选择。若选中旧5000，必须标出实际部署点，不能把它写成已获得新训练收益。旧18方法只有各自原训练历史，**与R2不是同10000机会**；它们作为自身5000锚点或系统级强参考，不用于重新宣称“只改变架构/E优化政策”的因果关系。

仍使用Fq 32×16×16、continuous_mean、N3060/E6120、0 header、实噪声1/γ、相同名义SNR及自身历史。不同E产生不同s/y，只配对源图、标准噪声和物理预算。DINO不进入训练或选模，新正式holdout不访问。

## 质量/资源与时延分离

沿用已验证的Grid质量机制：旧图像/分数/选择/源像素哈希和物理字段逐项冻结复用，仅新四模型推理；所有当前时间字段为空。显式共享质量模式采用相同8 GiB分配器上限及显存准入检查，不保证整体CUDA内存或算力隔离、不改MPS/驱动/时钟、不停止其它任务。

独立计时预先固定原32图、五SNR、噪声2001：新四R2加原11学习接收器共15模型/2400行。所有模型在该阶段共同轮换顺序，回放与质量一致的模型、s/y和图像；旧历史数字/Deep时间不放入当前排名。计时在GPU空闲时进行，资源竞争只暂停计时，不撤销质量。32图计时不与100图全噪声时间混排。

## 预先比较

四R2内部六个结构比较，以及新四对全部旧18的72个比较，共78组；八个SNR范围、六个原指标，3744条配对区间。主要结构对照是R2 multiscale state−R2普通full-grid state。单独列出四模型分别相对自身5000的变化，标为**额外训练效果**，不是新增机制。

对15学习模型与固定支持Deep的5/6 dB补充比较，共270条区间；不利用旧Deep离支持点异常制造优势。先按源图平均SNR/噪声再bootstrap，原10000次规则不变。普通迭代不改名next-scale，网格/阶段描述的剩余归因限制继续保留。

若终止在7500，不得直接把结果冒充本配置的10000机会比较；需先明确记录停止决定及新的评测范围。当前只是准备，未执行R2质量或计时。

## 独立计时实施

新四与旧十一模型共同计时，不复用历史时延；每帧循环移位15模型顺序。报告六个R2内部结构差及四个各自5000差，七个SNR范围，共70个源图配对时延区间。后者仍标注为额外训练影响。

分别从R2/Grid/Joint已保存的波形档案读取实际s/y，核对选择、编码器、噪声、图像及裁剪推理一致性。TX计入视觉编码与通信发送器，RX计入通信接收与视觉Decoder；这些固定子集时间不与旧100图时间混排。模型预热、哈希/像素检查和GPU查询不进入计时区间。

每个模型计时前后及每张源图前后检查其它GPU进程，发现竞争则保留已提交源图，等待后重新执行未提交源图，不停止其它任务。进程采样不能证明任意瞬间都独占，保留这一限制和被动观察记录。质量允许显式共享，计时不采用共享准入。

收尾器只接受已核验身份的10000训练/审计进程；依次执行质量、CPU产物与统计审计、独立计时。只对明确的资源保护退出自动续跑，模型/数据/哈希错误停止待检查，不无限重试，不启动新的训练分支。
