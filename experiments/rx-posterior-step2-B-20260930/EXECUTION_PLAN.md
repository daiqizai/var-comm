# A 部分：冻结 P4084 的接收端增量验证

## 1. 固定系统与资源

使用 C priority development 中第一训练 seed 的 **P4084、selected27500**，记为 `B2`。根据原 selected/lineage 文件定位真实 checkpoint，不使用历史 10k 版本或最后一步冒充。

冻结以下全部权重：视觉 Encoder、P4084 通信 Encoder/Decoder、官方量化器及码本、VAR、与该 P4084 对照一致的 Dc。模型置于评测模式；没有参数更新。

真实路径保持为：

```text
原图 → 视觉 Encoder → F → P4084.transmit → 原能量归一化
     → 一次 AWGN → P4084.receive(y, snr) → Fhat_P

B2：       Fhat_P → Dc → 原始接收图
新增候选： Fhat_P → 逐尺度修正/融合 → Fbar → 同一 Dc
```

- 总复信道次数 `N=4084`，沿用原逐帧能量约束 `E=8168` 和真实实测账本。
- 沿用原AWGN约定：名义SNR为s dB时，γ=10^(s/10)，每个实坐标的噪声方差为1/γ、标准差为10^(−s/20)。使用原生成器，不在receive之后重复加噪。
- 每个源图/SNR/噪声下只生成一份实际观测和 `Fhat_P`，所有后处理共享它。不另加 latent AWGN，不重新归一化候选的输入，不为候选增加任何传输。
- SNR 输入与 B2 保持一致；不添加免费类别信息。VAR 使用现有已验证的无条件接口，不使用 CFG、top-k/top-p 或采样。
- 在线后处理不得读取干净 F、真实 token、源图类别或源图像。真值只用于 TX、校准和独立评分支路。
- 这是基于经验误差模型的接收修正，不宣称精确物理后验、全局 MAP 或额外获得了新的单样本观测。

## 3. 核心方法：逐尺度近似打分

### 3.1 经验误差统计

在原 latent 坐标定义：

\[
e_P=\hat F_P-F,\qquad e_{k}=\operatorname{down}_k(e_P).
\]

对每个 SNR、每个尺度，使用校准源图及三噪声，汇总源图、噪声、空间和通道维度，估计：

\[
b_k=\mathbb E[e_k],\qquad v_k=\operatorname{Var}(e_k),\qquad q_k=\mathbb E[e_k^2].
\]

同时保存按 32 个通道分开的同类统计，用于诊断；本轮不再扩一套通道加权似然接收器。记录所用 reduction、方差下限和数值稳定规则。

主打分使用原稿的标量尺度方差 `v_k`，β=0。偏差与均方误差只作诊断，不根据 development 临时决定是否去偏、换方差或增加网络。

这里的 `v_k` 应称“等效重建误差方差”：它包含学习映射和压缩的误差，实测方差并不证明误差独立、高斯或零均值。

### 3.2 顺序恢复

使用完整官方十尺度 `[1,2,3,4,5,6,8,10,13,16]`、实际码本与累计映射，不只截取前四尺度。

\[
r_k=\operatorname{down}_k(\hat F_P-\hat f_{<k}),
\]

\[
S_{k,j}(t)=-\frac{\|r_{k,j}-c_t\|^2}{2v_k}+\lambda\log p_k(t).
\]

- `A1`：没有先验，直接最近码字。
- `A2`：使用沿用并核实的校准 token 静态频率表。
- `V`：使用冻结 VAR 根据当前接收端历史判决给出的条件分布。
- 实际接收器使用自身历史判决、逐尺度 argmax；每个尺度按官方残差贡献和 `get_next_autoregressive_input` 更新。
- λ 乘在 **log prior** 上，不乘在距离上。λ 对每个 SNR 选择一个值，十尺度共享，不新增逐尺度 λ 搜索。
- λ 网格固定为 `{0, 0.25, 0.5, 0.75, 1, 1.5}`。
- λ=0 时 A2/V 必须与 A1 选择同样的 token，可跳过 VAR 计算。
- 距离在原码本坐标计算；不要把标准化后的特征直接与原码本比较。
- `v_k=0` 或极小值沿用经过验证并预先登记的数值保护；干净输入的 λ=0 自检直接使用最近码字，不作零除。

得到 `Fq_post` 后，不直接把它当作最终 F 估计。需同时评价不融合输出和下一节的融合输出。

## 4. 融合、真正旁路和共同权重消融

### 4.1 主结果：分别校准的融合

复用 Step 1 的固定标准化统计 μ、σ；所有接收器共用。定义：

\[
x=(F-\mu)/\sigma,\quad \hat x=(\hat F_P-\mu)/\sigma,
\quad x_q=(F_q^{post}-\mu)/\sigma.
\]

在 calibration 上按通道 c 估计：

\[
\tau_c^2=\operatorname{Var}(\hat x_c-x_c),\qquad
\rho_{R,\lambda,c}=\operatorname{Var}(x_c-x_{q,R,\lambda,c}).
\]

每个 SNR 的 `tau` 在接收器之间共享；`rho` 按接收器和 λ 分别估计。相同统计中附报误差均值、均方误差和两种误差的交叉二阶矩，不把偏差忽略不报。

主融合沿用原稿：

\[
\alpha_{R,\lambda,c}=\frac{\tau_c^2}{\tau_c^2+\rho_{R,\lambda,c}},
\qquad \bar F=\hat F_P+\alpha_{R,\lambda}\odot(F_q^{post}-\hat F_P).
\]

上式与标准化坐标下的原公式代数等价。两侧误差相关，因此这是启发式收缩，不宣称独立高斯信息的最优融合。两项均为零时权重取 0；数值规则在校准前记录。

### 4.2 旁路不是 λ=0

必须提供明确的 `BYPASS` 动作：

\[
\bar F=\hat F_P.
\]

旁路直接返回 B2 的同一输出，避免重新标准化产生端点差异；不要用“λ=0 后再量化融合”冒充旁路。

### 4.3 共同权重内容消融

为分离“候选特征内容”和“各自融合校准”两项作用，固定：

\[
\alpha^{common}(\mathrm{SNR})=\alpha_{A1}(\mathrm{SNR}).
\]

这个权重只由 **A1 在 calibration 上的统计**确定。将它应用于 A1、A2、V 各自的未旁路选中候选 `Fq_post`，不得为共同权重版本重新选 λ。

- 候选 `Fq_post` 和 `Fhat_P` 直接复用，仅重新融合和解码。
- 共同权重不是所有方法的最优权重，只是预定的机制干预；不要据此单独宣布部署性能最优。
- 某方法最终策略选择旁路时，仍可展示其未旁路候选的共同权重诊断，但必须标注“诊断，不是策略输出”。
- 原来各自校准权重的结果不能删除；两组结果并列解释。

## 5. 校准选参：先选候选，再与真正旁路比较

对 A2 和 V 使用完全相同的流程，全部在 200 张 calibration 源图上进行。主选择使用**实际闭环融合后的图像**，不是 TF 的 token 准确率。

1. 遍历固定 λ 网格；每个候选按第4节估计自己的 rho，计算闭环融合后的平均 PSNR、LPIPS。
2. 可行候选要求：相对 B2 的平均 PSNR 下降不超过 0.3 dB。先对每个源图平均噪声，再平均源图；不用平均 MSE 换算平均 PSNR。
3. 在可行候选中选择 LPIPS 最低者；LPIPS 完全同值时取较小 λ，保存为该方法的 `raw_selected`。
4. 如果没有可行修正候选，策略必须 `BYPASS`。可将所有候选中 LPIPS 最低者保留为 `infeasible_diagnostic`，不当作可行策略。
5. 即使存在可行候选，也需与 B2 本身比较。修正候选 LPIPS 未低于 B2 时，策略 `BYPASS`；并列优先旁路。
6. A1 只有一个无先验修正候选，同样与 B2 比较并允许旁路。
7. 13 dB 的**校准**PSNR约束收紧为下降不超过0.2 dB，其他选择流程不变。Development 仍需实测，不因为校准满足就预报通过。
8. 冻结每个 SNR 的 `raw_selected_lambda`、`raw_feasible`、`policy_action`、`rho/alpha`、完整候选成绩和并列规则。

不把校准成绩当作独立泛化证据。选 λ=0 只说明当前评分/网格没有显示条件先验的额外好处；选旁路只说明当前后处理候选没有显示优于 B2，不作普遍否定。

## 7. 指标、机制与样例

### 7.1 主结果

保留 PSNR、LPIPS（alex）、DINO cosine。附报原稿定义的阈值事件：DINO<0.6、LPIPS>0.35；将其称为“所设指标阈值的失效比例”，不当成真实任务可靠性的完整定义。

同时报告：

\[
\|F-\hat F_P\|^2,\qquad
\|F-F_q^{post}\|^2,\qquad
\|F-\bar F\|^2.
\]

latent 误差统一原坐标平方和，必要时另列均方值并明确区分。

### 7.2 机制诊断

- 每个 SNR 的 λ、旁路比例/动作、融合 alpha 分布、偏差与误差二阶矩。
- TF：真实前缀下逐尺度 token 准确率；只诊断局部判别，不渲染成方法主结果。
- CL：实际自身前缀下的路径条件 token 准确率；另报相对原编码 token 的一致率，两个目标分开。
- 尺度等权与 token 数加权结果同时保留；低熵不等于判得正确。
- 干净 F 和真实 token 只能进入评分支路，不能进入实际闭环、融合权重或旁路决策。
- 本轮不新增 TF 准确率“生死门槛”。token 指标解释机制，最终 F/图像指标判断恢复价值。

### 7.3 源图匹配特异性

预先固定无固定点排列 π，使用种子20260930生成，并在评测前保存；不按图像相似度选择排列。

对每个比较控制 C，计算：

\[
\Delta_{match}=DINO(V_i,x_i)-DINO(C_i,x_i),
\]
\[
\Delta_{mismatch}=DINO(V_i,x_{\pi(i)})-DINO(C_i,x_{\pi(i)}),
\]
\[
\Delta_{specific}=\Delta_{match}-\Delta_{mismatch}.
\]

当主张相对某控制的 DINO 增益时，要求对应 `Delta_specific` 的配对95%区间下界大于0。B2、A1、A2均可复用相同特征做检查，不引入新模型。

这支持“更接近当前源图而非固定错配图”，不能证明同类别实例细节或文字全部真实。LPIPS增益仍单独判断，不强制附带DINO显著改善。

### 7.4 接收时间与固定样例

固定原development的10张计时图、两次测量和既有warmup规则，报告B2、V未旁路修正、V策略的接收时间。边界统一为CPU接收波形→CPU图像，P的接收网络必须计入；另列新增VAR/修正时间。旁路速度不得冒充运行VAR时的速度。

默认使用既有固定样例；没有既有名单时，在config中固定源序号0、25、50。输出原图、B2、A1、A2、V的同源同噪声比较，展示−2、1、4、13 dB。不得按结果挑最好看的图。

## 8. 统计与G1：分清效应、幅度和适用范围

每个SNR单独分析。每张源图先平均三个噪声，再按源图成对bootstrap 10000次，种子20260930，逐点95%百分位区间。对所有方法使用相同的源图重采样索引。区间不包含训练seed变异，未作多重比较校正，属于预先列出的探索性对照。

主比较为 `V_policy − B2/A1_policy/A2_policy`。PSNR、LPIPS、DINO、latent误差和失效比例全量保留，不只写过关项。

### 8.1 保留原稿的“明显增益”幅度

对每个控制，在某SNR满足以下任意一条质量收益分支：

- LPIPS均值下降至少0.02，且差值95%区间上界<0；或
- DINO均值提高至少0.02，且差值95%区间下界>0，并通过对应的匹配特异性检查。

同时，V相对B2的PSNR均值下降不得超过0.3 dB。三个控制都满足，才记该SNR为 `G1_CLEAR_GAIN`。各控制触发的指标分支逐项列出；不能因此声称同一个指标对全部控制都显著改善。

### 8.2 不到幅度门槛时不作错误归因

| 结果标签 | 定义/解释 |
|---|---|
| `G1_CLEAR_GAIN` | 满足上述明显增益标准 |
| `SMALL_SUPPORTED_GAIN` | 对全部直接控制存在同方向有统计支持的质量收益，满足PSNR约束，但未达到0.02幅度；是否值得追加取决于计算代价和复现，不预先等同于可发表贡献 |
| `PARTIAL_GAIN` | 只优于部分控制；如只胜B2、不胜A1/A2，不能声称VAR提供独立增量 |
| `NO_GAIN_ESTABLISHED` | 区间或约束不支持当前方法增量；不等于证明VAR或整个后验方向无效 |
| `BYPASS_SELECTED` | 校准策略选择原系统；明确输出与B2相同，不作为修正成功 |

### 8.3 13 dB单独报保护检查

沿用原稿的观测性检查：PSNR均值差≥−0.2 dB，LPIPS没有显著恶化。同时列出未旁路候选和最终策略。

“未发现显著恶化”不等于已经证明统计等效。若策略旁路，该点只能说明旁路保护有效，不能证明VAR修正天然高SNR无损。低SNR结果、高SNR副作用分别报告，不用一句PASS掩盖取舍。

原稿列出的AdamW、学习率2e-4、weight decay 1e-4、有效batch16、裁剪1是拟议设置；启动前与实际原P训练配置核对。若不一致，先明确采用哪一套，不能一边更换优化配置、一边声称“只改训练SNR”。微调与原checkpoint、优化器状态如何初始化均需注明，不覆盖原P4084。

以新增10000次更新为首个里程碑，每2500次完整校准。仅当最近两个2500步区间的校准utility相对改善均≥0.2%时，才再追加10000步；最多新增30000步。单臂P_low不存在“成对延长”，不因此多建一个训练臂。所有规则在启动前冻结。

在选中的P_low上，重新估计经验误差和融合参数，并按A的同一方法复测。

- 主评测：−5、−2、1、4 dB。
