二、P0-1：把离线策略与在线装帧写成可复现的方法

位置：主要修改 II.B；III.A 保留数据规模与评估条件。

需要从实际冻结配置、策略选择代码和结果记录中核实以下内容，并整理成简短方法段落或算法步骤：

1. 候选空间。
   写清 WHOLE 和 PARTIAL 的完整尺度端点、边界尺度范围、四分之一尺度 K 值及取整方式、最大端点，以及参与策略选择的 MCS。
   区分目标端点候选和目标之下可用的回退端点。
   主实验各 SNR 的冻结集合、controlled100 的 7/13/25/49 网格不是同一件事。
   特别核对 19 dB 的实际配置：历史脚本与后来加入完整 m10 的冻结配置可能不同，以生成当前论文结果的配置为准。

2. 离线选择流程。
   明确校准集上比较哪些“目标端点 + MCS”候选，实际重建经过哪些信道处理，DINOv2 相似度如何按源图和噪声聚合。
   核实校准分数是否包含拒收后的固定灰图；以实现为准。
   若真实流程是初筛后在完整校准集复评，就简洁交代两阶段流程，不能写成全空间穷举的全局最优。
   区分搜索选出的参数与按规则生成的回退链，不把确定性回退链写成额外学习出的参数。

3. 在线实际码长装入。
   给定已选 MCS 和目标端点，按冻结顺序检查候选，使用每个前缀独立终止后的实际算术码长。
   预算判断仍为 b(x,e)+29 <= k_a。
   选择第一个可装入的端点，发送的 profile 标明实际端点和 MCS。
   写清回退的排序、必要的并列规则和最短端点。
   区分发送端无可行端点与接收端 CRC/解析失败；链耗尽若没有定义，明确记录缺口，不能自行补造灰图分支或改协议。
   不把长算术码流直接截短当作合法前缀。

4. 冻结配置的可查证记录。
   整理 4/10/19 dB 下 WHOLE、PARTIAL 的实际 MCS、目标端点、回退规则及配置文件路径。
   论文只放读者理解与复现所需的紧凑说明；完整列表保留在仓库说明和配置文件中。

完成标准：
读者能够依据 II.B 和配套配置，判断一张新图在给定 SNR 下选择哪套策略、如何装帧、发送哪个端点。
这一步整理现有算法，不能顺带重新校准策略或替换冻结主实验。

三、P0-2：把核心贡献与 next-scale 机制连接起来

位置：引言最后一段、II.B、II.C；必要时同步摘要与结论。

围绕下面的逻辑写清设计：

- next-scale 模型用已知的完整粗尺度生成边界尺度各位置的分布，因此发送端和接收端能在本地构造对应 CDF。
- 在同一 next-scale 表示下，尺度内端点提供比整尺度更密的可发送前缀；独立终止后的实际码长决定它能否装入固定数字帧。
- 接收端把收到的边界 token 写回预测图。这既修正残差 latent，也改变更细尺度的预测上下文。

技术边界要准确：
模型参数化、残差 VQ 表示和 known-token overwrite 来源于 VAR，应正常引用。
当前实现的边界尺度未接收位置，仍按完整粗尺度条件生成；不要写成这些位置又以收到的 K 个边界 token 为条件重新联合预测。
本文主要贡献写成尺度内端点、实际装帧及相应接收流程的通信设计与受控证据。

摘要继续突出同模型的 0.32–0.70 dB 增益，以及 10 dB 的 77.70% -> 95.21% 利用率变化。
外部六系统比较用于说明质量与计算开销的取舍，不把对 ARPC 或 Ada 的全部差距归因于端点粒度。
“适配 decoder”与“冻结 prior”的状态分别写清，不把整个系统称为无需训练。

写作要求：
使用直接的机制说明和结果陈述。
引言中“rather than a finer truncation rule than Ada...”一类针对潜在质疑的句子，可改成正面描述本文在 next-scale 表示中解决的问题；相关工作段保留 Ada 的 token-prefix 事实即可。
不增加逐项自我辩护段落，也不把常规编码模块单列成创新。

四、P0-3：定义清楚接收端 A0/B0/C0 诊断

位置：III.B 的 receiver diagnostic 段落；完整定义放在对应实验说明中。

目前 0.220 dB 和 0.440 dB 缺少足够直观的干预定义。按实际代码核实后，用简短文字交代：

A0：忽略已收到的边界 token，沿原有先验预测路径重建。
B0：只把这些 token 的修正计入最终残差 latent，不改变用于更细尺度预测的上下文。
C0：同时修正残差 latent 和更细尺度预测上下文，即完整接收处理。

核实三个分支的来源图、实际收到的内容、接收有效性和数值执行条件一致。它们是接收端干预，不是三次重新选端点的系统运行。

结果表述：
10 dB：B0-A0 的平均 PSNR 差为 0.220 dB，C0-B0 为 0.440 dB。
19 dB：边界已在最后一个尺度，因此 C0-B0 为零。
这些是按指定顺序设置的实验差值，不要写成适用于任意系统的独立可加增益定理。

正文不必为三个分支新增大图；可以用两三句定义加一两句结果完成。

五、P0-4：整理通信假设、拒收记录与统计口径

位置：II.A/II.C、III.A、仓库实验说明。

1. 通信假设。
   从代码核对并用简短文字说明：
   - TX 用什么 SNR 信息选择策略；
   - RX 的 LLR 使用哪一噪声方差；
   - 数字调制和连续 JSCC 的功率归一化口径；
   - 每图总预算为 1024 个复符号，NeST 的 68 符号头与 956 符号体如何计入。
   当前 profile 使用旋转 BPSK，不要恢复为历史稿的 QPSK 描述。
   本轮整理实际实现，不更改能量或预算定义。

2. 拒收。
   优先从已有逐帧记录统计最终接收失败数和总数，按方法与 SNR 给出。
   核查范围应覆盖最后的 profile/body/length/padding/arithmetic 处理；仅有“PHY 解码成功”不能自动代表最终有效接收。
   最终失败按既定灰图计入四项指标。
   发送端为适应码长而回退不是接收失败，两类统计分开。
   无失败时也报告实际计数，如经核实后的 0/1500，而不是直接写“没有失败”。
   正文只保留有用的一句或紧凑汇总；完整计数 CSV 放仓库。

3. 统计。
   保留每张源图先平均 3 次信道结果，再对源图做 bootstrap 和逐图配对差的口径。
   不把 100 张图 × 3 次噪声当成 300 张独立源图。
   表中的实验集合、样本量和数值必须来自同一份结果文件。

若实现与文字不一致，先修正准确说明；若涉及科学结果口径变化，列出受影响项，不能静默重算并覆盖主结果。

八、P1：一个范围固定的 TX-policy SNR mismatch 实验

研究问题：
发送端继续使用为 10 dB 选定的策略，而真实信道偏离该值时，WHOLE 与 PARTIAL 的重建差异和接收失败率如何变化？

这是对冻结策略的局部压力测试。当前匹配 SNR 主实验的结论不以它为前提。

固定协议：
- 方法：WHOLE 与 PARTIAL。
- 数据：沿用已有固定 100 源图清单；记录清单与哈希。称为现有样本上的诊断，不称为新的盲测集。
- 发送端策略选择 SNR：始终 10 dB。
- 真实信道 SNR：8、10、12 dB。
- 每图每条件：3 次预先固定的噪声实现。
- 预算：每图 1024 个复符号；预处理、功率、头、体、码、接收规则与主实验一致。
- 冻结内容：各自的 10 dB MCS、目标端点、回退链、权重、生成设置和 profile 定义。
- 允许按已有实际长度规则执行回退；不能根据真实 SNR 换策略或重新排序端点。

两套原有策略的 MCS 与目标端点应在运行前列出。
论文当前报告 WHOLE/PARTIAL 在各主实验 SNR 选到相同 MCS，仍需依据冻结配置确认。
无论 MCS 是否相同，此处结论表述为冻结策略的 SNR 敏感性；纯端点粒度证据仍由 Table I(B) 提供。

接收端：
第一轮保留 RX 用真实噪声方差计算 LLR。
实验名称明确为 TX-policy SNR mismatch，不能称为收发双方均存在 SNR 估计误差，也不能外推到衰落信道。

噪声与复用：
预先生成每个“源图 × 重复”的复标准 AWGN，实现 WHOLE/PARTIAL 间同一噪声向量，并在三个真实 SNR 下按方差缩放。
噪声 RNG 与协议/生成 RNG 分开，不能只凭两个脚本传了相同整数 seed 就认为噪声相同。
10 dB 旧记录只有在清单、种子、实际噪声、配置和数值执行条件完全一致时才能复用。
可缓存与信道无关的编码及确定性重建；每次信道接收和拒收判断仍需真实执行。

规模：
2 方法 × 3 真实 SNR × 100 图 × 3 噪声 = 1800 个接收评估实例。
这个数量是重复评估次数，不是 1800 张独立图片。

需要输出：
1. 全部逐次接收记录与拒收原因。
2. 每个方法、每个真实 SNR 的 PSNR、LPIPS-Alex、DreamSim、CLIP-I。
3. 最终拒收数 / 300 与拒收率。
4. 每个真实 SNR 的 PARTIAL-WHOLE 逐图配对差及 95% bootstrap CI。
5. 每张源图先对三次噪声平均；灰图参与质量统计，不能只算成功接收样本。
6. 完整配置、图像清单、代码版本和噪声标识。

展示与停止条件：
结果完整呈现三个预定点及四个指标；正文可以突出 PSNR、DreamSim 和拒收率，其他数值保留在完整结果中。
优先用紧凑表和短段落；若曲线更清楚，再用小图，不挤占主要内部证据。
看见退化或不显著结果也按预定协议结束，不为改善曲线改 SNR 点、样本或策略。
若 8 dB 下失败明显，报告这一固定策略的工作边界，不把问题藏在“仅成功样本质量”里。
1800 个预定实例完成并核对统计后，不自动扩成更多 SNR、更多方法或新一轮训练。
