# Exact interrupted lightweight-publication continuation

The first publication stopped while copying an already closed 19,048,505-byte
A2b TX completion, before any document, index, check or commit change. Its real
failed exit is preserved. That single full frame-level completion remains on
PFS with its SHA and scientific closure; lightweight publication records its
descriptor instead of treating it as a restoration backup. All other selected
files are copied, verifying and reusing the 156 already copied files by SHA.

After an exact inventory comparison, the continuation executes the original
document/staging/check/normal-commit body. No science, metric, statistics,
scientific budget, filter or persistent Git configuration is changed. Failure
of any subsequent check is retained and requires explicit diagnosis.
