# 普通网格控制的归因范围

本次保持相同E/R权重形状、三次共享读取、自身历史、完整y和辅助目标，仅把网格4/8/16改为16/16/16。原`CommunicationReceiver.read()`把实际size同时用于池化/位置张量和`scale_condition`描述，因此两者随网格一起变化。

本控制可以检验普通全分辨率重复读取是否已经解释当前增量；**它没有单独分离空间分辨率与显式阶段描述**。若4/8/16在强控制下仍有有价值增量，需要再考虑固定16网格但提供相同阶段描述的控制，才可进一步把增量归于空间粗到细本身。当前不改正在跑的两臂或其被冻结协议。

原父点只按single训练过fine读取；相同初始化权重不代表不同网格初始函数相同。两新臂起点全校准LPIPS均约0.202972，而原multiscale state起点约0.247072。全部起点及后续完整曲线都必须保留；若结果显示尚未充分适配，不能用相同短更新数自动宣布所有结构已收敛。

full-grid innovation还使用额外融合参数和两次内部E，它是强控制，不是对基础state的严格等计算控制。若它胜出，必须如实命名，不能拿接近的参数数量或相同阶段数抹去算力/机制差异。
