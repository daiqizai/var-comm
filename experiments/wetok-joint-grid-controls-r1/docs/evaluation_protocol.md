# Grid5000：质量评测与计时分离

2026-09-14预先规定。当前训练仍按冻结配置推进；本文件只定义尚未运行的新Grid评测，不修改旧Joint/R-only结果、训练源码或原独占检查。

## 质量与物理口径

原100张development、七SNR、每图三个固定噪声；两新Grid模型只在各自5000机会内按完整校准LPIPS选模。原三Joint、六R-only及七个历史系统的16方法已完成同图/同噪声/N/E/指标评测，因此作为逐行冻结参考复用，不重新训练，也不为了补两个模型再重复整套GPU推理。

共18方法、37800主行，其中新推理4200行；旧9与新2共1100无噪名义19诊断；保留600行固定支持Deep补充。原先较弱的对照、较强的full-grid及数字自适应/感知Deep均不删去。

新方法仍为8192 raw source bits、0 header＋3060 data complex uses、总能量6120、实噪声方差1/γ。源Fq、名义SNR、噪声种子及连续接口不变。接收器只能使用完整y、名义SNR及自身状态；重编码不增加传输或观测。正确native和无噪结果不是无线方法排名。

质量阶段明确不测接收时延：所有方法的当前`receiver_seconds`和`online_TX_seconds`留空，旧计时仅标为archived，不混入新速度表。复用记录的质量、选择、物理字段及图像指针必须逐项保持原值；新输出仍核对实际s/y、功率、固定噪声、源图及模型不变。

## 共享GPU边界

质量阶段只有显式`--shared-gpu`才允许与其它任务共用已授权GPU0；未给该参数仍使用空闲启动检查。共享模式开始时至少有8 GiB可用显存，PyTorch缓存分配器上限8 GiB，每个新源图前检查可用显存不少于2 GiB。该限制不是全部CUDA内存或GPU算力的硬隔离，不保证其它任务不变慢；不启MPS、不改驱动/时钟/功率、不停他人进程。

每个源图前后记录GPU占用背景。共享只改变执行调度，不改变模型/采样/信道/指标；数值、数据或OOM错误必须保留现场，通过原源图边界恢复，不丢弃困难样本，也不把共享耗时作为模型速度。PyTorch接口说明：`https://docs.pytorch.org/docs/stable/generated/torch.cuda.memory.set_per_process_memory_fraction.html`。

## 单独计时

速度阶段预先固定32个均匀分布的源图索引、五个支持SNR和噪声2001，见配置。两Grid＋三Joint＋六R-only共11个冻结模型，共1760条新计时。各模型使用同样的32图/SNR/噪声，轮换测量顺序；历史数字/Deep时间不纳入当前计时排名。

计时阶段要求GPU空闲，计算前后检查其它进程。输出须与质量档案对应的图像回放一致，不能选更快或更好的一次输出；有竞争则只暂停/恢复计时，不撤销已完成质量结果。该阶段不选模、不训练、不改变任何质量行。速度只代表本机、此固定测量子集，不与旧100图全噪声时间混作同一采样表。

## 统计与证明范围

主要方向为原Joint multiscale state减新普通full-grid state；新innovation对普通full-grid及全部旧16方法为其它比较。共33个有方向的非重复对照，八个SNR统计范围、六个原指标，1584条图像级配对区间。先在每个源图内平均噪声/SNR，再用原10000次bootstrap规则，不把传输次数当独立源图数。

支持点补充对11个学习接收器与固定支持Deep比较，198条区间。保留同WeTok数字高SNR强结果，不能用其低SNR失败或Deep旧5/6条件异常制造优势。

普通迭代不得改名next-scale。空间网格与size/阶段描述尚未完全分离，见`attribution_limits.md`。本轮仍为development，没有新holdout或训练重复，也不是最终方法完成证明。
