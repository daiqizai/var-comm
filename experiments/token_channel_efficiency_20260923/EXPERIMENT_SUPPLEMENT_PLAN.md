# 离散Token与连续JSCC：资源效率补充实验方案

> 版本：v1.0｜编制：2026-09-23｜用途：Codex执行任务与研究记录
> 本文为补充方案，未启动训练或修改仓库。先做源表示／码流，再做质量—N曲线；短前缀实验与前份计划合并，避免重复。

## 01｜任务范围与执行顺序

**目标：在相同图像质量要求下，比较离散token数字链、连续JSCC和短前缀混合链需要的实际信道次数，而不再把源码bit节省直接等同于无线资源节省。**

本文将上一轮讨论整理为补充执行方案，不新增文献新颖性结论。下述新预算、配置和训练安排均为拟议实验；历史实测只在注明来源的位置引用。执行时先核对现有工作与运行状态，避免重复任务。

### 1.1 基准与已知事实

以已审阅提交 `cf70b314d596` 为版本基准，完整SHA见文末。该轮同N4084、同Dc、100张development、五SNR、三个噪声的平均结果如下。[S1]

| 历史工作点 | PSNR ↑ | LPIPS ↓ | DINO ↑ |
| --- | --- | --- | --- |
| raw数字自适应m7/m8/m9 | 21.5053 | 0.136528 | 0.893571 |
| 原m8＋1024连续增强 | 22.0674 | 0.136225 | 0.874412 |
| 全预算纯连续 | 24.0010 | 0.092556 | 0.923571 |

这些数值支持该工作点的系统比较，但不能推出离散token在所有质量目标、带宽和PHY下都不划算。历史算术码的payload节省曾被用于同N下的纠错冗余，而非缩短物理发送长度。[S2]

## 02｜共同定义、数据与通信账本

### 2.1 必须分开的量

| 符号 | 本方案中的含义 |
| --- | --- |
| F | 冻结视觉Encoder＋quant_conv输出的连续latent，当前形状32×16×16。 |
| Fq | 全部真实量化token重建的完整量化latent；一般不等于F。 |
| Bsrc | raw索引或实际算术码流的源bit数，不含另列的控制和FEC。 |
| N | 实际发送的复信道使用次数；包含header、数据、增强和填充。 |
| E | 完整实际发送波形的能量和；不能把显存中的float32位数当成N。 |
| D0 / Dc | 原图像Decoder / 阶段A选定的适配Decoder；主通信对照固定Dc。 |

### 2.2 主协议

主实验沿用AWGN、每复符号目标平均能量2，γ = 10^(SNR_dB/10)，每个实噪声坐标方差为1/γ。连续码字从训练起按对应N归一化；QPSK保持既有能量约定。[S3]

| 预算N | 主协议整帧目标E=2N | 用途 |
| --- | --- | --- |
| 2048 | 4096 | 新增紧资源点；不预设对数字或连续更有利。 |
| 3060 | 6120 | 新增匹配连续点；衔接已有外部JSCC和数字参考。 |
| 4084 | 8168 | 复用已完成纯连续、数字和混合工作点。 |

固定符号能量时，N改变也改变整帧能量；应报告“质量—信道次数／整帧能量”取舍。本文不新增固定整帧能量跨N实验。16QAM的平均能量边界另见第5节，不将其默认为逐帧恒能量。

### 2.3 共同数据与信息边界

复用原20,000张训练、1,000张校准和100张development；SNR为1/4/7/13/19 dB。校准seed为4101/4102/4103，development为2001/2002/2003。数据、crop、指标权重、精度配置及噪声命名域均绑定run身份。[S1]

数字VAR继续披露TX真实类别已知、RX类别实际过header、名义SNR理想共享的假设；类别获取与CSI估计未测。纯连续不得额外读取类别、真实前缀或VAR补全。首轮不新增反馈、ARQ或新holdout。

> 全部失败都计分。CRC失败不是“整张图不存在”；沿用已登记候选使用与灰图规则。既不能删除失败帧，也不能将连续链没有CRC描述为100%可靠恢复。

### 3.1 要回答的问题

| --- | --- | --- |
| m6 | 91 | 1092 |
| m7 | 155 | 1860 |
| m8 | 255 | 3060 |
| m9 | 424 | 5088 |
| m10 | 680 | 8160 |

上表按官方尺度[1,2,3,4,5,6,8,10,13,16]及每token 12 bit计算，是源码账本，不是新的传输结果。m10全传仍只传量化表示，不传剩余连续量化误差。

### 3.2 执行内容

对m6–m10生成真实raw索引及实际整帧算术码流；验证编码—解码的token逐项一致。算术统计必须使用实际写出的码流长度，不能以理想交叉熵替代。记录均值、中位数、P90/P95、最小／最大长度和raw回退比例。

使用同一执行精度与同一批图，补齐 `D0(Fq)、D0(F)、Dc(Fq)、Dc(F)` 四格诊断。前缀m6–m9分别记录直接累计表示解码与VAR确定性补全解码；保持官方十尺度量化映射。m10不再执行不必要的后缀生成。

对所有路径报告PSNR、LPIPS和DINO。四格用于区分表示与Decoder接口的影响，不把跨Decoder差值全部叫作纯量化损失；无误码或完整F结果不进入有限信道排名。

## 04｜实验B1：三个预算的质量—资源曲线

### 4.1 连续侧：新增两个预算模型

保留P4084已测工作点，新增P2048和P3060。三者复用相同冻结视觉Encoder、训练统计和选定Dc；在线绕过VQ量化与VAR，RX只读取实际连续观测和名义SNR。

新长度必须从训练开始参与forward、功率归一化和加噪。可以使用明确登记的权重暖启动，但输出头和mask要适配目标N并实际训练；不得将P4084测试时截短，冒充已经训练好的低预算系统。

### 4.2 数字侧：先在既有QPSK协议内补全曲线

每个N、每个SNR校准raw与算术两族的可行m及保护配置。先复用已支持的m7/m8/m9；m6/m10若需协议扩展，必须先建立新版本并验收，再纳入候选。不能将“代码未支持”写成“理论不可传”。

使用实际码流、真实FEC母码和rate matching，按正确N重新发送／接收。已测QPSK候选只要模型、协议、数值精度、数据和完整键相符就复用。数字模式由校准选择，不能从development逐图挑最佳模式。

| 对照族 | 主预算 | 处理方式 |
| --- | --- | --- |
| 纯连续P-N | 2048 / 3060 / 4084 | 低预算实际训练；4084合法结果复用。 |
| raw数字VAR | 2048 / 3060 / 4084 | 真实编解码、固定长度payload与对应保护。 |
| 算术数字VAR | 2048 / 3060 / 4084 | 实际可变码流、长度字段和预定溢出回退。 |
| 已有混合 | 实际已测N | 只放真实点；不按源码bit缩放横坐标。 |
| 外部JSCC/R3 | 合法自然预算 | 同N时直接比较；不同N单列工作点。 |

### 4.3 不可编码与溢出必须显式处理

raw m10有8160个源bit。在原68-use header、N4084的QPSK框架中，数据区仅有2×(4084−68)=8032个编码槽位，尚未计入body CRC/tail便不足。该具体配置应标为不可编码，不得强行截断或仅删除装不下的图。算术m10需要逐图实际判断，不能据raw情况直接排除。

定义候选状态：已实现且可传／实际溢出并按规则回退／不满足长度约束／尚未实现。溢出后所选低m、额外控制、填充与完整发送成本都保留；不能先运行多次信道再免费选成功者。

> 这组主图必须逐SNR展示PSNR—N、LPIPS—N；DINO和质量达标率同时报告。全五档均值只作摘要，不代替各信道条件的资源结论。

## 05｜实验B2：16QAM扩展与控制费用

### 5.1 目的与顺序

先完成QPSK主结果，再增加一档16QAM数据调制作扩展。目的只是检验高SNR时，压缩后的源bit能否通过更高谱效率转化为更少N；这属于补强数字对照，不自动构成新方法贡献。

保持既有FEC母码，先不同时引入多个新码族。MCS集合、rate matching范围和选择规则在校准阶段冻结。每个SNR保留QPSK对照；16QAM低SNR失效是有效结果，不以“理论上更省符号”为由跳过。

### 5.2 必须真实执行的链路

```text
实际源bit → CRC/tail → FEC/rate matching
→ 16QAM映射 → 固定星座缩放 → 单次AWGN
→ 基于实际噪声方差的软解调 → FEC译码
→ token恢复／失败回退 → 图像重建
```

先做无噪声bit回放、小规模软似然符号／尺度测试、有限值和总资源检查，再进入真实图像。不能把QPSK的二值路径得分直接用于16QAM，也不能先硬判决再声称完成了匹配软译码。

### 5.3 能量协议需要单独登记

QPSK为常模；一般16QAM有限消息的逐帧能量会随符号组成变化。采用固定、双方预共享的星座缩放时，应登记平均符号能量口径，并报告实际整帧E的均值、范围和分位数；不能把目标均值2直接当成每张图都恰好E=2N。

16QAM扩展与逐帧恒能量的主表分开呈现，明确双方的约束关系。若使用逐图归一化并需RX恢复增益，则增益必须实际传输并计费；不得从TX内存免费提供。若此项协议仍未解决，标记BLOCKED，不输出严格同E排名。

### 5.4 不免费传模式，也不将填充当节省

每个固定实验cell的N、调制和模型可作为预共享配置；如果逐图自适应改变m、码流格式、MCS或包长，RX必须通过已声明的控制协议获知，相关字段及其保护都计入N。header建议保持稳健且可先解码的格式，不能依赖尚未知道的data MCS去解header。

完整N按实际波形长度计算。固定N主表中，填充符号同样计费；另做真实变长模式时，要单独登记平均N、P95 N、最大N、帧界／包长开销和失败服务规则，不能与“每图固定N”结果混称同一约束。

> payload长度换算 Ndata≈(Bsrc＋校验等)/(Rc·log2M) 仅用于候选筛选。正式结果一律使用真实整数编码、填充和调制后生成的波形长度。

## 06｜相同质量下的节省率与统计规则

### 6.1 冻结共同质量目标

在实验A完成后、读取本轮development新结果之前，用校准数据确定一组共同质量要求并写入 `quality_targets.json`。建议采用“LPIPS上限＋PSNR下限”的二维目标，覆盖较粗、平衡和较高保真三个等级；具体数值由校准可达范围决定，逐项说明依据。

这些阈值是展示资源取舍的目标，不是任意设置的模型生死门槛。不能为了让某一方获胜，事后只保留其有利目标；所有登记目标、负节省率与未达标情况都要报告。

### 6.2 最小N按已测集合定义

```text
N_required(family, SNR, target)
= 满足冻结质量要求的已测配置中的最小实际N

saving = 1 − N_required(digital) / N_required(continuous)
```

每个预算的配置或模式策略先在校准上选定，再在development上验证。报告“已测范围内的最小N”，不称连续最优解。目标在某一族中未达到时标为“已测范围内未达到”；不得用低质量点代替、跨SNR借点，或将线性插值当作已部署结果。

若只有三个预算点，节省结论是离散网格上的结果。资源分辨率不足时可以提出后续中间点需求，但不能为追逐刚出现的有利交点自动开启大范围搜索。

### 6.3 失败与独立样本单位

所有图像保留header失败、CRC失败和合法失败候选。主均值：每个source/SNR先平均三个噪声，再跨源图汇总；区间采用source-image paired bootstrap，重采样10,000次。逐帧图像达标率单独计算并报告，不与“平均PSNR/LPIPS达标”混用。

严格配对使用source_id、population、preprocessing_id、SNR、noise_id与运行身份。相同seed编号不意味着不同码字长度／噪声命名域下观测逐元素相同，应按实际协议说明配对范围。图像bootstrap不包含重新训练种子的变异。

### 6.4 必交付图表

| 图／表 | 必须表达的内容 |
| --- | --- |
| 逐SNR质量—N | PSNR、LPIPS各成图，DINO另图；不把单位不一致的点混成严格排序。 |

## 07｜实验C：衔接m6／m7短前缀混合方案

### 7.1 与前一份任务书的关系

本节沿用前份 `EXPERIMENT_PLAN.md` 的短前缀设计，不将其重新解释成已完成结果，也不另开一套相同基线。尚未启动的工作先完成A/B；已启动的短前缀训练沿原登记继续，结果统一并入质量—N图。

| 配置 | Header | 数字N | 连续N | 总N |
| --- | --- | --- | --- | --- |
| m8混合参考 | 68 | 2992 | 1024 | 4084 |
| m7起始候选 | 68* | 1968 | 2048 | 4084* |
| m6起始候选 | 68* | 1200 | 2816 | 4084* |
| 纯连续控制 | 0 | 0 | 4084 | 4084 |

* 上表是原先建议的预算模板。只有控制字段确实能在该版本中完整表示、且已通过真实编解码，才可使用68-use header账本。m6或新增模式使header增长时，必须从数据／连续部分扣除并训练实际长度；不能保持全部原数值后额外免费加字段。

### 7.2 每个m保留VAR／Prefix两个接收控制

共同TX仅用F和真实前缀累计latent，不获得本次RX噪声或CRC。Prefix-RX使用实际解出的前缀累计表示；VAR-RX由同一实际前缀执行官方补全。两臂都可用同一个已计费的接收类别与合法状态，通信网络同构、匹配训练机会，Dc固定。

Prefix-RX需要单独训练，不能在VAR模型评测时强行关闭补全。两个完整模型联合训练后码字可以不同，不冒称完全同一观测。额外VAR模型和运行成本单列，不为了配平通信参数而隐藏全系统规模。

### 7.3 完整系统比较与机制比较分别解释

| 比较 | 回答的问题 |
| --- | --- |
| 混合 vs 同N纯连续 | 数字基础整体是否值得占用资源？ |
| VAR-RX vs Prefix-RX | 相同前缀条件下，自回归补全是否有额外价值？ |
| m6/m7 vs 同接口m8 | 较粗基础与较大连续支路的分工是否更好？ |
| 修复 vs 无增强 | 新增观测是否有用；此项不能代替全预算强对照。 |

> 旧m7 RGB残差实验不能替代本轮latent实验：它使用68＋1882＋1110=N3060，且低SNR数字保护受损；该旧结论继续按原范围保留。[S4] 首轮不加内容选择器、扩散、coset、显式分组功率或新Decoder。

## 08｜训练、复用与最低验收要求

### 8.1 连续预算模型的建议日程

P2048、P3060沿用已有20k训练与1k校准、原五SNR和同一Dc。目标为 MSE＋0.1×LPIPS＋0.01×normalized latent error；AdamW学习率2×10⁻⁴、weight decay 10⁻⁴，有效batch16，microbatch按显存调整。上述为本轮建议，不是已完成训练记录。

每臂以20,000步作为首轮里程碑，0步及每2,500步完整校准，每500步保存。P4084旧10k点保留；若需要相近新优化机会，可单独续至累计20k并同时报告旧点，不把新增训练收益当作预算机制。只依据校准进行合理续训，不把到达步数等同于完全收敛或模型失败。

选模规则沿用完整校准综合目标，另报告所有分项曲线；DINO不训练、不选模。候选确定后再安排重复训练seed及未见图像确认，本轮不打开新holdout。已有旧holdout不得重新命名为未见测试。

### 8.2 最低验收，不另造一套接收流程

| 检查 | 通过条件 |
