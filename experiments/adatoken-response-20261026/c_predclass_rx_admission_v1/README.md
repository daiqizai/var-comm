# Calibration RX admission

Engineering planning from closed PHY outputs. No model inference, selection or
bootstrap. Re-derive and verify the stored projection from actual received data.
Do not use a post-output comparison with transmitter truth to correct or filter.

Keep every logical source/candidate/SNR/noise event. Validate a complete native
model/code/generation/numerical contract before reusing a closed qualified output.
Only exact class, prefix and actual arithmetic bytes reuse that output. All other
actual source inputs are unique by received identity. Rejected/null frames stay
fixed-gray outcomes with their original logical weights.

Deterministic order uses original source_index, SNR, candidate and noise. Up to
1000 unique inputs per shard; never relabel source indices. Every RX worker gets
only received bits, class and paid-prefix metadata. Source IDs, observations and
scoring target paths remain in a separate logical manifest outside the RX worker.

The preparation helper must verify true PHY exit0 and gone parent/child, all
18000 frames, immutable input/output hashes and the old numeric identity. It
then binds the already-qualified production RX entry and distinct shard inputs.
Launch only the first unlaunched shard once its previous dependencies are closed;
do not retry a failed or partial shard automatically. Scientific completion is
separate from an engineering registration or code qualification.
