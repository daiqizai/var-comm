# Finite production receiver with explicit arithmetic rejection

Independent entry, not a change to the completed qualification receiver or
active source encoder. This directory is engineering preparation until deployed,
qualified, registered and actually launched. No neural invocation follows from
code presence or synthetic test success.

The exact qualified conditional CDF and official frozen native model are reused.
Successful received prefixes follow the original start/logits/CDF/decode/encode/
previous-token order, canonical termination, and identical seed/fork_rng/tail/
render sequence. The sender's image, true tokens, true class and CDF never enter.

Only three precise arithmetic wire failures become gray: bounded terminal
lookahead exceeded during arithmetic decode, canonical length/termination
mismatch, or canonical terminal-lookahead mismatch. Model/CDF/asset errors and
all unknown exceptions remain fatal and retain their failure record. Rejected
streams do not generate a tail or run the VQ image decoder. Their actual gray
output, partial received tokens, reason and actual successful forward counts are
saved. Exact accepted-but-wrong streams remain actual accepted results.

Each input contains exactly key, paid prefix, received bits, payload hash,
received class bits and container hash. A registration must bind original scope,
shared model and numeric identities, all source files and the exact received-only
shard. Do not attach source audit files to the RX registration. Runtime file-read
firewall is the existing qualified boundary. Source truth is allowed only in a
separate audit after fixed outputs, never to correct or choose an RX result.

No arbitrary retry. Reuse already closed outputs only under exact stream/class/
prefix/model/generation/numeric identities. Deterministic shards keep each stage
within 12 hours and the original cumulative ceilings. Calibration selection and
formal evaluation remain separate, later gates.
