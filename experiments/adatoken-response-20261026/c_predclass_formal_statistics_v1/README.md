# Closed formal statistics runtime

This independent CPU wrapper consumes the already qualified analysis.py without
changing its bytes. It is not a model/PHY/metric launcher. It cannot run before
all four formal metric roles and their upstream science closures have real
exit0, gone process identities, zero unresolved calls and matching input hashes.

It validates original common500 and Kodak population identities separately,
including uint8 preprocessing hashes and historical float-reference hashes.
Common500 uses the repaired PARTIAL table at all three SNRs, plus current CLIP;
Kodak uses its own NEST_PARTIAL source table. Different historical noise seeds
are permitted across methods; pairing is by source, not by noise realization.

The unchanged analysis module supplies all mean/paired intervals using the two
existing pinned banks. This runtime adds exclusive outputs and an exactly-two
call statistics ledger. A failed or partial attempt is preserved and never
automatically retried. Old baseline summary decimal strings are carried into
the combined table unchanged; no historical interval is recomputed.

Output target: O/c_predclass_formal_delivery_v1/{common500,kodak24}; every actual
image pair remains in frame_metrics.csv, including fixed gray/rejected outputs.
Summary and direct paired differences each have twelve rows per population.
Capacity and actual endpoint distributions use saved formal PHY choices; the
paper's 32-token subset is a capacity diagnostic only. No new quality setting,
policy, seed, random bank, image reconstruction or metric inference is added.

This directory alone is not registration, launch authorization or completion.
The preparation helper must bind exact code, qualification, all four closed
metric roles/score ledgers/plans, frozen source-baseline tables, banks, source
identities and saved PHY choices. The existing control.py owns the real bounded
wait. Required checks and normal Git publication follow actual delivery.

test_contracts.py tests only invented metadata. It does not invoke the production
worker, any real stage preflight or the earlier numerical analysis tests.
