# Geometry最终开发评测与归因

固定在新模型开发评测之前：仅比较完整总7000=表示2000+image5000训练机会，原100 development、七SNR、原三个噪声。较早里程碑只做匹配预算的校准，不把新image1000与旧image5000结果混成因果对照。

主矩阵为两geometry×三个结构，加WeTok数字8PSK/FEC、数字m8/自适应、感知Deep四参考，共10方法/21000无线行。另有600个实际5/6dB、NN条件4/7的Deep固定支持点，不覆盖原始曲线。

新旧六个geometry模型都在同一GPU会话重新发送/接收，验证旧三个模型与冻结5000图像/指标一致，以免拿旧时延冒充同环境比较。训练控制历史只读复用，不等于在线计算免费。正确native与noiseless映射单列，不是无线方法或数学上界。

所有学习式geometry模型输入同一个native Fq，不接受原图/类别/真实前缀作为RX输入，continuous图像始终直接decode receiver_features。实际N3060/E6120、全局噪声、训练源/校准/开发角色、损失与选择机会保持账本；差异参数量和memory计算必须报告。

质量指标及严重失真规则沿用冻结评测器；先按源图平均噪声/SNR，再用10000次source-image paired bootstrap。主1/4/7不改。21个配对关系×六指标×八SNR组=1008区间，另48个“条件−无历史在两geometry间的差”的交互区间，用以区分packing共同收益与条件结构的额外增量。局部增量不直接推成系统成功。

旧图像/指标不符时停止并保留现场，不放宽既定容差或更换旧图；每个session重新预热，并记录异常/恢复全部已观测耗时。遇到外来GPU计算不结束他人任务。所有失败源都保留，禁止按原图选输出。

此执行器准备不是新geometry成绩；本轮不访问新的正式holdout。合理强对照/训练重复/独立验证仍属于总研究目标。
