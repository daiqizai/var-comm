# 当前连续接口：训练梯度小样本监测

1500固定监控显示：三个continuous的LPIPS均较1000同源回退，部分PSNR却继续改善。仅据loss标量不能判断原因。

在CPU上对一个已保存的共同检查点，取固定global sampler step5000的四张训练图/噪声，检查三种continuous结构的MSE、LPIPS、bits与state对相同通信参数的加权梯度范数与余弦。目标是区分目标冲突的线索与单纯梯度不存在；不加载任何新模型权重，不用calibration/development，不更新参数，不改正在运行的九臂配方。

四张训练样本不能解释全分布，梯度方向也不等于Adam实际更新方向。这不是新的效能gate，不因某个范数大就直接换权重。完整2500校准仍是当前下一决策点；需要后续修订时另立匹配实验。
