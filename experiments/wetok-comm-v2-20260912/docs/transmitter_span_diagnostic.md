# 发射端线性支路与实际信号占用：只读诊断

当前代码的线性skip为153×256空间映射与40×32通道映射的可分离组合。仅就该线性算子，秩最多153×32=4896，小于6120个已付费实坐标。**这不是完整非线性Encoder的秩上限，也不是源bits不可恢复的容量证明**：可学习残差完全可能补充其它方向。

在当前训练运行期间，只用固定16张训练源、名义19dB，检查原2000模型及本轮1000追加步模型的实际发射信号：是否在当前channel_lift列空间以外有能量，以及40维通道协方差的谱。数据由既有配对sampler确定，不挑图片，不使用校准或development。只在CPU前向通信Encoder，不加载图像Decoder、不更新任何参数。

该诊断用于理解高SNR学习映射损失，不能据低方差宣布信息为零，不能从少量样本证明整个非线性码的维数或图像性能，也不能把任意信道坐标命名为语义尺度。结果不作为新方案必须先成功的gate，不改变当前九臂训练、分配或选模。若以后提出发送映射修订，须另外预注册匹配训练与计算对照。
