# 接收估计的波形解释误差：诊断，不是新接收算法

新geometry减少了映射损失，但noiseless仍有约4.7%阈值化bit错误、LPIPS约0.133，对照正确native约0.0868。现有条件历史在更强geometry中损害主区间LPIPS/DINO，不能继续把它默认当正确设计。

本诊断只用固定16张训练源，实际SNR1/7/19和noiseless nominal19，冻结已选中的204×30三个模型。分别将接收端自己的连续估计mu与hard符号h经共享通信Encoder重新映射，测量它们对同一实际波形的解释误差，并与真正噪声能量分开报告。

GT只用于真实发送和事后诊断，不提供给RX，不按真值选择输出。不生成新图、不更新参数、不访问新test。连续mu不是合法native源码；E(mu)仅为已训练连续函数的扩展预测，不能叫精确离散消息似然。误差小也不证明恢复源信息，误差大也不自动证明迭代方法会改善图像。

同时记录实际源TX中的神经残差与线性skip的能量比例，以判断是否可把发送器视为近似线性；不能将比例当码率/容量结论。该诊断只决定下一接收机制是否有新的观测依据，不重开已封存的量化cell约束或两图选择路线。

ISEC等已有工作已使用似然/先验及重编码的迭代修复，因此这些操作本身不能作为原创。若后续实现，应使用真正的新机制、同信息/同预算与合理计算对照，并证明最终图像收益。
