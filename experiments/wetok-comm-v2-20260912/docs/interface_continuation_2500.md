# 接口九臂：1000检查点后续训决定

2026-09-12 18:14，完成实际1000更新/臂与全部1000图×五SNR校准，CPU配对/Adam/选模审计PASS后作出。不是根据development挑模型。

## 完整校准结果

六个hard臂按既定全校准LPIPS仍选追加0，三个continuous均选追加1000。hard的起点是合法候选，不是假造合格fallback，但不能由跨接口差宣称next-scale增量。

continuous条件版对无历史的全校准LPIPS差约-0.004663、对single_pass约-0.002635；这仍是用于选模的calibration，不是独立系统确认。当前没有新模型development、重复训练种子或新holdout结论。

在与500监控完全相同的100源上，500→1000的continuous LPIPS变化为single_pass +0.000462、无历史 +0.001496、条件 -0.001538。走势并非全部单调改善，不能因为0→1000大幅下降就保证无限续训有效。

## 决定

九臂一同从实际1000更新的完整模型与Adam继续至**总追加2500**，即再1500更新/臂；不是从各自选中的最佳点回退训练。LR=1e-4、loss、interface、网络、micro1/effective4、N/E、数据顺序/噪声均不改。继续沿用当前冻结脚本和配置，无新参数搜索。

理由：连续接口取得了比原native起点更好的完整校准质量，条件分支在固定监控上仍有小幅改善；当前总曝光仅(2000+1000)×4=12000，还不能声称充分训练。下一点用于判断收益是否稳定、能否继续减小通信映射损失，不保证最终胜出。

1500/2000追加步只作固定100图监控；2500作完整1000图校准和配对审计。根据那时的真实曲线再决定继续到5000或改变假设，不把2500当整个研究上限。

同时发现的发射支路线性几何问题只记录为下一步线索：16个训练源的19dB信号在channel_lift列空间外的能量很低，但这不是整个非线性码的容量界，不能据此直接宣布20%带宽浪费或立刻换packing。当前不同时修改发送结构。
