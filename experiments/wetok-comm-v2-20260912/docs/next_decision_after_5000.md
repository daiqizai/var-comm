# 等待5000完整里程碑后的决策依据

当前没有改变正在训练的配方。以下是已有观测及下一步触发条件，不是新效果结论。

## 已观察的信号

固定100张calibration子集、相同五SNR/噪声，2000→3000步：
- A0：PSNR 17.689→18.848，LPIPS 0.28803→0.33724，BER 0.14858→0.17987。
- 无历史多尺度：PSNR 17.856→18.701，LPIPS 0.28691→0.34336，BER 0.14868→0.18198。
- 条件多尺度：PSNR 17.893→18.921，LPIPS 0.28780→0.33158，BER 0.14845→0.17669。

2000步进入joint时的固定训练探针中，weighted bit-gradient norm约0.0018–0.0020，weighted image MSE gradient约0.086–0.259，LPIPS约0.052–0.064。单个探针不是全分布结论，但与校准上像素改善、感知/bit退化的迹象一致。
这不是按loss标量大小推断主导，也不是将1000张full均值与100张monitor混比；2000点已严格筛取相同100个ID。

## 下一步

1. 等5000完整calibration及配对development（含native参考、19dB和noiseless映射诊断），不能因单一monitor端点立刻改当前实验。
2. 若LPIPS仍改善且最佳点靠近末尾，原配方继续共同续训，不因5000步或旧时间上限中止。
3. 若完整结果确认image阶段持续造成感知和native-bit退化，优先登记训练目标修订，而不是先改功率或换第三个视觉模型。首个可解释候选是仅提高joint的bit-BCE权重0.01→1，使其与已测image-gradient量级更接近；其余权重、模型、物理参数保持不变。
4. 该候选必须从同一5000模型及Adam起点，与原joint配方同新增更新/数据/SNR/噪声比较。不要从只有model的2000 checkpoint猜造Adam历史；评测入口会为5000共同resume建立不可变硬链接，保留因果比较起点。
5. 若代表性恢复已充分训练但identity/高SNR映射仍差，再按v2检查hard/continuous接口或有依据的发送映射变化，不用更多state/token正确率代替图像收益。

严格工程核查已在评测前纠正新旧噪声seed的端序差异。旧未配对数字预计算保留但不用于主比较；新的PAIRED版本与旧系统标准噪声一致。训练采样及校准噪声没有改动。
