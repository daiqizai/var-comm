# 完成2500开发评测后：共同推进既登记的5000检查点

2026-09-12，已读完整2500校准/开发结果及审计。连续接口改善属实，但当前条件版在主区间LPIPS不胜同接口无历史，且所有新模型仍落后强数字/Deep。该负结果保留，不改模型选择或主指标。

决定保留全部九臂，从实际2500末端模型与Adam共同恢复到**总追加5000**。LR=1e-4、原joint权重、source/native或continuous定义、N/E、micro1/effective4和固定数据/噪声均不变。不是从selected checkpoint重新起训，也不是把旧hard起点偷偷替换为更差末端作控制。

理由是原计划5000检查点尚未跑完、A0/no-history的完整校准最佳仍在2500，当前总(2000+2500)×4=18000曝光不足一次完整20k训练池；不能据短历史给架构下普遍结论。同时这不是收益保证，不因资源上限取消而无限原配方续训。

3000/3500/4000/4500仍为固定100图监控，5000完整1000图校准及配对审计。原best都保留；非有限loss/梯度或物理/冻结校验异常按原规则终止并保留现场。若5000仍不能改善，应明确改变假设或停止这个具体组合，而非继续以代理loss下降自我证明。

不增加新的视觉骨干、发送几何、功率分配或反馈，不打开新holdout。此阶段只补足当前接口与条件结构比较的训练证据。
