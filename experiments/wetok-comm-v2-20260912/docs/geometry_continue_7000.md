# Geometry总4500后：完成匹配image5000的下一检查点

总4500=表示2000+image2500的完整1000图/五SNR校准及配对审计已PASS。新geometry三个结构都由同一选择规则选image2500。

| 结构 | 旧153×40选中LPIPS | 新204×30选中LPIPS |
| --- | ---: | ---: |
| single_pass | 0.257791 | 0.203079 |
| 无历史 | 0.254603 | 0.204214 |
| 条件 | 0.256377 | 0.203916 |

新geometry同时提高PSNR并降低阈值化bit错误率，这与恢复源表示更好相一致，但不等于可靠交付了全部native bits。当前改善首先是geometry实现包的共同收益，不能把它归给条件历史；新条件版尚未稳定超过single/no-history。

从实际总4500模型与image-Adam step2500共同恢复到总7000/image5000，保持全部设置。5000/5500/6000/6500总步数只作固定监控，7000全校准与审计。旧控制具有相同完整训练机会，选择池仍是image0/1000/2500/5000。

达到该匹配预算后才运行evaluate_geometry/analyze_geometry：六个geometry模型同场计时与旧图复现、四强参考、600固定支持点、交互统计。当前不把calibration约0.204与其他development表中的强系统均值混排，也不打开新正式test。

总7000不是整个研究上限；随后依真实强对照、条件增量和成本决定充分续训、修改机制或停止该具体配置。
