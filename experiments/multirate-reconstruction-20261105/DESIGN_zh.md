# 多实际码率数字图像通信：新分支设计边界

## 已完成的转向

用户要求“新建一个分支来做”，并明确选择“当前四臂安全保存后全部暂停”。
原四臂已真实 exit 0，模型、优化器、随机状态和数据游标已保存并核验；其余六臂未启动。
旧 P0/P1 结果和 NeST-Com 稿件保留。新方向不继续旧 P2 的剩余步数，也不沿用其三种子矩阵。

## 两项已有记录检查

3072/4096 bit 两个预算下，500 张测试图都传输完整 28 个原生 slice、336 个 token。
实际收到的所有 token 与发送端一致；两个预算点逐源引用完整表示的同一份原生浮点重建数组，
四个质量指标亦逐源完全一致。完整表示均值为 PSNR 19.660854 dB、DISTS 0.139725、
DreamSim 0.128035、LPIPS-Alex 0.176163；它们来自已闭合结果，没有重新评分或重采样。

因此，这两个点没有可由“换一个尾部补全模型”改善的缺失 token。这里支持的是瓶颈定位，
不等于已经证明更大模型必然有效，也不应把量化、编码器和 decoder 的贡献进一步凭空拆开。
本轮没有另跑 500 次 direct-decoder；现有完整 RX 路径用全部恢复的 codebook 特征进入同一 decoder。

## 主模型的设计优先级

1. 增强可传输表示与完整重建能力。总参数设计目标 6 亿至 10 亿，主要增量应进入图像编码和重建，
   熵模型规模按新表示的建模需求决定。不能把“加深补全 AR、其他完全固定”冒充本方向。
2. 编码器可接收预算条件，允许不同预算产生不同描述。若选择这种方式，论文不声称跨预算自然嵌套，
   预算/模式和尺寸等实际所需信息必须随数字协议计费。
3. 量化和码本可训练，不默认永久冻结。初始化稳定阶段可以短暂冻结，之后随联合率失真目标更新；
   码本/表示容量变化需要重新核验真实码流和独立 RX，不能沿用旧冻结模型的资格声明。
4. 一个主重建路线。现有 RDVQ 预训练组件可用作初始化；直接条件重建与条件 flow 的取舍，
   依据可复用组件、逐源质量目标和实际吞吐确定。选定后不并行铺开 AR/diffusion/flow 三套完整训练。
5. 率损失须影响编码器表示，而不只是让熵模型事后拟合固定 token；真实比特预算仍由最终码流检查。

具体层数、码本大小、预算集合、损失权重和初始化映射尚未冻结。不能把这些尚未实现的选择写成
已完成模型，也不能用旧 251.9M RDVQ 的参数计数代替新系统实测计数。

## 数据、训练与资源

已核验的旧数据为 20,000 个训练 ID、1,000 开发、1,000 校准、500 测试，训练中有一对完全重复的
原生像素（19,999 个唯一训练图像），跨划分无完全相同原生像素。尚未提供近重复或预训练重叠保证。
新方向目标为数十万至百万量级有效自然图像；需要明确扩展语料、合法来源、去重及评测排除清单。
512×512 是正式训练阶段，不只做缩放展示。不能把旧 20k 短训包装成充分训练。

现场八张设备中，旧任务释放了 1/2/4/5，0/3/6/7 仍有其他任务；可用状态需要每次准入重新检查。
不终止他人任务，不假设已经获得整机八卡。主训练优先集中在同一个模型；按实际吞吐、有效图像量和
窗口登记有限可续行段，保存模型、优化器、调度器、随机状态和分布式数据游标。
旧 336 GPU 小时不是本方向的永久上限；也不能因此启动无期限、无账本的训练。

实施资格只排除硬错误：损失/梯度、独立编解码、稳定数据供给、恢复一致性与吞吐。通过后进入正式
训练，不以短程是否已有论文级提升设置新的永久门槛。对照收紧为原始 codec、同目标小模型，以及
主模型稳定后补齐的大模型常规训练对照。

## 文献核验与解释范围

- [RDVQ](https://arxiv.org/html/2604.10546v2)：论文给出 251.9M 总参数；可微量化分布允许率项影响
  编码器，原作者联合 RD 阶段冻结码本。新分支允许训练码本是新的实现选择，不声称原论文已验证。
- [HART](https://hanlab.mit.edu/projects/hart)：明确讨论离散 tokenizer 的重建限制，并使用离散与
  连续残差的混合建模。这为检查表示瓶颈提供动机；其生成/重建 FID 不是本项目逐源通信质量的证据。
- [FlexTok](https://flextok.epfl.ch/) 及[正式论文](https://proceedings.mlr.press/v267/bachmann25a.html)：
  可变离散 token 与条件 rectified flow 可以结合；增大模型对 rFID 的作用不同于逐图 MAE/DreamSim，
  复杂图像也需要足够表示容量。不能据此预先承诺扩大模型将改善全部源图指标。
