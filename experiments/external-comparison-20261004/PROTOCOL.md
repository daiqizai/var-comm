- 必做：SwinJSCC MSE、HiFi-DiffCom 的 Swin 适配、P 与无类别数字 VAR/方法一对照、资源图、指标参照、统一统计和接收耗时。
- SGD-JSCC、DiffJSCC、ADJSCC、DeepJSCC 不新增训练或比较实验。原来已经完成的历史结果及其正在收尾的独立补评保留。

- LPIPS 微调作为 MSE 主比较后的可选扩展。原附件中的预测类别头和大 VAR 属于后续建议项，排在本轮必要工作之后，不妨碍主比较交付。

## 训练、选模与成本

一个官方 base SA+RA 网络、Adam 初始学习率 1e-4、有效 batch 16、MSE；两个总 N 平衡采样，训练 SNR 覆盖整数 1–13 dB。实际微批、精度、优化器状态、随机状态、源顺序、吞吐和峰值显存通过真实资格测试后封存。

资格测试使用 FP32、关闭 TF32、严格确定性计算。Torch 1.12 的通用 gather 反向调用原子 scatter-add，不支持该模式；本轮只在传输包装层对已验证为排序且唯一的通道索引使用无冲突 scatter 反向，数学导数与 gather 相同，官方神经模块不变。前向与梯度精确对照、有限差分及真实 GPU Adam 断点恢复均需通过；保留首轮失败日志。资格测试权重丢弃，恢复最初随机权重，不计为正式训练。

每 2500 更新用完整 1000 校准源、两个 N、1/4/7/10/13 dB、固定校准噪声 4101 评测。按两个码率均衡的校准 MSE 选同一个模型，保存各 N/SNR 曲线。20k 是稳定性里程碑；40k 起每20k按两个不重叠的10k窗口检查：两个 N 的均值及每个 N×SNR 单元的相对改善都小于0.2%，才将学习率依次降为3e-5、1e-5。最终学习率下再满足完整两个窗口后停止，最早80k；最多240k。达到上限仍未满足最终平台规则时标注 budget_truncated，不宣称收敛。

不得根据开发集决定训练停止、选择 checkpoints 或调节 HiFi 参数。正式耗时在同一 GPU、相同接收边界测量；模型加载、文件读取、指标计算不包含在接收时间中。

## HiFi-DiffCom 适配

原已跑通的官方底座是 ADJSCC。本轮将其后验算子适配到新训 Swin，报告为登记过的 Swin 适配，不声称上游已直接提供该实现。

使用原已验证的 ImageNet 无条件 ADM：256x256_diffusion_uncond.pt，SHA256 a37c32fffd316cd494cf3f35b339936debdc1576dad13fe57c42399a5dbc78b1。扩散权重不训练。

两种接收器使用同一次完整观测。后验算子只使用从付费头译出的 mask/power；在新适配代码中恢复完整图像梯度，并验证前向与作者 Swin 数值一致。真实有限差分、梯度、两步采样、峰值显存通过后才能进入完整采样。两步探针不得冒充正式结果。

作者采样日程硬编码的 CBR=1/48 改为实际正文复符号数/(3×256×256)，保留其公式和其余采样参数。这是预先登记的资源适配，不按开发集搜索起始步或生成种子。

## 指标与参照

PSNR、LPIPS-Alex、DISTS、DreamSim、CLIP ViT-L/14、DINOv2 ViT-L/14、MS-SSIM、独立 ResNet-50 分类准确率及与原图预测一致率。新增语义错误率为 1−预测一致率；自信地错为 top-1 概率≥0.5且预测不同的帧数/所有帧数。旧记录没有概率时，必须从真实浮点 RGB 补算，不能推测。

100 源先对三噪声平均，再源配对 bootstrap 10,000 次得到 95% 区间。各方法沿用自己的登记物理噪声命名空间，不声称跨方法逐元素 AWGN 相同。
