# Joint/R-only完整同预算评测

本协议不改训练配方、初始化、采样或正在恢复的RX队列。Joint尚未训练，本评测不能提前用未训练模型替代5000更新结果。

## 比较矩阵

- Joint三基础结构：single、no-history、state-history。
- 冻结E的原六个接收器全部保留：三基础结构、prediction features、multiscale innovation、full-grid innovation。**九个模型均在同一主机重新推理和计时**，不挑选弱R-only对照。
- 三个原geometry父点及WeTok数字、数字m8、数字自适应、感知Deep作为另外七项只读系统参照；旧时延不当作本次测量。

合计16方法×100 development源图×七SNR×三噪声=33600主行，另600个Deep固定支持点。只在Joint和冻结控制各有5000次更新机会、完整校准选模审计完成后运行。Joint选中的step可以不同，但不能改变可用更新预算。原六臂的最终开发评测/CPU分析也须先完成并冻结其receipt。

## 物理与信息边界

统一每图3060次复信道使用、总能量6120。WeTok方法无header与类别，数字m8/自适应继续68+2992账本。均沿用实际每实维噪声1/gamma；名义SNR是假设共享的CSI，不提供本次噪声/真实接收前缀。

同一源/噪声实现使用同一标准噪声。六个冻结E模型仍共享实际s/y，Joint的s/y可因E变化而不同，**不要求也不声称九臂同y**。每模型保存实际s/y的hash、发送器hash和图像/特征。新源图编码在线执行并核对原缓存，不给发送端免费原生特征计算时间。

## 公平实现与数据复用

no-history只保留最终16尺度图像读取；4/8辅助监督仅在训练/校准需要，不在时延测试中强迫它计算。每帧对精简与原完整路径核对logits/符号/Decoder输入逐位不变。其余条件/迭代依赖不得删除。

冻结六臂需重渲染并与其已冻结图像比较。字节完全相同则保留旧archive指针，不复制大量历史图像；若只存在预定容差内数值差，则保存实际新输出并核对指标，不拿旧图替换本次计时对应的输出。所有失败与非理想输出保留。

九臂计时顺序按frame序号轮换；全网格各位置233或234次、每SNR各位置33或34次。每源前后记录GPU温度、时钟与节流；接收时间包括所有内部E调用和最终视觉Decoder。校验、指标和文件写出是离线评测成本，不计为接收推理延迟。

## 统计与解释

主区间1/4/7，另报告全部1/4/5/6/7/13/19。先每源平均指定SNR和三个噪声，再做source-image paired bootstrap，保留PSNR/SSIM/LPIPS/DINO、相对native的LPIPS增量及严重失真指标。原native/noiseless仅用于诊断，不混入无线排名。

每Joint对全部六个冻结接收器、三个父点、四个强系统比较，加Joint内部三关系，共42关系/2016逐比较区间。另给出三种“Joint内结构差−冻结E内同结构差”的交互，共144区间；这不等于证明尺度优于所有等计算迭代。Deep固定支持点另有162配对区间。

这些是反复使用的development数据上的描述性区间，未作多重比较校正，不涵盖训练种子随机性，不是独立验证。若Joint条件有增量，仍需匹配的Joint全网格控制；不得把只更新E、额外训练或更多迭代本身宣称为next-scale创新。
