# 接收机制与部署条件的配对实验

这组实验接续 [11 月 23 日的方向审查](../../reports/directions_20261123/README_zh.md)。[本轮结果](../../reports/direction_followups_20261123/README_zh.md) 给出发现、限制、统计表和 PFS 原始文件入口。

| 研究问题 | 改变什么 | 哪些条件配平 |
|---|---|---|
| 4B 的弱用户为何获益 | 独立开关其他用户的估计波形相减和残余干扰方差更新 | 同一完整接收器权重、同一次叠加上行观测、两轮先验与门控、三次线性分离 |
| 4B 的学习模块相对常规并行干扰消除有多少增益 | 用原始线性估计重构干扰波形，再把学习门控换成验证集选定的阻尼 | 同一图像收发器、功率、信道观测、线性分离次数和协方差更新公式 |
| 5A 在相同接收可靠度下是否保留扩展收益 | 成对训练带和不带 ISFFT/SFFT 的收发器，再交叉切换部署波形 | 相同初值、样本、信道抽样、训练步数、二维估计器，以及送入下游解码校准器的帧级可靠度规则 |
| 4A 的 2-bit 系统是否依赖整帧模拟幅度 | 整帧 RMS、离线固定门限、只看先前符号的门限 | 同一模型给出同一组量化前模拟样本，两种系统适用同一门限规则，同收发资源 |
| V2 的收发联合校准是否需要真实长期信道统计 | 用固定常数或过去 24 次已经到达的 CQI 反馈，替代提供给收发器的长期 SNR 和新息水平 | 同一图、同一延迟二块的 5-bit CQI、同一导频估计与物理信道、同一接收侧当前有效 SINR |
| V4 的 64-QAM，在相同绝对噪声底下能否维持优势 | 从按帧调节噪声改为验证集固定发射功率标定和三方法共用的绝对噪声方差 | 原 64-QAM 权重、32 个资源块、相同信道和单位噪声样本；四导频参考的额外 128 个符号计入标定 |

## 复现

路径在 `common.py` 中给出。运行依赖既有 PFS 中的生产模型、原始数据和冻结的 Python 环境。研究结果、临时源码和新权重分别落在用户自己的分析、临时和 checkpoint 目录。每个输出使用独占创建。已完成目录可直接查看。

1. `prepare.py` 从已核验的生产快照生成隔离的普通文件，登记 4B 与 5A 的协议。4B 只改变第二、三次分离的接收观测和协方差。5A 在两侧使用相同的帧平均可靠度；公共二维特征修正器仍可看到局部信道图。
2. `worker.py qualify_cache GPU` 对照图像核实训练输入。随后 `worker.py no_spread GPU`、`worker.py spread GPU` 各训练 7,000 步。固定取最后一步进行正式比较。`wave_test.py register` 在评测前登记交叉部署的四个单元。`after_training.py wave_test GPU` 在训练退出后执行 `wave_test.py` 和统计。训练、评测与注册的原始时间见资源账本。
3. `worker.py noma GPU` 使用冻结的 4B 完整检查点。对照原始源图、噪声、信道和首批逐事件分数后，复用完整臂其余历史分数。`statistics.py noma` 计算来源配对区间。`disjoint.py` 另检验用户三元组之间没有共用图像时的敏感性。
4. `rf.py register` 登记 ADC 配置。`rf.py calibrate DEVICE` 在 256 张验证图上确定一个两模型共用的门限。`rf.py test DEVICE` 逐源比较三种规则。CPU 路径用 `rf_cpu.py` 的设备放置修订，冻结的 Swin 注意力掩码取值不变。`run_rf.py` 与 `resume_rf.py` 保留本次实际执行关系。`statistics.py rf` 汇总结果。
5. `feedback.py calibrate` 只用独立模拟信道拟合两个长期统计量的估计器。`after_training.py feedback GPU` 在空出设备后执行冻结模型评测和 `feedback_stats.py`。该研究另报告按连续八个时隙成块重采样的敏感性区间。
6. 4B 的四臂结果出来后，`pic.py register` 独立登记了常规并行干扰消除对照。`pic_after.py` 等设备空出后执行 `pic.py run`。从五个阻尼系数中按验证集 256 张图的弱用户 PSNR 选择一个，随后冻结，用原测试三元组和信道实现比较三种接收器。`pic_stats.py` 同时报告全体三元组和互不共用源图的子集。
7. `qam.py register` 从固定的 V4 Git 提交核对权重哈希、原始信道和四导频接收器。`qam_stats.py GPU` 在 5A 测试退出后执行功率标定、测试和配对统计。标定使用 256 张验证图，每个发射器只使用一个公开常数增益。每个测试帧在固定噪声下的实际发射能量另附逐源表。
   首次测试在写入 500 图得分前，读取旧表时发生 Git 按需取回失败。实际续行使用 `qam_resume.py prepare` 按原提交的 Git blob 身份准备六份普通文件，再用 `qam_resume.py GPU` 复用已冻结的增益，逐批保存得分。两个执行记录与计算量均保留。四导频接收器在两张合成输入上的新旧接口输出逐元素相同。

所有 NumPy 重采样均以源图或明确指定的源图三元组为单位。common500 与 Kodak24 分开计算。每个方法使用原生图像计算 PSNR 和 DISTS。相同训练种子控制两臂的输入和初始参数；训练时部分 CUDA 归约使用 PyTorch 的非确定性实现，跨运行的逐位复现未经验证。
