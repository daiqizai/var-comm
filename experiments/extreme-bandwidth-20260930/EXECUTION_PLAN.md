# 极低带宽验证执行单：P512 / P1024 与逐尺度方案对比

**版本：2026-09-30 修订版 R1**  
**状态：探索性方法验证，不是最终论文实验。**  
**当前执行范围：先完成 N512 的训练、对照和报告；N1024 保留为第二阶段，不自动启动。**

> 核心问题：在固定视觉 Encoder 与图像 Decoder 的条件下，将 F 压缩到更少的信道坐标之后，数字前缀＋VAR 补全，或纯连续＋VAR 接收插件，能否产生超出匹配训练的纯连续系统的感知／语义收益？
>
> 本轮分别检验两个假设，不再用一个“逐尺度结构有效”的标签概括全部结果：
> - **H_D：数字前缀＋生成补全的完整传输分工是否划算？**
> - **H_R：在相同连续观测上，VAR 插件是否有超出码本投影和静态先验的独立增量？**
>
> 先训练一个 P512。不得自动训练生成模型、P_low_perc、更多预算点或新的修复网络。当前旧队列保持暂停。

### 0.1 历史结果只支持什么

已核对的历史基点为仓库提交 `07cafae0e4bb9469a37723d4d27260895d3c28d3`：Step2 B 的 P_low 新增训练 20k、校准选中新增 20k；当前 LPIPS 导向策略在 −5／−2／1 dB 选择旁路，没有建立符合原目标的 VAR 插件增量。这不等于所有未旁路输出、所有指标或所有预算均无取舍。

本次新问题是**带宽进一步压缩**，不是把已经完成的 N4084 低 SNR 插件测试重新做一遍。

F 为量化前连续特征，形状 `32×16×16`，共有 8192 个实坐标。预算关系为：

| 总复信道次数 N | 总发送实坐标数 2N | 相对 F 的坐标数比例 |
|---:|---:|---:|
| 4084 | 8168 | 约 99.7% |
| 3060 | 6120 | 约 74.7% |
| 2048 | 4096 | 50% |
| 1024 | 2048 | 25% |
| 512 | 1024 | 12.5% |

“4 倍／8 倍压缩”只指坐标维数比例，不是码率、熵或有效信息压缩倍数。不能预先认定 P512 必然模糊，或 VAR 在低带宽必然获胜。

## 1. 固定条件与比较边界

### 1.1 共同视觉接口

完整研究边界为：

```text
原图 → 冻结视觉 Encoder → F
                         ↓
               待比较的传输／接收方法
                         ↓
                        Fhat → 同一冻结 Dc → 重建图
```

- 所有机制主结果使用同一视觉 Encoder、同一 F 定义、同一 Dc 权重和输入预处理。
- 量化器、码本、VAR 全部冻结；P512／P1024 只更新各自的通信收发网络。
- 数字方案额外用 D0 重渲染**同一份接收 latent**，仅作原生完整系统参考；不得为 D0 在 development 重新挑动作，也不得把 D0／Dc 各自最好的指标合成一个工作点。
- 不改变 Stage-A Decoder，不训练生成模型，不把不同 Decoder 的差值解释为中间通信机制增量。

### 1.2 数据与信道

| 项目 | 设置 |
|---|---|
| 训练 | 原 20,000 张训练源图；不加入校准或 development 图 |
| 训练选模、数字动作校准 | 原 1000 张校准图，噪声种子 4101／4102／4103 |
| 插件校准 | 沿用 Step2 已固定的 200 张校准子集及其校准噪声规则 |
| Development | 原 100 张源图，噪声种子 2001／2002／2003 |
| SNR | 1、4、7、13、19 dB；训练、校准、评测集合一致 |
| 信道 | 原 AWGN 实现；每个实坐标噪声方差为 `10^(−SNR_dB/10)` |
| 接收信息 | 与原协议一致的 SNR、实际接收的头信息／正文；不读取干净 F、真实 token 或免费类别 |

连续链只加一次信道噪声。P_N 的各个后处理共享同一份波形、接收观测和 Fhat_P；不得在其输出上再加一层 latent AWGN。

不同方法或不同 N 即使使用相同种子，也不自动拥有相同的接收观测。配对单位是相同源图及预先定义的噪声重复。所有失败均保留。

这些 development 图已经多轮使用，本轮仍是探索性证据，不称新独立测试；不访问 holdout。

### 1.3 能量分成两种口径

**主口径：逐帧同能量。** P_N、P_N＋插件、QPSK 数字链均要求实际总复符号数 N、逐帧总能量 E=2N。数字头和正文全部计入。

**补充口径：原固定星座缩放的 16QAM。** 保留现有实现，逐帧记录实际 E，并汇总均值、最小、P05、P95、最大值。等概率星座平均能量为 2，不保证实际编码帧 E=2N，也不保证实际数据平均恰好为 2。

不得静默增加逐帧 16QAM 归一化或免费传送增益；不得把这个补充口径称为严格逐帧等能量。若 16QAM 显示优势，先保留“当前实际 N/E 下的工作点”结论，严格能量匹配确认留待另行决定。

跨 N 时 E 随 N 减少，图名应为“固定符号功率下的质量—资源曲线”，不是“固定整帧能量下仅改变带宽”。

## 2. 对照组：数字分工和接收插件分别比较

以下方法均以 Dc 作为主输出。M 表示预先固定的数字 PHY 家族：QPSK 或 16QAM。

| 方法 ID | 内容 | 用途 |
|---|---|---|
| `P_N` | 匹配预算独立训练的纯连续系统 | 必须面对的强基线 |
| `D_U_M` | raw 真实前缀＋数字传输＋无条件 VAR 补全 | H_D 的核心数字候选 |
| `D_C_M` | 相同类型数字链，使用付费接收到的类别 | 完整系统补充；标注依赖正确类别的来源 |
| `P_A1` | P_N 输出经无先验量化／融合，允许旁路 | 排除码本和融合本身的收益 |
| `P_A2` | P_N 输出经静态先验修正／融合，允许旁路 | 排除常见 token 偏好 |
| `P_V` | P_N 输出经冻结 VAR 逐尺度修正／融合，允许旁路 | H_R 的候选 |
| `D_prefix` | 对同一次数字接收，仅累计可信／协议允许的前缀，不生成后缀 | 廉价机制诊断；不替代匹配训练的 P_N |
| `D_*_D0` | 已选数字动作的同一接收 latent 经 D0 解码 | 原生系统参考，不进入同 Dc 机制判定 |

### 类别条件的归因

- `D_C_M` 的类别来自既有数据／应用标签，必须注明来源。付费发送解决的是传输开销，不证明实际应用中能免费得到正确类别。
- `D_U_M` 保留相同长度头信息，补全时固定使用经过验证的无条件接口，不能暗中使用真实／收到的类别；该配置是保守的等头开销控制，不代表最优无条件协议。
- C 与 U 的部署动作可以各自在校准集按相同规则选择。为了隔离类别作用，另对**同一动作、同一接收前缀**做 C/U 渲染对比，不能把不同动作的全部差值归给类别。
- 只有带类别版本胜出时，仅报告“类别辅助的数字系统取舍”；不声称在相同 F 信息条件下，逐尺度机制已胜出。

## 3. 数字链：raw 真实成本、模式与选择

### 3.1 预算与可装载范围

沿用已验证的 68 次复信道 header PHY。正文可用次数：

- N512：`N_body=512−68=444`；
- N1024：`N_body=1024−68=956`。

原始前缀 payload 为：

| m | token 数 | raw payload bit |
|---:|---:|---:|
| 4 | 30 | 360 |
| 5 | 55 | 660 |
| 6 | 91 | 1092 |
| 7 | 155 | 1860 |

本轮不做算术编码。不得使用历史 m6 约 900 bit 的算术均值替代 raw1092。

按原稿保留正文 CRC16＋6 位尾比特，有效码率为：

\[
R_{eff}=(B_{raw}+22)/(b_M N_{body}),\qquad b_{QPSK}=2,\ b_{16QAM}=4.
\]

保留 `R_eff≤0.9` 且现有实际母码／rate-matching 能合法编码的动作。下面是按账本计算的必要条件，不是可靠性保证：

| N | 调制 | m4 | m5 | m6 | m7 |
|---:|---|---:|---:|---:|---:|
| 512 | QPSK | 0.4302 | 0.7680 | 排除：1.2545 | 排除：2.1194 |
| 512 | 16QAM | 0.2151 | 0.3840 | 0.6273 | 排除：1.0597 |
| 1024 | QPSK | 0.1998 | 0.3567 | 0.5826 | 排除：0.9843 |
| 1024 | 16QAM | 0.0999 | 0.1783 | 0.2913 | 0.4922 |

因此，N512 的 QPSK 不能传 m6；不能把 m6 的无噪声参考直接当作它的预期接收质量。

### 3.2 不增加隐含控制信息

- QPSK 与 16QAM 作为**分别登记、收发端预先已知**的 PHY 家族，分别校准、分别报告。
- 2-bit 模式字段在本实验中固定映射到 m4／m5／m6／m7，映射在执行前冻结，不能沿用旧模式映射后由真值替接收端纠正。
- 2 bit 不能同时独立表示 4 个 m 和 2 种调制。本轮不新增逐图混合调制选择器，不把跨 PHY 家族的事后最好结果包装成一个免费自适应协议。
- 每个家族内部只按 N、SNR 使用校准冻结的 m；不按 development 源图选动作。

### 3.3 校准选择规则

保持原稿“LPIPS 为主、相对可靠性动作有 PSNR 约束”的思路，并明确执行含义：

1. 对每个 `N×PHY家族` 评测全部合法 m；头／正文失败均计入质量和失败率。
2. 可靠性参考动作沿用现有已登记 BLER 选择规则，先将完整排序与并列规则写入 config。若没有可直接复用的规则，本单的明确后备规则是：最小化头失败或正文 CRC 失败的帧比例；完全并列时优先较大的 m，再按固定动作 ID 排序。不得根据结果临时改变规则。
3. C、U 分别在同一家族内部选择：候选平均 PSNR 不低于该条件下可靠性参考动作的平均 PSNR−0.25 dB，再选平均 LPIPS 最低者。并列优先失败率更低者，再按固定动作 ID。
4. 策略在读取 development 前冻结。选择使用 Dc 输出；D0 仅重渲染同一已选动作，不重新选 m。
5. 未选候选的数值保留作诊断，不在 development 重选。以 LPIPS 选策略，不代表已经搜索了 DINO 最优或所有质量目标的最优资源需求。

### 3.4 失败处理与无噪声参考

头失败、正文 CRC 失败、硬候选及可信前缀状态沿用实际已验证的协议。不能仅凭 CRC 失败就删图，也不能把未知 token 换成真值。若短 m 需要新模式映射，只扩展模式域，不同时发明新擦除／回退规则。

按 Source A 的相同图像、量化累计映射及生成设置补算 m4、m5 的 D0／Dc 参考；m6、m7 有兼容产物则直接复用。生成随机性及采样设置沿用已冻结协议，不做最好样本选择。

m6 的历史无噪声参考为：D0 约 `16.593995 / 0.295587 / 0.791689`，Dc 约 `17.173915 / 0.278304 / 0.786601`。这些只是特定表示／Decoder 的实测参考，不是数学上界或有限带宽成绩。

## 4. P512 / P1024 训练：只建立匹配预算的强控制

本阶段只启动 P512。P1024 经确认后复用同一协议。

- 结构族：复用当前已验证的 PureContinuous／P2048 预算接口，宽64、3个残差块；只调整与 N 有关的通信瓶颈和必要输出／接收形状。
- 使用真实 N 长度独立训练，不能把 P2048／P4084 在推理时直接截短当作已训练 P512。
- 以**一份明确的 P2048 实际训练登记**作为配方基准，核对初始化、优化器、数据顺序及归一化。不要混用 P_low 的低 SNR 微调权重或另一预算的更长训练历史，却称“唯一差别是 N”。必要的头部重初始化和继承范围写清即可。
- 训练 SNR 为 `{1,4,7,13,19}`，沿用该配方采样规则。
- 损失保持 `MSE + 0.1 LPIPS + 0.01 normalized latent error`；归一化尺度复用共同 F 的既有定义。Dc 冻结，但图像损失可经其向通信网络反向传播。
- 使用一个预先固定的训练 seed；不根据 development 追加随机重启或挑 seed。
- 新增20,000更新为首个里程碑；每2500更新在完整1000校准图、五SNR、三噪声上评测并选模。

**本修订新增的预算边界：每个新模型最多40,000更新。** 在20k／30k边界，只有最近两个2500步区间的完整校准 utility 相对下降均≥0.2%，才再延长10k；否则按已有候选中最低校准 utility 选中并停止。到40k仍改善则标注训练预算截断，不称理论收敛。

如该规则与拟复用训练器的原登记不同，保留原资产，为新实验明确登记上述规则；不热改旧任务。保存可续训状态，不因某一方案暂时输赢改变更新上限或损失。

旧 P2048／P3060／P4084 只作为较大预算参照，不重训。优先复用同源、同Dc、同指标协议的已发布结果；缺乏兼容性证据的点单列，不为画一张曲线自动重跑所有旧矩阵。

## 5. P_N＋VAR 插件：复用机制，不新增搜索范围

插件使用 Step2 修订方案的既有实现，只把基模型替换为当前选中的 P_N。为新 N **重新校准**误差统计和融合，不能直接复制 P4084／P_low 的方差。

### 5.1 固定算法

- 完整十尺度：`[1,2,3,4,5,6,8,10,13,16]`。
- A1 无先验；A2 为静态 token 频率；V 为冻结 VAR 的无条件历史判决先验。
- 沿用经验误差似然、逐尺度 argmax、原码本坐标及官方累计映射，不宣称精确物理后验。
- λ 乘在 log prior 上；每个 SNR 十尺度共享一个 λ，网格固定 `{0,0.25,0.5,0.75,1,1.5}`。
- 不用类别、CFG、采样、束搜索，不训练额外模型。

### 5.2 选参和旁路

沿用 Step2 的闭环校准规则：各候选分别校准融合；PSNR 相对 P_N 下降不超过0.3 dB时，选LPIPS最低者；13 dB校准约束为0.2 dB。候选不可行，或LPIPS不优于P_N，就选择真正 `BYPASS`。

λ=0仍是码本量化＋融合，不等于旁路。旁路必须原样返回同一份 Fhat_P。A1、A2、V均允许旁路，不把输出相同记为VAR修正成功。

保留原未旁路候选、固定λ=1参照；它们不按development升级为主策略。该策略是LPIPS导向，旁路不意味着已排除所有DINO导向的工作点。

### 5.3 共同融合权重消融

继续使用 A1 的校准融合权重，对 A1、A2、V 的未旁路选中候选各重渲染一次；不重新选λ。候选与 Fhat_P 直接复用，不增加传输或重新跑VAR。

同时保存：基模型F误差、融合前F误差、融合后F误差。token诊断只解释机制，不设“前四尺度失败即停止整个方向”的门槛。

## 6. 指标、统计和主要比较

### 6.1 指标

- PSNR、LPIPS（alex）、DINO cosine，使用同一图像预处理及版本。
- `||F−Fhat||²` 原坐标平方和；若另列均方，明确除以8192。
- DINO<0.6、LPIPS>0.35的帧比例；仅称“所设指标阈值的失效比例”，不直接称真实业务可靠性。
- 对主张DINO增量的比较，用同一固定错位排列计算匹配增益减错配增益。LPIPS分支不强制同时有DINO改善。
- 错配检查不证明同类别实例细节或文字都真实；须与固定样例一起解释。

### 6.2 配对与统计范围

每张源图先平均三次噪声，再用共同索引作10000次源图配对bootstrap，seed20260930，报告逐点95%百分位区间。所有预设预算、SNR、对照都报告；未作多重比较校正，单点通过只称探索性单点信号。

不能把三个噪声当成三张独立图，也不能把本轮单个训练seed的图像bootstrap当成训练seed置信区间。

### 6.3 必须报告

| 比较 | 层级 |
|---|---|
| D_U_QPSK vs P_N，同Dc | 核心H_D，逐帧同能量 |
| D_U_16QAM vs P_N，同Dc | H_D补充，实际帧能量约束不同 |
| D_C_M vs P_N；同一动作的D_C_M vs D_U_M | 类别辅助取舍与归因 |
| P_V策略 vs P_N、P_A1策略、P_A2策略 | 核心H_R，三项均不能遗漏 |
| V_common vs A1_common、A2_common | 候选内容与融合校准分离 |
| 数字VAR补全 vs 同次接收D_prefix | 生成的局部作用诊断，不单独宣布方法成功 |
| D0 vs Dc，固定同一数字动作／latent | Decoder影响诊断，不混入通信机制增量 |

计时固定10张源图×2次测量，沿用项目warmup。主边界为CPU接收波形→CPU图像，包含P接收网络及实际修正；旁路和运行VAR分开。数字另列源编码／TX时间，尤其保留生成计算代价；不开展硬件优化项目。

## 7. H_D / H_R 判定：保留取舍，不包装为全面胜出

### 7.1 两个假设各自判定

**H_D：数字分工的感知／语义取舍。** 对每个 `N×SNR×PHY家族×类别条件`，在同Dc下比较D与P。满足以下任一分支，记为该点“明显增益”：

- ΔLPIPS≤−0.02，且95%区间上界<0；或
- ΔDINO≥+0.02，且95%区间下界>0，并通过相对P的匹配特异性检查。

无条件QPSK结果具有最直接的同信息条件、逐帧同能量解释。只有16QAM或类别辅助成立时，按对应资源／信息条件限定结论。

**H_R：VAR插件的独立接收增量。** P_V的同一个已冻结策略，在同一N／SNR下，必须沿**同一个质量指标分支**超过P_N、P_A1、P_A2三项控制；幅度和区间规则同上。另保留原插件选参的PSNR可行性要求。

只超过P_N而未超过A1／A2，不能记VAR独立增量；选择旁路时记 `BYPASS_SELECTED`。共同权重结果用于判断增量来自候选内容还是主要依赖融合校准，不再新设一项苛刻“生死门槛”。

### 7.2 PSNR与F误差如何处理

保留原稿的感知取舍定位：H_D不额外要求PSNR获胜，但必须同时报告实际ΔPSNR、F误差和样例。结论写成“以多少像素／特征失真换取多少感知或语义改善”，不能写“恢复F全面更准”。

H_R仍明确报告插件预先PSNR约束与实际代价。不得通过发展阶段重新放宽约束，把原不可行候选改成胜者。

### 7.3 不到0.02时不要直接写“没有作用”

| 标签 | 解释 |
|---|---|
| `CLEAR_GAIN` | 达到预设幅度与区间要求；标明是H_D还是H_R以及条件 |
| `SMALL_SUPPORTED_GAIN` | 对所需直接控制有同指标方向的统计支持，但不到0.02；同时报告代价 |
| `PARTIAL_GAIN` | 只胜部分控制，或仅特殊Decoder／类别／能量条件成立 |
| `BYPASS_SELECTED` | 校准选择原连续系统，不计为修正成功 |
| `NO_GAIN_ESTABLISHED` | 当前配置、网格和数据未建立增量，不作普遍不可能结论 |

任意单点获胜不证明整个预算区间获胜，也不证明“低带宽天然适合VAR”。未选DINO候选若有取舍，只保留诊断，不事后换选模目标。

## 8. 执行顺序：当前只交付第一阶段

### 第一阶段：N512，当前授权范围

1. 冻结本单协议，核实共同Dc、P2048参考配方、数字模式映射与能量家族。
2. 复用或补算m4–m7源表示参考，完成N512合法数字动作的校准。不得把无噪声参考列为通信成绩。
3. 训练并校准选择P512；不因数字侧提前看到结果改变其loss、seed或训练预算。数字发展集和P512发展集在各自策略冻结后统一交付。
4. 用选中P512生成真实接收特征，完成A1／A2／V校准、旁路与共同权重消融。
5. 完成N512 development主表、配对区间、固定样例及接收代价；报告H_D和H_R，不只交付训练曲线。
6. 第一阶段交付后暂停等待决定；不自动启动P1024，不自动恢复旧队列。

必要自检只保留：小范围旧P接口复现、真实N/E、短m数字无噪声回环、类别未泄漏、码本极限、λ0等于A1、旁路等于P。不要求为这轮再创建复杂发布器或重跑全部历史对照。

### 第二阶段：N1024，后续确认范围

沿用本单已冻结的候选、目标、数据及选择流程；只改预算并重新训练／校准对应模型，不能根据N512 development扩大λ或m网格。

N512无增量不能直接否定N1024：数字可用尺度、调制及可靠性不同。N512有增量也不能直接推断N1024同样成立。第二点用于界定取舍，而不是“继续找一个能赢的点”。

原稿“约5个工作日”保留为估计，不保证两轮训练和校准必能按此完成。更新上限与已完成结果必须分开披露；超时不删除负结果，不冒称已收敛。
