# 接收创新量受控研究

遵守VAR_COMM及根任务书v2。当前实验只改变接收计算，冻结共同204×30发送器及WeTok视觉模块；六臂必须使用逐样本完全相同的y、名义SNR和训练机会。
原geometry和接口结果只读，代码引用旧实验冻结模块，不在旧源码中打补丁。新输出仅在VAR_COMM/outputs。
Encoder参数冻结不等于禁止对其输入求导：接收假设重编码必须保留输入梯度，实际GT发送可不建图。RX API只能接收y和名义SNR，GT只作训练监督或事后诊断。
重编码、似然优化和迭代本身已有ISEC等先例，不作为本项目原创。六臂的计算差、额外Encoder调用与历史训练成本需记录；全y多阶段读取不是逐包渐进。
