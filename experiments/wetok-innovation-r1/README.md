# 固定发送器的接收创新量实验

问题：更强geometry已减少发送映射损失，但普通条件历史在该geometry下反而损害主区间LPIPS/DINO。检查接收端是否能利用当前源假设对实际y的预测误差，以同样的接收信息改善重建。

该方案不是ISEC或已停止量化cell修正的改名。先验/重编码/迭代本身不是新颖性；实际检验是轻量通信域的固定阶段创新量是否优于同计算的预测特征控制及非多尺度迭代，并最终胜过合理强系统。

当前已通过CPU及真实GPU无更新检查并启动首1000更新流程，状态见docs/CONTINUE.md。协议见docs/protocol.md，参数/源数据等沿用上一轮冻结资产。所有新图像输出仍为continuous_mean，视觉Decoder只在最后调用；尚无本实验训练/开发收益结论。
