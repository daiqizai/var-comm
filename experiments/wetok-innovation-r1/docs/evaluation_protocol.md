# 固定发送器接收研究的评测资格

当前训练与校准不变。最终评测只读取完整校准选中的接收checkpoint，不按development改变步骤、SNR、门控或输出。

六个新接收器逐源/逐SNR/逐噪声必须得到**同一s和y**，都来自冻结的204×30 single发送器；保存两者hash并核对源与噪声。三种原geometry已冻结输出与四个强系统参考另列，不把其不同发送器说成同y。总13方法/27300主行，另600个Deep固定支持点。

重点比较多尺度创新量与预测特征控制、state-history、full-grid创新量及single/no-history；原父模型只反映增加训练的总收益，不替代同预算续训控制。所有额外E调用和最终视觉Decoder计入RX时延，source/RX传输耗费按真实0+3060/68+2992分列。

主区间1/4/7，其余七SNR完整保留；先每图平均三个噪声和指定SNR再paired bootstrap。41组关系、六指标、八SNR组共1968区间。旧模型与强对照的图像/指标需复现，所有失败图保留。原geometry父/其它端到端系统的旧时延不伪称本次测量。

本轮尚未实现或复现完整ISEC强接收基线，不声明超过它。若候选取得系统级收益，还需补齐最近强对照、必要训练重复、鲁棒性及独立holdout，不能把重编码或一致性本身当创新。

实现入口`scripts/evaluate.py`、`scripts/analyze.py`。每源提交前后检查GPU独占；中断只重跑未提交源，每个session重新预热，保存失败和续跑已观察耗时。CPU分析重算实际s/y与预定AWGN、图像SHA/PSNR、连续特征MSE与诊断BER；不是独立训练重复或另一个Decoder实现的重渲染。源图分组不得重复，选中checkpoint/共同Encoder的SHA和实际新增更新预算逐行复核。

17项CPU测试覆盖数据网格/配对bootstrap/预算与信息边界、实际评测器的中断续跑/共享张量、保存波形与RGB/特征的算术核查、只读硬件记录/时序平衡，以及不改变输出的no-history推理裁剪。旧参考预检441行和21个父点信号通过；新接收器GPU评测仍待完整校准后执行。预检和测试不是性能gate，不据其通过宣布通信成功。

训练中曾观察到软件温控降频；不更改GPU时钟/功率/风扇或训练配置。新评测按固定frame序号循环轮换六臂时序，每个SNR下每个方法在各次序出现50次，全网格每个次序350次；不改s/y、随机噪声或图像输出规则。每源前后保存温度、时钟和节流标记；时延是该实测硬件状态下的结果，不宣称无节流极限。旧参考时延仍不混入本轮时延排名。

no-history的4/8尺度只提供训练辅助监督，不参与最终16尺度图像的计算依赖。图像评测允许仅做16尺度读取，不强迫基线计算无用阶段；训练和校准状态监督保持原样。`inference.py`禁止进入训练图，逐帧在计时外与原完整路径核对logits、诊断hard符号和实际Decoder输入均逐位相同；noiseless同样核对。这是等价实现优化，不是新的输出规则。条件状态读取不能如此删除。

配对bootstrap区间是逐比较的95%描述区间，未做多重比较校正；本轮反复使用的development不能替代独立确认。
