# 固定发送器、同波形的接收机制比较

## 问题与已有证据

204×30显著改善了同N/E图像质量和源恢复，但其条件版主区间LPIPS约0.2459，弱于同geometry无历史约0.2422，仍未胜强系统。16张固定训练源的诊断显示19dB下，E(mu)对y的残差约为实际噪声能量的5倍；noiseless仍约0.055–0.058/real coordinate。低SNR残差反而小于噪声，不能盲目强迫一致。

这个小诊断不是图像增益或容量证明。E(mu)是公共连续函数的扩展，mu并不是合法native码字；GT只用于诊断，不进入本接收器。新假设是把可观测的预测误差及其噪声尺度交给已训练的接收更新，而不是只接收归一化的历史状态。

## 固定项与共同起点

选用上一轮single_pass完整校准所选的204×30模型作为共同发送器和接收初值。选single_pass是为了共同简单发送/接收基准，不按开发图逐样本选择。其完整2000+5000历史单列；新六臂共享同一冻结Encoder数值，复制同一Receiver初值，新增模块按同seed初始化。

本次只训练接收器及融合模块，全部使用fresh Adam；共同Encoder与官方WeTok Encoder/量化器/Decoder冻结。所有臂的真实s/y每batch仅生成一次并复用，保证是同一收到的信息。N=3060复信道，E=6120，平均复能量2，每实维噪声1/gamma，训练SNR仍1/4/7/13/19。名义SNR为双方共享假设，无class/caption/header/反馈/真实前缀。

这是联合训练系统之后的接收端受控修订，不声称新阶段也更新了发送端；若后续联合微调须另立同预算比较。

## 六臂

| 臂 | 接收结构与额外计算 |
| --- | --- |
| single_pass | 原一次性接收，保持有力同预算续训控制 |
| multiscale_no_history | 4/8/16网格，不读取前状态 |
| multiscale_state_history | 4/8/16读取自身前状态，无重编码特征 |
| multiscale_prediction_features | 4/8/16，重编码自身假设；额外特征为E(mu) |
| multiscale_innovation | 同样重编码/投影/门控，额外特征为y−E(mu) |
| full_grid_innovation | 16/16/16三次读取，同创新量与参数，作为非多尺度、较高查询计算控制 |

前两阶段源监督一律对应GT Fq的4/8平均状态；full-grid中间16状态下采样到相同监督尺度，不额外监督完整GT细节。最终是continuous_mean，bit CE仍仅辅助。

多尺度假设保留初始全分辨率均值的细节，加入上采样的前状态粗修正，再裁剪到[-1,1]。这是公开的接收计算，不拿真值补齐后缀。冻结E的重编码保留输入梯度；大型视觉Decoder只在最终图像输出调用，不置于重编码内循环。

预测特征/创新量两臂有相同的E调用次数、投影和门控参数。门控只取名义SNR、阶段编号和可观测残差能量/预期噪声比；两者使用相同标量输入，不给创新量臂单独额外答案。比例只用于门控时detach，特征向量保留梯度。投影初值0，门控末层初值sigmoid(-2)，不做温度退火或额外参数搜索。

## 对照解释与成本

核心比较是innovation对prediction_features（排除只是多用冻结E的非线性特征），以及innovation对state_history；full_grid_innovation用于检验是否只是普通迭代。所有方法读完整y，不称渐进传输。

额外融合增加少量参数与两次共享E前向，必须计入RX时延；不能强行让不使用它的基线做无用计算。full-grid有相同参数与轮数但更多查询计算，作为更强计算控制；若只省时延而不损质量，也须按实际数据报告。

## 训练、选模和界限

六臂同5000新更新计划，首1000为里程碑，沿原sampler的global step7000开始配对数据/增强/SNR/噪声。MSE+0.01LPIPS+0.01BCE+0.01state不变，LR1e-4、micro1/effective4、clip1。预定完整校准0/1000/2500/5000，monitor每500只观察；完整LPIPS最小选模，DINO不训练/选模，PSNR逐点报告。

按实际profile核算本机费用再执行；首估六臂5000接收训练约3–4 GPU小时另加校准，是估算而非研发上限。当前不访问新holdout，不因残差或BER下降宣布成功。非有限/接口/物理检查失败保留现场，不能改SHA或容差放行。

ISEC已研究似然/先验和重编码迭代，DeepJSCC-f已有反馈逐次精化；本方法不声称这些思想首次出现，也不把反馈信息免费给TX。候选最终必须由同信息下的质量/资源/时延、强系统和独立验证支撑。
