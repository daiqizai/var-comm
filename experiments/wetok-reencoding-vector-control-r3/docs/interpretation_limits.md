# R3向量对照的解释边界

本轮严格控制参数、三次full-grid读取、两次E调用、残差能量门控、初始化与完整训练机会。唯一代码干预是融合q而不是y−q；这个比较可以排除“仅仅多了同样的重编码与融合工作就必然得到相同收益”的解释。

它并未把两种向量的幅度统计强行归一到相同水平。q与y−q的方向、大小及随SNR变化的统计都可能不同，因此即使最终有差，结论也只限于**整体向量构造**，不能进一步单独归因坐标方向、纯相位或某个精确似然量。若以后需要更窄的方向主张，应另立合适对照，而不是事后扩大本轮结论。

两种Joint训练映射会一起适配E/R，不是固定同一发送器/y的纯接收端因果实验；接收端只可用实际y、名义SNR、自身状态和共享模型。μ是连续状态，不保证是合法native消息；同样的标量残差能量在两个分支都保留。

本轮首1000校准好坏不改变已登记的10000训练机会、主区间和选模规则。校准、development、训练重复、新holdout的证据层级不能混同；也不能把全网格迭代改称next-scale。
