# R3登记：向量残差是否超过通用重编码特征

2026-09-14，R2完整结果之后制定；当前未实现、未训练。

## 通信问题与可证伪对照

R2在同N/E下，full-grid innovation主LPIPS0.220543优于普通full-grid0.230345，但增加6417参数、两次内部E及1.68758ms RX时间；仍落后数字自适应/感知Deep。4/8/16则落后普通full-grid，因此不再机械续训此固定空间分层。

需要知道：收益来自按信道坐标构造的向量残差，还是通用重编码特征/额外融合已经足够。此项只做已有原型归因，不声明重编码、残差或神经网络本身新颖。

固定三次16×16读取，在每次后续读取之前，用自身连续恢复状态构造μ，计算q=E(μ,γ)。

- 原残差臂：融合向量v=y−q。
- 新控制臂`full_grid_prediction_features`：融合向量v=q。
- 两者均计算同样定义的残差能量比，并通过同样SNR/阶段/能量门控。新控制仍有标量残差信息，本比较只考察向量内容，不等于完全移除一致性信息。
- 两者都有相同两次E、相同回投影、相同6417附加参数和三次读取；不删除某臂的工作量来制造速度差异。

`μ`不一定是合法native二值源，E(μ)不等于后验平均码字。本轮不把它称为精确MAP/似然译码，也不把生成或软状态冒充被协议可靠恢复的源消息。

## 初始化、训练与复用资格

匹配原残差臂开始时的**共同7000 single父点**（2000表示恢复＋5000图像训练），不是当前R2选中checkpoint。视觉模型、204×30通信geometry、连续均值输出、三次full-grid读取都不变。

新参数种子沿用2026091313；融合投影为零初始化，其余参数与原臂相同。必须逐值核验全部初始参数，并检查零融合时实际初始函数相同。不能因参数形状相同就跳过函数检查。

AdamW从fresh0开始，与原残差完整历史一致：lr1e−4、betas(0.9,0.99)、weight decay1e−4、clip1，有效batch4/micro1、FP32，原损失MSE＋0.01LPIPS＋0.01bit BCE＋0.01state。通信E/R均训练，视觉Encoder/量化器/Decoder冻结。

原20k训练/两视图、独立1k校准，训练SNR1/4/7/13/19；global data7000→17000，完整10000更新机会。同数据顺序、增强、SNR、标准噪声与旧残差臂对齐。四处不能混淆：父点7000、分支fresh Adam0、分支10000机会、global17000。

完整校准点0/1000/2500/5000/7500/10000，500步固定100图监控不选模；完整1k平均LPIPS最小、同值取早，DINO不进入训练/选择。若逐值/函数资格证明起点相同，可以复用封存起点校准，不能免费给新臂更多选择机会或抹去旧成本。

原Joint residual10000已由Grid＋R2按相同规则完成，满足完整历史/初始化/数据/损失资格才复用，不能通过修改旧哈希放行。不同Joint发送器训练后产生不同s/y，因此只声称端到端表示选择的对照，不声称固定同一发送器/y下的纯接收消融。

## 物理与信息边界

原生WeTok Fq32×16×16（4组8-bit、8192rawbits），N=3060复信道使用、0header、总能量6120、平均复能量2，实噪声方差1/γ。不提供类、caption、真前缀、接收噪声或反馈。整个y在各次读取都可见，是全局发送/多次接收，不是渐进传输。

不改视觉骨干、FEC、输入尺度/尺寸、功率分配、geometry、loss或参数规模；不同时加入新保护网络。预计新单臂10000训练和校准约1.5–2小时本机GPU相关进程时间，以原0.41s/update实测修正，不是研发总预算上限，也不保证共享时速度。

## 评测与决定

原100图仍是development、七SNR、三原噪声；主1/4/7 dB，支持点/高SNR/无噪诊断全部保留。主要比较新prediction-vector与R2 joint residual，同10000机会；同时保留R2普通full-grid、single、MS及旧强系统，特别是同WeTok数字和VAR自适应/Deep，不只比较弱对照。

沿用源图聚合后paired bootstrap，报告PSNR/SSIM/LPIPS/DINO/严重失真、真实诊断BER、通信账本、训练时间、参数和独立RX时间。质量与时延分开；共享资源只能用于明确准入的质量阶段，计时遇竞争等待，不停他人任务。不读取新正式holdout。

若通用prediction向量同样好，不再把当前增益独立归给物理残差方向；若残差仍好，保留这一有限归因，但仍不能掩盖强系统主区间差距或把普通迭代叫next-scale。后续是否进入发送侧结构/保护研究、训练重复或新holdout，依据完整结果，不预先宣布成功。
