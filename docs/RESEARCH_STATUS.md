# Research status: 2026-09-16

本仓库记录VAR/next-scale在有限资源图像通信中的研究，而不是把历史目录中的diffusion名称当成当前主线。

| 研究问题 / 路线 | 当前证据 | 当前决定 |
|---|---|---|
| 真实prefix＋VAR后缀补全 | 有感知补全价值，但存在tokenizer及生成不确定性损失 | 保留机制与数字系统参考 |
| 源尺度 / FEC与数字模式选择 | 已完成真实整帧raw、算术码、校准策略与所有失败输出评测 | 保留强数字对照；不冒称首次提出自适应 |
| 无训练接收修正 / 列表搜索 | 代理约束或正确率改善并不自动转为平均图像优势 | 已停止相应候选，保留负结果 |
| 学习式prefix通信、WeTok R2/R3 | 部分结构有增量，需区分训练资格、低/高SNR和计算成本 | 作为历史学习参考，不重启旧队列 |
| 固定m7数字＋连续源纠偏 | 实际基图条件有像素及失真—感知结构增量 | 三权重收尾后结束当前固定混合主线 |
| 不确定TX CSI下的鲁棒源率 / 保护 | 已核查三篇已发表原文，需求可测，具体技术差异仍不足 | 仅报告和未执行草案；没有新训练 |
