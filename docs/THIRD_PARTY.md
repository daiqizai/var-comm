# 第三方与外部资产边界

本次只发布本项目自有的通信、训练控制、统计/审计代码与研究报告，并保留外部依赖说明。没有把第三方vendor、模型权重、数据集像素、论文PDF或虚拟环境作为本仓库内容上传。

- VAR及其VQ autoencoder来自官方实现；next-scale、多尺度残差量化不是本项目原创。
- DINOv2、LPIPS及所需视觉权重由各自上游提供。
- WeTok视觉模型依赖不随本次快照分发，`experiments/`保留的是本项目通信及评测部分。
- 若要运行完整GPU链，还需原历史项目的`cadsd_jscc`组件等本地依赖；仅有本公开仓库不能冒称已实现全量端到端复现。
- 图像数据、第三方代码、权重及论文应从其授权来源取得并分别核对许可。公开的图是指标曲线，不是重新分发ImageNet照片。

与研究最直接的三篇CSI原文、DOI、假设和不足已列在`reports/tx_csi_uncertainty_literature_preparation_20260916.md`。本仓库没有声称穷尽相关工作，也不把标准鲁棒适配或贝叶斯风险决策冒称首次提出。

本次整理没有额外赋予整个仓库MIT/Apache等统一许可证；需要统一许可时应由仓库所有者另行明确。
