# 近期图像通信研究的价值与论文定位

11 月 20–22 日的六个研究分支是 V1、V2、V3、V4、Direction 3 和 Direction 4。把 V1/V2、V3/V4 分别作为连续工作，把 Direction 3、4 中不同的研究问题分别考察，再计入已完成的 5A、5B，共有八条路线。以下判断区分“有独立的研究问题”和“现有证据足够支撑哪些主张”。

**我会优先保留 V1/V2 和 4B 两篇独立论文。** V1/V2 的证据最完整，能说明部署后什么时候改接收端、什么时候值得连发送端一起改。4B 的新增机制对照最有区分力，能说明为什么受强干扰的弱用户从联合接收中获益。下一顺位是独立推进 5A，以及用 V3/V4 组织一篇波形论文并纳入 3A。4A 和 5B 可保留独立课题位置，3B 的分组结果适合作为后续系统设计依据。

| 路线 | 最值得回答的问题 | 我会怎样安排 |
|---|---|---|
| V1/V2 · 信道反馈失配 | 接收端已经按各频块可靠度校准后，发送端还值得根据过时反馈做多少修正？ | **合为一篇，最成熟。** 对每种主干给出发送端的条件性增益，并保留反馈及时或现有自适应能力较强时的反例。 |
| V3/V4 · 带内参考与有限星座 | 没有单独导频时隙时，接收端怎样恢复图像尺度和噪声水平，在有限星座下还能保留多少质量？ | **共用一篇波形论文。** 已知参考占用 3/384 个方向，有源成分合计占约 5.73% 功率。可把资源账、有限星座与接收性能放在同一比较中。 |
| 3A · 多天线空间复用 | 多流混合后，带内参考能否支撑信道矩阵估计和逐流恢复？ | 并入 V3/V4 的多天线验证。相对本地四导频 LMMSE 链路，2×2、4×4 分别高 3.805、3.368 dB。若单独立题，同条件的强盲 MIMO 接收器才是直接对手。 |
| 3B · 不完整收包 | 一个资源块到达时，究竟带来哪些空间位置和哪些特征通道的信息？ | 保留分组和可靠度补全的经验。配平实验把空间变换从主要贡献中排除了，暂缓独立立题。 |
| 4A · 1–2 bit 射频接收 | 幅度被量化、相位又在漂移时，怎样恢复图像尺度？ | **有独立硬件问题。** 相同失真链路上，10 dB 比已训练黑盒高 1.134、0.924 dB。现有证据来自仿真，2-bit 接收器使用逐帧模拟 RMS 控制量化门限，独立论文需清楚交代这种增益控制的代价与适用条件。 |
| 4B · 过载多用户上行 | 本用户图像已经去噪后，利用另一个用户的估计来消除干扰，对弱用户还有多少帮助？ | **优先独立。** 同参数量、同去噪先验对照仍给出明确的弱用户增益。可写带内签名估计后，潜变量级并行软消除怎样缓解过载和功率不均。 |
| 5A · 快时变波形 | 在同样的二维信道估计和带内参考预算下，哪些图像表示能利用时频扩展分集？ | **可单列高移动图像通信。** 对同估计器的 OFDM 报增量，同时报告训练波形与测试波形不配套的结果。已存在 OTFS 图像通信工作，论文价值落在波形、图像表示和可靠度怎样配合。 |
| 5B · 极窄带感知重建 | 只有 768 或 1,536 个复数符号时，用共享视觉表示可以换得多少感知改善，要付出多少保真代价？ | **保留为独立的视觉通信研究。** 码本在训练时带来小幅感知收益，推理时的修正会抵消一部分。当前最有说服力的是连续表示和冻结视觉解码器的系统表现。 |

这些路线与旧 NeST-Com 的关系也有区别。前七条主要使用 SwinJSCC 图像特征和新设计的收发链路。V4 另测有限星座。5B 共享了 VAR 的图像 VQ-VAE，但传输连续潜变量，也没有运行 VAR 自回归补全或 NeST 的独立终止数字前缀。用原 NeST 的名称统称这批结果，会让读者误解实际比较对象。[各路线原理、历史结果及最接近的论文](DIRECTIONS_zh.md)

## 哪些数据改变了对贡献的判断

- **V1/V2 有可验证的适用条件。** 500 图、10 dB、AWGN 预训练主干、相关系数 0.90 时，反馈滞后两块，联合校准比冻结系统高 2.930 dB。相对只校准接收端，发送端再提高 0.345 [0.316, 0.376] dB。零滞后时这项增量为 −0.031 [−0.044, −0.019] dB。Rayleigh 预训练主干在零滞后时仍有 +0.496 dB，原模型也决定了部署时该改哪一端。[三种主干的结果](historical_feedback_scope.csv)
- **3B 的大幅增益在去掉空间 Hadamard 后仍然存在。** 500 图只收前 8/32 块时，同装包、同接收器、恒等空间变换比 raster 高 6.758 [6.523, 6.991] dB。两臂同种子训练后，加回 Hadamard 的净效应是 −0.052 [−0.067, −0.038] dB，DISTS 也变差。整块擦除对块内每个系数使用同一掩码，块内空间旋转不能把缺块的信息挪到另一块。[完整配平结果](evaluation/holo/paired.csv)
- **4B 的收益集中在过载弱用户。** 固定双轮去噪、监督和 170.2 万可训练参数，增加跨用户波形回写、干扰方差更新及重新分离。500 图三用户、两天线、13/8/4 dB 时，弱用户从 18.703 升至 21.587 dB，差值 **+2.884 [2.783, 2.993] dB**，三用户平均 +1.520 dB。Kodak24 弱用户 +2.362 [1.937, 2.831] dB。双用户 10/10 dB 的平均增量降至 +0.213 dB。完整接收器使用三次线性分离，对照使用一次，所以结果衡量整个迭代接收机制的收益和相应的额外计算。[全部角色与工况](evaluation/noma/paired.csv)
- **5A 有跨图像集的正结果，而且依赖训练。** 10 dB、归一化多普勒 0.10，完整扩展系统比使用相同二维估计器的 OFDM 高 0.395 [0.367, 0.423] dB，Kodak24 高 0.396 [0.312, 0.483] dB。在 256 张验证图上固定逐位置可靠度，仅打开扩展，扩展训练权重提高 1.008 dB，OFDM 训练权重变化 −0.075 dB，后者区间跨零。这里每幅图实际占 12,288 个复数资源元素，按 RGB 分量计算带宽比为 1/16。[正式结果](dir5/published_v2/all_paired_long.csv) · [冻结权重交叉干预](dir5/waveform_val256/paired.csv) · [符号预算](dir5/channel_check.json)
- **5B 的系统收益大于已测码本修正的独立作用。** 在 500 图、1/256、10 dB，生产版比共享 VQ-VAE 的黑盒高 0.855 dB、DISTS 低 0.05156。相对有真实信道信息的 Swin，同工况 PSNR 低 2.374 dB、DISTS 低 0.13820。新的两臂各训练 7,500 步，按各自原生方式部署，开启码本修正只改变 +0.0046 dB 和 −0.00019 DISTS，两项区间都跨零。固定推理都关闭时，训练使用码本对 500 图 DISTS 与 LPIPS 有小收益。两个数据集均显示推理时重新打开修正会使这两项指标退步。[两批生产结果的核对](dir5/release_comparison.json) · [训练和推理分开后的完整对照](dir5/train_control_256/REPORT_zh.md)
