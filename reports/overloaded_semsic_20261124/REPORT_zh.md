# 过载图像上行中，用什么来重构其他用户的干扰

**4B 和 6C 现在可以围绕一个问题成篇。** 三到四个用户同时向两根接收天线传图时，接收端从其他用户图像中提取的结构，能帮助它还原最弱用户。新实验给出了一个限制很清楚的结果：线性副本留下的干扰能量最小，图像质量却最差。直接使用去噪潜变量是一个有效、调用次数较少的方案。愿意为每次四用户接收额外支付十二次本地 RGB 解码再编码，两个测试工况下的弱用户 PSNR 都还能提高。[三页英文研究稿](paper/manuscript.pdf)

## 四用户的新证据

500 张图组成 125 个互不共图的四元组，四名注册用户同时活跃。每个四元组按原来的三个种子生成接收观测，各接收器共享相同的信号、噪声、信道和权重。两组名义 SNR 分别为 (18, 13, 8, 4) 和 (20, 14, 8, 2) dB。最后一名用户最弱。三轮并行抵消加上初始分离，共四次 LMMSE 求解。每个用户共享同一组 12,288 个复数资源元素，参考信号与静默观测占用每块 384 个维度中的 12 个。

| 生成干扰副本的方式 | 14 dB 近远差，弱用户 PSNR / DISTS | 18 dB 近远差，弱用户 PSNR / DISTS | 第三轮干扰 NMSE，14 / 18 dB 近远差 |
|---|---:|---:|---:|
| 线性估计，固定原门控 | 12.781 / 0.4258 | 11.766 / 0.4696 | −10.057 / −10.276 dB |
| 去噪潜变量直接重调制 | 15.245 / 0.4082 | 13.828 / **0.4502** | −8.918 / −9.049 dB |
| 先解码成 RGB 再编码，自身门控 | **15.949 / 0.4036** | **14.227** / 0.4582 | −6.444 / −6.649 dB |

这些 NMSE 只在推理结束后利用仿真真值计算。比较对象是最弱用户所受的三个干扰用户之和，位于接收端数据子空间中。值越低，减去的波形越接近真实干扰。误差在两工况的三轮中均以线性副本最低。弱用户 PSNR 的排序恰好相反。在更大的近远差下，潜变量的弱用户 DISTS 更好，四用户平均 DISTS 则仍以 RGB 路径更好。[完整均值](analysis/summary.csv) · [直接配对区间](analysis/paired.csv)

**门控配平能把收益定位到副本路径。** 保留潜变量接收器全部十二个用户／轮次门控张量和残余方差，线性改成去噪潜变量，两工况弱用户 PSNR 增加 **2.464 [2.231, 2.700]** 和 **2.063 [1.841, 2.286] dB**。在首轮结果出现后，另行登记了固定同一门控的 RGB 对照。潜变量改成 RGB 再编码后，仍增加 **0.704 [0.587, 0.824]** 和 **0.398 [0.293, 0.505] dB**。允许 RGB 自行更新门控后，两点均值分别只再变化 +0.000204 和 +0.000186 dB。这个改动使用接收端自己生成的连续 RGB，不读取源像素，每轮为每个用户增加一对图像解码与编码。[固定门控的全部差值](analysis/gate_paired.csv)

Kodak24 只有六个独立四元组。去噪潜变量相对线性副本增加 2.626 [1.872, 3.442] 和 2.642 [1.802, 3.519] dB。使用自身门控的 RGB 路径相对潜变量增加 0.669 [0.345, 1.005] 和 0.362 [0.032, 0.714] dB。两点上潜变量与线性副本的弱用户 DISTS 差值区间都跨零。所有区间均先在同一四元组内平均三个配对种子，再做 10,000 次四元组重采样，描述给定三份权重下的图组差异。

## 与三用户结果如何衔接

三用户、两天线的既有实验先解答了“抵消其他用户是否有用”。只更新残余干扰方差时，弱用户 PSNR 从 17.478 降到 16.169 dB。只减去其他用户的重构波形可升至 20.719 dB，两者配合为 21.587 dB。相对在独立验证集选好阻尼的常规 PIC，完整接收器增加 3.888 [3.758, 4.018] dB，限制为 166 个互不共图的三元组后为 3.898 [3.658, 4.156] dB。四用户新实验进一步回答了“减去哪种副本更有利于图像”。两种过载程度的用户构成和接收器不同，各自以自己的对照估计增益。[三用户原始配对报告](https://github.com/daiqizai/var-comm/blob/e7d0f0862baa9b682b2d25dcdedcb30d5356a74d/reports/direction_followups_20261123/README_zh.md)

学习式软干扰消除和多用户图像协作 SIC 都已有前例。本工作可独立主张的实质是，在注册用户数超过接收天线数的图像上行中，把其他用户的源结构用于重构干扰，并用同观测、同门控的干预定位它对弱用户图像的贡献。这里的 RGB 方法是同一接收器上的本地对照。它没有按外部方法另行训练。论文把图像保真、感知距离、消除误差以及额外调用次数分开报告。当前没有独立的接收时延测量，实验也只覆盖模拟信道和固定注册用户集合。[DeepSIC](https://arxiv.org/abs/2002.03214) · [多用户图像 MIMO 通信与协作 SIC](https://arxiv.org/abs/2504.07969)

## 复核与存档

首轮共 786 组正式四用户接收观测、3,144 个用户位置、9,432 条接收器评分，资格检查另有 12 条。原接收器按种子、图集、工况逐项复核的 48 个 PSNR/DISTS 锚点全部通过。后续门控实验在相同的 750 组 common500 观测上新增 750 个最弱用户重建，复用首轮对照分数。为取回未保存的门控，仅重放原接收器的分离步骤，750 组第三轮 NMSE 与首轮逐组一致。本轮没有模型训练。单卡 A800 两次评测分别耗时 238.64 和 133.62 秒，合计 0.1034 设备小时，包含评分与首轮资格核验。[数据检查](analysis/data_checks.json) · [两轮资源账本](run_receipts.json)
