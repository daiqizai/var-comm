# C_REAL：64 张校准图像上的真实链路结果

## 结论

QCSI-C8 在 4、7、10、13 dB 均提高了 DINOv2 ViT-L/14 相似度，平均增益为 0.0161–0.0290。与此同时，PSNR、LPIPS 和 MS-SSIM 在四个 SNR 均出现退化。7、13 dB 的 CLIP 相似度下降，13 dB 的 ConvNeXt 源预测一致率也下降。

四个 SNR 的原登记决策均为 `REPRESENTATION_TARGET_ONLY_STOP`：当前证据支持表征目标改善，未同时通过登记的独立指标要求。按固定样本规则停止，不据此宣称内容正确性改善，也不追加样本、重选策略或重新调参。[完整决策](../results/content_real_64qam_20261006/c_real_fixed64_v1/statistics/decisions.json)

真实接收、重建、指标、统计和在线 TX 组件计时均已正常闭合。C8 的 TX_total 均值约 2.03–2.17 秒，U 约 54.5–54.9 毫秒；这是固定 bin 的源端组件测量，不是端到端时延。

## 范围与统计口径

- 样本：原校准集合中的固定 64 张图像，属于 `calibration64` 内部验证；它们与策略建模使用的数据有复用，**不是独立 holdout**，也不是 H 的 development100。
- 网格：64 源 × 4 个平均 SNR（4/7/10/13 dB）× 16 次轨迹 × QCSI-U/QCSI-C8，共 8,192 帧。TX 使用预先冻结的选择，实际错误接受、拒收和灰图均保留在接收与评分结果中。
- 每源先平均 16 次轨迹，再对 64 源等权平均。区间来自原登记的源配对 bootstrap：10,000 次，种子 2026100605，95% 区间。这里报告的是复用校准样本上的描述性区间，不把 8,192 帧视为 8,192 个独立样本。
- 所有差值均为 QCSI-C8 − QCSI-U。指标方向按原定义保留，没有将误差指标反号。
- 以下均值、差值和区间直接转录封存统计表，只做显示舍入；未重算 bootstrap 或增加比较。[全部 18 指标均值](../results/content_real_64qam_20261006/c_real_fixed64_v1/statistics/summary.csv)、[全部配对区间](../results/content_real_64qam_20261006/c_real_fixed64_v1/statistics/paired.csv)

## 冻结链路与选择规则

每帧总预算固定为 N = 1,024 个符号：16 pilot + 16 feedback + 68 header + 最多 924 body；不足上限的剩余符号不发送。反馈携带 3 bit，属于付费但理想可靠反馈；CSI 也按上述开销计费并假定理想，不模拟有限 pilot 估计或反向链路错误。

信道为块 Rayleigh。相同源、SNR、trial 的两方法及各组共享同一个 h，并按前向物理符号位置使用相同的标准噪声数组；不同波形仍产生各自的实际接收观测。选择器只看到源图、平均 SNR 和量化 bin，不能看到真实 h 或链路结果。

C8 沿用原冻结的最多 8 项字典与逐源、逐 bin choice，期望质量权重仍使用原 C/R/U 条件概率、同 h 下组概率乘积和冻结积分规则。候选更新容差为 1e−14，块内及逐源 argmax 取第一个精确最大值，字典按原目录顺序排列；未按本批接收结果重选。接收使用实际 CRC 接受的连续前缀，拒绝组及其后扩展执行 DROP；部分尺度的熵序由 RX 已接收前缀重算。CRC 接受不等于已知正确，不用 TX 真值修复接收图像。
