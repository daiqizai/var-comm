# 数字基础＋真实源图纠偏：固定分配实验协议

登记日期：2026-09-15，Asia/Shanghai。依据用户新附件 `bdbba13c-2aeb-4fe6-bc2b-e92d635726fb/pasted-text.txt` 及“理解后推进”授权。此前收敛结果不改写；这是一个新的、有界的混合传输实验，不恢复旧架构搜索队列。

## 1. 唯一通信问题

在单次 N=3060、E=6120、无反馈 AWGN 下，从数字基础表示/保护中拿出一部分资源，实际传输 `x-G_m(U_m,c)` 的连续纠偏，能否相对完整数字自适应提高 PSNR，同时维持 LPIPS 非劣？数字与连续两条各占3060的输出融合不在本实验内。

旧独立验证主1/4/7 dB：raw数字19.41148dB/LPIPS0.179154，感知Deep 24.05945dB/0.206740，只证明存在不同取舍，不证明互补或融合必胜。依据为 `communication_convergence_final_20260915.md`。

## 2. 预先固定的工作点与代价

| 项目 | 本轮固定值 |
|---|---:|
| 视觉表示 | 原官方 VQ/VAR d16/图像Decoder，冻结 |
| 基础尺度 | raw m7，155 token，1860 source bit |
| Header | class10 + mode2 + CRC16 + tail6；68 complex uses |
| 数字body | 1860 + CRC16 + tail6，原K7母码1/2、QPSK；1882 uses |
| 连续纠偏 | 1110 complex uses，紧接数字区，正交坐标 |
| 总资源 | 68+1882+1110=3060；136+3764+2220=6120 energy |
| 噪声 | 全部区段同一实方差 `1/gamma`；不随功率重算噪声 |
| SNR | 1/4/7/13/19 dB，主1/4/7、高13/19分别报告 |

这只是单一可复核起点，不是最优分配。m7数字保护从2992缩为1882，源CRC/tail计入的有效信息码率从1882/5984变为1/2。控制信息通过实际header，无免费类别/前缀/瞬时误码；TX/RX共享名义SNR的理想CSI假设继续披露。

TX只读取原图、其确定性无噪声基础 `G_7(U_7,c)` 和共享名义SNR；不读取RX噪声、CRC或实际基础图。RX只读取实际数字译码、连续观测和名义SNR。冻结VAR使用batch1、FP32、argmax、无CFG的旧 `complete_image`，每帧重建KV状态。离线缓存仅节省训练中的确定性重复计算，不减免正式在线TX生成成本。

## 3. 一个候选与两个小融合控制

连续E/D复用本地既有残差卷积模块，只固定一组小规模通道32/64/96/128、每层1块、condition64。10×16×16原生实坐标中固定选2220坐标传输；未用坐标在RX为零，不传归一化因子。按每帧实际活跃I/Q归一化至能量2220。不得截断现有完整JSCC的波形充当已训练对照。

| 臂 | 输出 | 用途 |
|---|---|---|
| add | `clamp(x_D + e_hat)` | 单纯传残差＋硬相加 |
| snr_gain | `clamp(x_D + g(snr,0,0)*e_hat)` | 与候选完全同参数的无数字可靠度控制 |
| reliability_gain | `clamp(x_D + g(snr,CRC,received_distance)*e_hat)` | 唯一核心新候选 |

g为16隐藏单元、3通道gain、范围(0,2)的小MLP，初始化为1。接收距离是实际y_D与ML路径（包含实际译出CRC位）的重编码波形残差，按名义噪声方差归一；不是真实BER、真token概率或CRC正确性的oracle。两种gain完全同参数；add少的参数如实单列。此候选只检验简单的接收可靠度调制，不泛化为所有融合网络。

Header失败/模式不符始终固定灰图；数字body CRC失败仍用实际ML候选渲染。错误接受也保留，事后统计而不修复。训练包含真实数字PHY错误，不只训练完美基础。TX显式源残差与RX内部R2 residual不是同一信息来源。

## 4. 训练和选模固定，不再搜索

三臂从相同E/D初始权重分别训练；两gain初态也相同。每臂10000更新、batch16（160000源图呈现，名义8遍20k），原20k中心裁剪、不增广；AdamW lr2e-4、wd1e-4、clip1，loss=`MSE+0.01 LPIPS`。同数据顺序、数字噪声/候选与连续噪声，独立optimizer。DINO不训练、不选模。10000是本次有限预算，不是训练充分性的先验保证；结合曲线报告，不据短训否定架构。

每1000更新固定100校准源（三原噪声、五SNR）；5000/10000跑完整1000。仅在这两个完整校准checkpoint中选模。工程profile可调整实现执行分块，不改变有效batch、loss或总更新预算。非有限梯度停止所有配对臂并保留失败，不暗中降低一个臂预算。

主目标为主1/4/7的源图平均PSNR，约束对**两条冻结完整raw/arithmetic自适应**分别满足平均LPIPS差≤0.005。0.005是预先登记的工程非劣容差，不是虚构的应用阈值；期望PSNR增量≥0.5dB。先按约束筛选，再最大PSNR，精确相同取较早checkpoint。无可行点时，只以最小最大约束违反选一个明确标为“不合格”的诊断点，不能称新强基线。测试时不按每图真值选择。

开发报告：对两数字链分别给PSNR/MSE/LPIPS配对CI；达到主目标需PSNR点增量≥0.5dB且CI下界>0，LPIPS差CI上界≤0.005。这个容差不等于LPIPS严格更好。按原图先平均三个噪声再bootstrap，不能把传输数当独立样本数。所有失败进入分母，分SNR与高SNR另列，不用合并平均掩盖劣化。

## 5. 必须面对的强对照

1. 冻结完整raw数字自适应与实际整帧算术码＋FEC自适应（各自真实68/94 header账本）。
2. 已充分训练的3060-use感知DeepJSCC；不得使用5/6dB错误condition历史输出。此次只评原支持五SNR。
3. 同分配add和同参数snr_gain；有无可靠度的独立作用以两gain对照为准。
4. 原完整raw固定m7（将1110全部用于额外保护）和固定m8/m9（将资源用于更多真实尺度），作为直接数字资源去向控制。它们用原整帧，不人为增加分包损失。
5. 缩短基础单独输出与无噪声基础仅做消融/表示参考，不能替代完整强对照；analog=0输出不是新的低预算赢家。

复用旧数据前核验图像ID、预处理、seed、波形坐标、功率及header。新波形使用原 `seeded_noise(image_id, seed, (3060,2))`，连续部分取最后1110次，不能另给更好的随机实现。完整数字和连续Deep都保留其合法协议区别。

在线成本需另测新系统：CPU原图→VQ→TX VAR补全→残差E→实际波形；CPU y→FEC→RX VAR→残差D/gain→CPU图。训练缓存不能出现在此计时中。分别报告TX/RX、训练GPU小时和缓存GPU小时；不含空口、排队、权重加载、类别获取、CSI估计。旧baseline完整计时只读复用，不重复整套benchmark。
