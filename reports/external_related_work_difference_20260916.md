# 与相关工作的具体差异：有边界差异，尚无自动成立的新机制

核查日期2026-09-16；只采用论文/正式页面/作者仓库。范围限以下相关工作，不是穷尽式新颖性保证。当前不因差异表启动新模型或新数据评测。

| 工作 | 已有内容 | 本项目不同之处及不能冒领之处 |
|---|---|---|
| ARPC，ICLR2026 | next-scale渐进源编码、生成概率熵编码、未发部分补全 | 原文是压缩系统，表示/训练也不同；本项目固定无线N/E与失败后果是问题边界，不是前缀生成首创 |
| Ada-TokenCom，2026-08-28 v1 | AR算术码、前缀/MCS联合适配；平均符号约束、ARQ；质量统计针对成功图像，重传消耗计入CBR | 我们每帧固定N/E、无ARQ、失败输出也计质量；不能说它没有计CRC、没有计失败资源或只用固定索引 |
| SwinJSCC，作者SA/RA模型 | 学习通信映射、SNR和码率适配 | 本项目多尺度先验和数字/学习接口不同，不自动具有新颖性；作者模型在像素/计算上仍是强对照，训练条件未控制成纯架构实验 |
| DiffCom / HiFi-DiffCom，作者代码 | 复用已有通信编码，以实际观测约束扩散恢复 | 本项目的VAR前缀补全不是其迭代后验采样；待完成同ADJSCC/同数据观测归因和同N4204比较，不能预先把慢等同没有价值 |

Ada-TokenCom原文§III-B/C、§IV-D明确区分资源与成功图像质量。其少量语义条件开销在实验中忽略；我们为类别bit真实计费，但TX真类别的获取假设仍额外存在，不能因此宣称信息条件完全一致。它已展示过感知/像素取舍，仅重复这类现象本身不是独立创新。

## 现有证据真正支持什么

- 已完成结果支持低资源感知、像素保真和接收计算之间的实测取舍，不能由N3060与N4498的横排表直接判胜负。
- 新的只读复算显示N4204/1dB整帧算术链可靠接受率更高，但全传输LPIPS更差；这支持研究失败图像的风险形态，而非继续追逐一个成功率代理。
- 该发现仍可能被常规误差韧性源编码覆盖。普通适配/熵编码已经取得的收益不能归为本项目新调度；2026-09-15的算术quality=BLER负结果保留。
- 没有直接把ARPC、Ada-TokenCom在相同协议下实际重跑，因此这里只比较技术/服务假设，不宣称胜过其完整作者系统。

## 单一最小缺口

将普通可重同步/误差韧性熵码作为额外强对照，才可能区分“有限预算与失败风险的可用机制”与“整帧熵码特有错误传播”。只能先登记一个固定、可计费的对照，不搜索分配、换网络或复活旧分组VAR-MAP路线；当前没有执行授权/新队列。若它覆盖现有优势，应保留成熟系统并更换机制研究起点，而不是为VAR增加模块。未来若保留工作点，独立验证仍须另行冻结与授权，不能再称旧development/已用holdout为新测试。
