# RX posterior step1 v2：历史校准与已替换的自检

v2 使用真实冻结模型、原固定200张校准源和三噪声种子，完成了 β/λ 的真实-token对数概率校准。它没有通过当时要求的“30 dB、TF和CL均≥99%”硬门槛，因此当时没有读取新的 development 结果。用户随后以 v3 的精确零噪声检查替换该门槛；本记录保留历史，不能据此阻止已授权的 v3，也不能把旧失败改写为通过。

固定 β=0、λ=1 的30 dB检查：TF 90.6740%，CL 36.2745%。四档校准版本依次为 TF/CL：89.8284%/36.6789%、83.4191%/31.1152%、70.8333%/21.5319%、70.8333%/21.5319%。CL与原编码路径的token一致率会受到路径分岔影响；v3已改用路径条件准确率和latent平方误差。

四个难度档位为30.6、20.2、14.6、10 dB。V选择的(β,λ)分别为(.05,.5)、(.2,.5)、(.5,.5)、(.5,.5)；A2分别为(.1,.5)、(.2,.5)、(.2,.5)、(.5,.75)。这些参数只优化旧版概率评分，不是 v3 的判定参数。

完整校准源均值、旧自检120项/1200尺度记录、参数和两张图见 [revision_v2](../results/rx_posterior_step1_20260929/revision_v2/index.json)。48,000条网格源均值和33,000条难度源均值仍保留；真实帧与源平均的统计单位不得混称。

旧版结束时曾按当时执行单恢复原队列。N3060等待器因 Git 文件枚举增加了独立 RX 文件而拒绝重登记；原470项依赖 SHA 均未改变。独立适配层固定原依赖清单，拒绝原依赖移除或范围外新增；该事件不是模型质量失败。后来用户明确要求停止旧训练，原外层守护、训练和四个历史等待器均已退出，自动推进 var-comm 已暂停。历史恢复脚本仅保存证据，**不得再次运行来恢复旧队列**。
