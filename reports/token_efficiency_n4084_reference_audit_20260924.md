The real existing comparison has seven methods and10,500 rows (100 original development sources x five SNRs x three noise seeds). The audit confirms byte-identical source preprocessing between the current population loader and original evaluation loader, complete source/SNR/noise keys, finite metrics, N4084/E8168 ledger and frozen Dc identity. Every comparison metric equals its actual original output row. Oracle/zero-noise diagnostics are excluded from the original1024 communication reference.

All declared lineage files, recorded source snapshots, selected checkpoint files and calibration-policy input hashes passed verification. Digital adaptive rows use their calibration-frozen mode and exactly match that candidate's original development row. The resource lookup actions were recomputed from the original calibration utility and every development action matches the frozen choice. Existing policy versions and m789 support are preserved; they are not substituted into new m6-m10 protocol cells.

This establishes original receipt integrity, not current thermal/runtime equivalence. The old timing remains separate until the current uniform timing scope is accepted.
