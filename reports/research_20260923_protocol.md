# Registered bounded post-review research

Authorized after phase1 commit3f229fa73dd8eee117b746a3ee064eeecc0661c4. No new holdout. Original20k/1k/100 roles, five SNRs, frozen visual codec and selected stageA Dc remain. Original loss is MSE+0.1LPIPS+0.01normalized latent; failed hybrid headers retain original image fallback and latent mask. Pure communication has no class/header/base inputs, so its latent loss includes every source.

1. Frozen original1024: actual/oracle base crossed with actual/zero enhancement noise. SNR and observable status stay at trained values. Dc(F) is a representation reference, not wireless. These diagnostic views do not enter the main ranking.
2. Pure continuous: exactly4084 complex symbols, E8168, F-only TX and observation/SNR-only RX. A fixed8168-coordinate readout from8192 learned coordinates is used from initialization through training, with zero-filled unavailable RX positions. This is not evaluation truncation of a4096-use checkpoint. Network width64 and three blocks follow the existing small communication modules. Per-frame normalization does not expose an untransmitted norm.
3. Matched light/full TX pair: both start from the same selected40000-step enhancement parent and get5000 new updates with separate fresh AdamW optimizers. Full TX uses its original residual/Fb_TX. Light TX gets F and the true m8 cumulative latent, accumulated with the original ten-scale mapping. Its first convolution is reparameterized [Wr,Wb] -> [Wr,Wb-Wr] before replacing the completed condition with the prefix. RXs retain actual Fb_RX/status and the same Dc. No VAR is run in the light TX endpoint. Optimizers are reset on both arms because transformed second moments cannot be reconstructed from stored diagonal moments alone.
4. The fresh pure control receives10000 updates, full calibration every2500, selection by minimum full calibration utility. This is a registered finite opportunity, not a convergence claim or equal total historical training with the40000-step parent. Development is read only after checkpoint selection. Report curves and this limitation regardless of who wins.
5. Existing N4084 endpoints: raw/arithmetic m7/8/9 and the original m8 hybrids are selected by calibration mean MSE+0.1LPIPS at each SNR. Digital calibration may be reused with artifact hashes/source identity checks; missing fold512 calibration is recomputed. All fees/failures are retained. This is a frozen lookup, not a novel scheduler. It is not complete m10/new-Decoder digital adaptation.
6. Secondary projection: uncentered training residual second moment, top1984 directions, versus the original random1984 basis. Both use32 norm-control+992 measurement uses, re-fit pooled W and the same Dc. No sample-dependent projection or free mean/norm. Explained training energy is not an image-quality result.

GPU0 is used only while available. New trainers checkpoint and stop at paired update boundaries on stop signals or foreign GPU use. Existing registration/SHA conventions bind code, configuration, parent, decoder, data and prefix cache. Real-model checks precede training; test updates are discarded. Initial GPU resume comparison exposed nondeterministic reduction differences around1e-8; this new process uses deterministic kernels. A second probe exposed CPU-versus-GPU placement of Adam's scalar step in the test loader; the probe now uses the actual trainer's CPU-load path. The third qualification passes bitwise parameter and Adam-state continuation checks. Failed qualification runs and logs are retained and are not training results.

The working tree remains the actual project root. No shared device settings, old checkpoint/result bytes or public repository visibility are changed.

## Numerical scope amendment before new resource-policy calibration

Actual reuse checks found that the historical digital entry point left cuDNN TF32 enabled, whereas registered new training and shared evaluation disable both TF32 flags. The original table matches a legacy-precision replay but not strict precision. Preserve the old scope; recompute only N4084/Dc raw/arithmetic m7/8/9 calibration and development, and folded512 development, at the registered strict precision. The loss, sources, SNRs, seeds, candidate set and policy criteria remain unchanged. This is a required cache invalidation and minimal inference rerun, not A/B retraining or a changed research selection rule.
