# 外部定位：非扩散部分阶段结果

日期：2026-09-16，19:05完成实测汇总，19:05:42完成CPU复核。**HiFi-DiffCom全量仍在运行，本报告不替代最终外部定位报告。**

## 结论

现有系统存在明确的感知、像素质量、带宽和计算取舍，并非全面没有竞争力，也不是全面获胜。

- 真正相同N4498/E8996下，主1/4/7dB的raw数字VAR相对作者SwinJSCC RA32，LPIPS降低0.126653、DINO提高0.221732；但PSNR低5.2319dB、SSIM低0.18456，完整RX约59.64ms而Swin约5.58ms。
- 原N3060的R3在13/19dB仍保有低LPIPS工作点，但没有像素质量或速度的全面优势。Swin更高自然码率能显著改善感知指标，不能删除其高码率曲线或我们自己的更强对照。
- **现在不能判断是否胜过成熟生成式通信恢复，仍须等HiFi同观测对照。** 不据阶段结果启动新架构、CSI题或重新打开已停止的混合支线。

## 2. 通信口径

| 外部点 | 数据uses | 必要元数据uses | 总complex uses | 总能量 |
|---|---:|---:|---:|---:|
| ADJSCC C2 | 4096 | 0 | 4096 | 8192 |
| HiFi C2，质量尚待 | 4096 | 108 | 4204 | 8408 |
| Swin RA32 | 4096 | 402 | 4498 | 8996 |
| ADJSCC C4 / C6 | 8192 / 12288 | 0 | 8192 / 12288 | 16384 / 24576 |
| Swin RA64 / RA96 | 8192 / 12288 | 562 / 664 | 8754 / 12952 | 17508 / 25904 |

- 统一平均复符号能量2、实噪声方差1/gamma；作者单位功率作数学等价换算。外部数据CBR分母是3×256×256，总资源另报；实坐标、source bits不当complex uses。
- Swin真实encoder归一化功率和源相关active-channel集合计费；集合使用组合数排名紧凑编码。HiFi真实encoder功率计费。**裸ADJSCC不需要这些字段，没有被强加header。** 作者免费元数据假设只出现在单独表。
- 元数据实际经过信道；CRC失败但字段合法的候选保留，非法字段按冻结规则回退。Swin本次一个RA96元数据CRC失败未被排除。
- 新数字raw header为68、算术为94uses，其余为数据。CRC16、尾6bit和rate matching均计费；真实重新编码/译码，不把旧N3060质量冒充新预算。
- TX知道真实类别、TX/RX共享理想名义SNR的假设继续披露。类别bit付费不等于类别获取免费；获取/估计成本未测，无反馈和重传。外部模型不使用类别，不被人为加相同header。
- 新预算只在原m7/m8/m9、原FEC内校准，不声称穷尽更大N下全部可能源尺度。校准索引为原1000中的`rint(linspace(0,999,100))`，seed4101/4102/4103；development为原100和seed2001/2002/2003。
- 以原LPIPS主目标、相对同族BLER规则PSNR下降不超过0.25dB选动作；DINO不选模。两预算两族均选SNR1→m8，4/7/13/19→m9；开发不按每图真值选mode，不混入校准指标。
