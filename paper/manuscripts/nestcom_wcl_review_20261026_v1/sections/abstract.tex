\begin{abstract}
Next-scale token representations support progressive image transmission, but whole-scale endpoints can leave substantial digital-frame capacity unused. We propose NeST-Com, which combines within-scale prefix selection, actual-length fitting, and prefix-constrained reconstruction under a fixed symbol budget. A protected profile specifies the endpoint and modulation/coding scheme, while a shared frozen prior completes missing tokens. With the same prior and image decoder, within-scale endpoints improve PSNR by 0.32--0.70~dB and raise source-bit utilization from approximately 78\% to 95\% at 10~dB. Five-method experiments characterize the resulting fidelity, perceptual similarity, and processing cost.
\end{abstract}
