# Software and visual-review provenance

The manuscript figures use existing saved results. The figure workflow follows the locally installed figures4papers `scientific-figure-making` skill (design theory, common patterns and trend-layout demos). The final export audit also uses the preserved K-Dense `scientific-visualization` skill. Exact files and SHA256 identities are in `software_provenance.json`; PDF review uses the local PDF skill and the actual rendered pages recorded in `review/`.

The final physical figure sizes follow the measured IEEEtran template geometry. This is a scientific review copy, not a claim of compliance with an unspecified journal or submission phase. No training environment was upgraded, no external image generator was used, and no font files are distributed.
