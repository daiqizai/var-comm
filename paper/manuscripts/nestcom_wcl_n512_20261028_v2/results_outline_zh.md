# 本轮稿件主线

固定数字帧需要选择可送达的源图表示。Next-scale 的完整粗尺度提供全幅低分辨率潜描述，后续尺度残差细化；整尺度端点与图像相关的实际熵码长使帧容量容易闲置。NeST-Com 以尺度内端点和独立终止码长检查装入，再让收到的边界 token 同时进入残差重建与后续尺度预测。

引言四段依次回答：通信约束、表示结构与相关工作、容量不匹配及接收端使用、完整方法与证据。方法仍保留三个小节。

III.B 使用同模型主对照、受控端点粒度和 A0/B0/C0 接收干预验证新增设计。III.C 使用完整系统语言报告 N1024 外部比较。

III.D 分两层：WHOLE−Ada 的 4/10 dB 平均 PSNR 差为 3.79/3.66 dB，仅描述既有均值，不新增配对显著性；NeST−WHOLE 的三 SNR、四指标已有配对区间全部有利 NeST 且排除零。10 dB 的相同目标 (7,0) 和 16-QAM 2/3 表明尺度内回退可把利用率由 79.30% 提高至 93.46%。仍保留 Ada 的 CLIP-I 优势、19 dB DreamSim 优势、17 次失败的权重和跨预算分别校准的解释边界。

结论聚焦整体方法、内部增益在 N512 的延续、系统级表现与感知取舍；后续工作仅提出 SNR 不确定性和衰落信道。
