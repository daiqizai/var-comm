## 当前引言中文对照

Next-scale 表示通过完整的粗尺度图及后续的残差细化来描述图像 [1]。每个尺度图都覆盖整个潜变量空间的空间范围，并为更细尺度的概率预测提供上下文。对于通信，这种组织方式既提供了可以逐步细化的源图描述，也为重建未传输的内容提供了上下文。

ARPC 通过尺度选择、熵编码、生成和自适应量化，实现了 next-scale 渐进图像压缩 [2]。Ada-TokenCom 在长期符号预算约束下联合调整 next-token 前缀长度与调制编码方案（MCS），并利用已接收的前缀生成剩余 token [3]。ResARC 则进一步编码残差，以补偿后缀生成误差 [4]。这些研究分别从渐进式源编码、前缀传输和生成误差补偿等方面，建立了逐步传输与重建图像信息的技术基础。

然而，在每幅图像采用固定长度数字帧的通信系统中，源编码的终止位置需要与实际熵编码长度、信令开销及信道保护开销相匹配。如果下一个完整残差图无法装入当前帧，整尺度传输就可能留下仍可用于传输部分 token 的剩余容量。因此，需要在尺度内部引入更多合法的终止位置，并依据实际终止码长判断其是否能够装入当前帧。与此同时，当仅传输部分边界尺度时，接收端还需要将恢复的 token 同时纳入残差重建和后续尺度预测的上下文。因此，如何协调源编码终止、受保护数字帧的容量适配与渐进重建，构成了本文关注的核心问题。

为此，我们提出 NeST-Com，一种面向固定逐图信道符号预算的 next-scale 数字图像通信框架。该框架保留尺度级概率计算，同时依据独立终止后的实际码长与受保护帧主体的可用容量，选择尺度内传输前缀。接收到的边界 token 通过 VAR 已有的已知 token 覆盖与递归更新机制，参与残差重建并约束更细尺度的预测 [1]。此外，我们利用所用算术编码器独立终止码长的非递减性质确定预算内的可行前缀集合。通过共享模型比较与匹配条件下的端点粒度实验，验证尺度内传输对帧容量利用和重建质量的改善；通过接收端干预实验分析已接收信息的作用，并通过完整系统比较评估不同通信方案的重建质量与处理成本。
